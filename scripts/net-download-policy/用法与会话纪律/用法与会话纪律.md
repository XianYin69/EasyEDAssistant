# 网络资源下载策略 — 用法与会话纪律

> 本文件收录命令示例与运行时挂钩（总索引见 [`../net-download-policy.md`](../net-download-policy.md)）。
> 编辑遵守 RULE_EDIT.md：≤ 50 行、自然语言。

## 用法示例（cwd 必须是工作区根目录）

```bash
# 单个：数据手册
python scripts/net-download.py \
  --url https://www.renesas.com/document/dst/ics1893ds.pdf \
  --name ics1893ds.pdf --out-dir tmp/downloads/datasheet

# 批量：从清单文件
python scripts/net-download.py --url-file ./tmp/plan/dl-list.txt

# 判定（不下载）
python scripts/net-download.py --url https://x.example/foo.zip --dry-run
# 预期：拒绝：.zip 在黑名单
```

## 与会话纪律的挂钩

1. **先记动机再下载**：调用前须已在 `./tmp/learning/` 或 `./tmp/plan/` 记录「为什么要下载这个 URL」，避免顺手抓取（正本见 [`../../../references/约束部分/记忆链/记忆链.md`](../../../references/约束部分/记忆链/记忆链.md)）。
2. **下载后补摘要**：数据手册/参考文档须同步 `./tmp/datasheet/` 摘要 markdown（型号/关键参数/页码出处）；`./tmp/downloads/` 原件本身在收尾时全清（正本见 [`../../../references/约束部分/垃圾处理/垃圾处理.md`](../../../references/约束部分/垃圾处理/垃圾处理.md)）。
3. **门禁不豁免**：任何非白名单格式即使「看似必需」也不放宽（见 [`../格式黑名单/格式黑名单.md`](../格式黑名单/格式黑名单.md)）。
4. **账本留证**：涉及下载的检查步骤（成本、元件、专规）在 `./tmp/init/progress.md` 的 `cmd:` 字段记录本次 `net-download.py` 调用，`art:` 指向 `./tmp/downloads/index.json`（正本见 [`../../../references/约束部分/步骤门禁/步骤门禁.md`](../../../references/约束部分/步骤门禁/步骤门禁.md)）。
5. **tmp 子目录契约**：`./tmp/downloads/` 及 7 个分类子目录的归属见 [`../../../references/初始化部分/在工作区建立tmp文件夹/目录契约/目录契约.md`](../../../references/初始化部分/在工作区建立tmp文件夹/目录契约/目录契约.md)。
