# 网络资源下载策略 — 格式黑名单

> 本文件是 `scripts/net-download.py` 常量 `FORBIDDEN_EXTENSIONS` 的正本对照（总索引见 [`../net-download-policy.md`](../net-download-policy.md)）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 明确禁止（哪怕 URL 直接可下载）

| 类别 | 扩展名 | 原因 |
|---|---|---|
| 可执行 / 动态库 | `.exe` `.dll` `.so` `.dylib` `.bin` `.com` | 恶意风险、无 EDA 用途 |
| 脚本 | `.sh` `.ps1` `.bat` `.cmd` `.vbs` `.js` `.jar` | 潜在执行面 |
| 归档 | `.zip` `.rar` `.7z` `.tar` `.gz` `.bz2` `.xz` `.iso` `.img` `.dmg` | 内容不可校验，易夹带可执行 |
| 媒体容器 | 未列入白名单的音视频 | 与本 skill 用途无关 |

## 判定与例外规则

- **黑名单优先于白名单**：同时命中两侧时按拒绝处理。
- **不存在 `--force` 参数**：任何非白名单/黑名单格式，即使对设计「看似必需」也不打开；
  改为向用户报告并请其手动提供原件，或改走 [`../../references/浏览器检索/浏览器检索.md`](../../../references/浏览器检索/浏览器检索.md) 取在线页摘要。
- `--yes` 只落实已有的授权确认，**不越过格式判定**。
- 放宽黑名单属重大变更：须 [`../../references/约束部分/安全与合规/安全与合规.md`](../../../references/约束部分/安全与合规/安全与合规.md) 评估 + 用户明确授权 + 同步脚本常量与本文件两处 + 记 `CHANGELOG.md`。
