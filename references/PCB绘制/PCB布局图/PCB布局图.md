# EasyEDAssistant Reference：PCB绘制 — PCB布局图

> 本文件是「PCB绘制」第 3 步的分支细则（自然语言）：绘制前生成独立 PCB 字符画布局图并再次向用户询问布局。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 步骤

1. **独立文件（与原理图布局彻底分开）**：布局图落 `./tmp/design/<工程>-pcb-layout.md`，**只依据** `<工程>-pcb-spec.md`、`<工程>-layout-intent.md` 与 `layout-calc.py` 计算结果生成；**禁止复制、改写或「转换」`<工程>-sch-layout.md` 充数**——原理图布局文件归原理图侧独立维护，两份互不覆盖。
2. **字符画图例**：box-drawing（`╭╮╯╰ ├ ─` 或纯 ASCII `+ - |`）画板框外形与圆角，标注长宽（mm）、安装孔位、板边接口与开口方向；分区用 `+------+`/`[模块名]` 小框，keepout 斜线阴影 `////`，器件只标位号（`U1`/`J1`/`C1..C8`/`ANT1`）；**声明比例尺（1 字符 ≈ N mm）**；附 T1–T4 四档清单与跨模块关键连接（net 名 + 起讫 + 档位）。
3. **先读后画**：net 真值取 `sch connectivity --all-pages` 回读，分区/边距数值取 `layout-calc.py` 与 `pcb list --include-bbox`，不得凭记忆或照抄原理图蓝图补分区。
4. **再次询问用户（强制中断点）**：蓝图摊出后**必须再次询问**——分区位置、接口朝向、主芯片落点、阵列/对称偏好是否按图执行；答复与拍板时间记入文件「决策头」，同步 `chain-log.py add memory --by user`；未答复 = P0 中断，禁止进入放置。
5. **只增不改**：布局变更在蓝图「变更记录」追加新节并注明取代关系，破坏性重写须用户确认；每次落位/移动对照蓝图执行，偏离先改蓝图并重新签核，再动板。

## 门禁

- `./tmp/design/<工程>-pcb-layout.md` 不存在、或决策头无用户「按图开工」拍板记录 → **禁止任何放置/布线**；违反按 [`../../约束部分/处罚机制/处罚机制.md`](../../约束部分/处罚机制/处罚机制.md) L2 回退。
- 字符画与坐标冲突时，坐标以 `pcb list --include-bbox` 回读为准；字符画不替代 `layout-lint`/`pcb check` 硬门。

## 判据与动机

- 原理图蓝图管「图面怎么画」，PCB 蓝图管「板子怎么摆」——两份文件分开，改版与对账互不牵连。
- 放置前多一次布局确认的成本远低于整板重摆。
