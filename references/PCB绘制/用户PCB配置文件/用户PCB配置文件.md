# EasyEDAssistant Reference：PCB绘制 — 用户PCB配置文件

> 本文件是「PCB绘制」第 2 步的分支细则（自然语言）：绘制前先生成用户 PCB 配置文件。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 步骤

1. **读必答清单**：读取 [`../../lib/pcb-design-spec.md`](../../lib/pcb-design-spec.md) §2 的 D1–D20 共 20 项，外加本文件第 2 节的 **R1–R5 扩展必答项**。
2. **逐项向用户核对**：D 系列——板框与尺寸、安装孔、叠层与铜厚、电源轨与电流、接地方式、阻抗与差分、接口位置与朝向、天线与 keepout、封装下限、热预算、测试点、丝印要求、隔离要求、DFM 目标、拼板、颜色、未用脚处理、成本档、验收线；**R 系列逐条不可漏**（见下节）。
3. **落盘成基线**：答复写入 `./tmp/design/<工程名>-pcb-spec.md`（同名 `.json` 可选），作为本阶段设计基线。
4. **「沿用」须有出处**：已由方案或上游确认的项可沿用，但须向用户出示出处（文件路径+条目）；**无出处的视为未问过**。「只问会改变做法的项」不构成跳问许可——未问且无出处 = 该问题仍未完成。

## R 系列扩展必答项（本项目追加，均须拍板后写入配置）

| 项 | 内容 | 影响 |
|---|---|---|
| **R1 走线拐角角度** | 45°/圆弧/直角混合中允许哪档；圆弧半径档；高速/RF 段加严档（默认禁直角） | 走线风格统一性与制版蚀刻质量（见 [`../../电气检查/硬编码规则/PCB/间距与线宽.md`](../../电气检查/硬编码规则/PCB/间距与线宽.md) 图形质量条） |
| **R1b 走线宽度分级** | **全板统一线宽** vs **按角色分级**（信号 / 时钟 / 差分 / 电源主干 / GND 回流）；若分级，各角色档位按 [`../../电气检查/硬编码规则/PCB/间距与线宽.md`](../../电气检查/硬编码规则/PCB/间距与线宽.md) 走线宽度档位表拍板；铜厚与电流换算见 [`../../电气检查/硬编码规则/PCB/载流与温升.md`](../../电气检查/硬编码规则/PCB/载流与温升.md) | 布线阶段执行方式与返工范围；`pcb net-classes` 回读须与所选档位一致 |
| **R2 走线策略** | 关键网清单（差分/等长组/时钟）与匹配档；换层与残桩策略；**向量布线许可面**（哪些网允许 `route-short` 批量、哪些必须人工逐段；`via-hop` 换层是否批准、允许层数；`rip-up` 让位授权范围）；3W/包地默认档。**注：迷宫自动布线（autoroute）已弃用，不作为选项提供**，方法正本见 [`../干涉布线/干涉布线.md`](../干涉布线/干涉布线.md) | 布线阶段执行方式与返工范围 |
| **R3 铺铜策略** | 顶层/底层是否全铺 GND；热焊盘 relief 档；死铜清理与 antenna-keepout 例外清单 | 蚀刻、回流与 EMC |
| **R4 丝印三清单（型号/版权/功能指引）** | **板型号丝印**：型号/版本/日期码/序列号区/厂商标识字符串与板角落位；**版权丝印**：逐字版权文本（可选 logo SVG，须用户提供）与所在层（丝印/隐蔽）、字号下限（≥40 mil 制版约束）；**功能指引丝印**：分区框清单（电源/RF/接口等）、按键与指示灯注解、接口方向标识；每项都要逐字文本，不加也记「不加」 | 执行见 [`../丝印标注/丝印标注.md`](../丝印标注/丝印标注.md)；DFM 约束见 R 项与 [`../../电气检查/硬编码规则/PCB/绘制与制版规范/绘制与制版规范.md`](../../电气检查/硬编码规则/PCB/绘制与制版规范/绘制与制版规范.md) 各类型制版条款 |
| **R5 其它偏好兜底** | 过孔类型偏好（盘中孔/背钻是否接受加价）、测试点覆盖率、拼板标记与基准点、板边倒角等一次性摊给用户；答复或「无偏好」均入配置 | 防止逐项漏问 |

## 附加决策点（继承原 §6 设计决策目录）

除 D/R 系列外，以下选项会改变实际做法，须摊给用户拍板后写入配置：2 层 vs 4+ 层叠层（推荐 ≥2 电源/地网即 4 层）；VCC 内层用 PLANE 还是 SIGNAL 分区（单一主电源域走 PLANE）；地域数量（单 GND，显式多地才拆域）；线宽分级（全板统一 vs 按角色分级）；USB 架构（单通道桥 / HUB 双通道 / 纯原生无桥）；自动下载方式（物理键 / DTR-RTS 双管 / 原生 USB 软复位）；选型档位（固定标准件表 vs 动态比价）；单面 vs 双面；焊接工艺（手焊 0603 下限 vs 贴片 0402/QFN）。

## 门禁

- **D1–D20 + R1–R5 逐条闭环**：每条要么有用户答复、要么有带出处的沿用记录；**存在未问或未答项 = 不得开工（P0 强制中断等答复）**；禁止静默跳问、禁止代用户填默认值、禁止把「用户没提」当「同意默认」。
- **D1 板框 / D2 安装孔 / D8 关键接口位置**未定 → 不得开工，触发 P0 强制中断等用户答复。
- **布局基线（边距与分区）**：D1–D20+R1–R5 拍板、配置基线落盘 `./tmp/design/<工程>-pcb-spec.md` 后，**先向用户问清排布意图**（分区/固定件/信号流/热与 RF/阵列偏好，落盘 `./tmp/design/<工程>-layout-intent.md`），再用 [`scripts/layout-calc.py`](../../../scripts/layout-calc.py) 按答复计算边距/分区/器件间距（`pcb edge`/`gap`/`zone` 三命令），结果回填配置基线；未问意图或未算布局 = 基线未定 = 不得进入放置（见 [`../../约束部分/布局计算纪律/布局计算纪律.md`](../../约束部分/布局计算纪律/布局计算纪律.md)）。
- 板框后续变更使 `outline_confirmed` 失效 → 重新向用户签核，再继续绘制。
- 配置文件属规划层工件，不写 EDA 图元；缺失项标「未定」而不填猜测值。

## 判据与动机

- 机械与外壳约束（P0）压倒美观与性能：先行确定才能让其余器件绕它布局。
- 配置文件是重复评审与返工成本的止损点：一次问清，避免中途反复推翻板框与接口。
- 与 [`../PCB设计规范/PCB设计规范.md`](../PCB设计规范/PCB设计规范.md) 配套：配置定「要什么」，规范定「怎么算合格」。
