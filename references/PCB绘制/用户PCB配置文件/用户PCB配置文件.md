# EasyEDAssistant Reference：PCB绘制 — 用户PCB配置文件

> 本文件是「PCB绘制」第 2 步的分支细则（自然语言）：绘制前先生成用户 PCB 配置文件。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 步骤

1. **读必答清单**：读取 [`../../../Sample/easyeda-agent/references/pcb-design-spec.md`](../../../Sample/easyeda-agent/references/pcb-design-spec.md) §2 的 D1–D20 共 20 项。
2. **逐项向用户核对**：板框与尺寸、安装孔、叠层与铜厚、电源轨与电流、接地方式、阻抗与差分、接口位置与朝向、天线与 keepout、封装下限、热预算、测试点、丝印要求、隔离要求、DFM 目标、拼板、颜色、未用脚处理、成本档、验收线。
3. **落盘成基线**：答复写入 `./tmp/design/<工程名>-pcb-spec.md`（同名 `.json` 可选），作为本阶段设计基线。
4. **只问会改变做法的项**：已由方案或上游阶段确认过的选项直接沿用，不重复索取。

## 附加决策点（继承原 §6 设计决策目录）

除 D1–D20 外，以下选项会改变实际做法，须摊给用户拍板后写入配置：2 层 vs 4+ 层叠层（推荐 ≥2 电源/地网即 4 层）；VCC 内层用 PLANE 还是 SIGNAL 分区（单一主电源域走 PLANE）；地域数量（单 GND，显式多地才拆域）；线宽分级（全板统一 vs 按角色分级）；USB 架构（单通道桥 / HUB 双通道 / 纯原生无桥）；自动下载方式（物理键 / DTR-RTS 双管 / 原生 USB 软复位）；选型档位（固定标准件表 vs 动态比价）；单面 vs 双面；焊接工艺（手焊 0603 下限 vs 贴片 0402/QFN）。

## 门禁

- **D1 板框 / D2 安装孔 / D8 关键接口位置**未定 → 不得开工，触发 P0 强制中断等用户答复。
- 板框后续变更使 `outline_confirmed` 失效 → 重新向用户签核，再继续绘制。
- 配置文件属规划层工件，不写 EDA 图元；缺失项标「未定」而不填猜测值。

## 判据与动机

- 机械与外壳约束（P0）压倒美观与性能：先行确定才能让其余器件绕它布局。
- 配置文件是重复评审与返工成本的止损点：一次问清，避免中途反复推翻板框与接口。
- 与 [`../PCB设计规范/PCB设计规范.md`](../PCB设计规范/PCB设计规范.md) 配套：配置定「要什么」，规范定「怎么算合格」。
