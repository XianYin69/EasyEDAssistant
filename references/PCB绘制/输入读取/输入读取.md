# EasyEDAssistant Reference：PCB绘制 — 输入读取

> 本文件是「PCB绘制」第 1 步的分支细则（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 读取方案文件与图纸

1. **方案文件**：读取工作区方案文件与四份图纸——[`../../系统框图/系统框图.md`](../../系统框图/系统框图.md)、[`../../元件关系图/元件关系图.md`](../../元件关系图/元件关系图.md)、[`../../元件连接图/元件连接图.md`](../../元件连接图/元件连接图.md)、[`../../引脚索引/引脚索引.md`](../../引脚索引/引脚索引.md)。
2. **原理图侧现状**：回读 `pcb board-info`（SCH/PCB 绑定前提）、`sch connectivity --all-pages`（pin→net 真值）与 `pcb nets`（网络全集），作为 PCB 侧对账基准。
3. **前置阶段结论**：沿用原理图制作的门禁与对账结果；若原理图已变更，先完成 `import-changes` 再读取。

## 读取下载的技术手册与封装数据

1. **手册**：读取 `./tmp/datasheet/` 摘要与 `./tmp/downloads/` 原始手册；引脚名与电气类型以 [`../../元件检查/封装与引脚检查/封装与引脚检查.md`](../../元件检查/封装与引脚检查/封装与引脚检查.md) 登记的「元件 ↔ 手册」归属为准（含 URL、版本、页码）。
2. **封装与焊盘**：用 `pcb list --include-bbox --include-pads` 回读封装、焊盘编号与真实铜宽；封装型号须与手册封装图一致（不一致回元件检查流程处理）。
3. **特殊件确认**：天线/RF 模块、晶振、功率电感的 keepout 尺寸按手册取值，不套默认值。

## 读取 PCB 设计规范

1. **本地规范**：读 [`../PCB设计规范/PCB设计规范.md`](../PCB设计规范/PCB设计规范.md) 取得板框、叠层、线宽、间距、铺铜、丝印与 DFM 判据索引。
2. **规范正本**：`references/lib/pcb-design-spec.md`（必答清单）、`pcb-design-rules.md`（设计规则）、`fab-rules-jlcpcb.json`（板厂能力基线）。
3. **参数真值**：命令参数以 `easyeda <command> --help` 与 `easyeda actions` 为准；未知接口先 `easyeda api search <query>`；**指令条目索引**（有什么命令、去哪一步用）见 [`../../嘉立创EDA指令索引/PCB指令/PCB指令.md`](../../嘉立创EDA指令索引/PCB指令/PCB指令.md)。

## 判据与动机

- 先读后画：不凭记忆补封装或补网络，回读数据与手册是唯一真值来源。
- 规范冲突按「手册 > 协议 > 认证 > 通例 > 板厂」裁决，硬门不得放宽。
- 输入未齐不动笔：缺手册或缺封装数据时先回上游补齐，避免带错封装进板。
- 单位与坐标语义（PCB 锚点 vs bbox 中心、旋转与 center 不同调用）见 [`../../坐标与数据模型/坐标与数据模型.md`](../../坐标与数据模型/坐标与数据模型.md)。
