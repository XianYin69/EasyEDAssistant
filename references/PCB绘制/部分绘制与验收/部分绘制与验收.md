> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 绘制（逐部分）

1. **技术细节拍板**：叠层、接地、电源轨、接口朝向等按 [`../用户PCB配置文件/用户PCB配置文件.md`](../用户PCB配置文件/用户PCB配置文件.md) 与用户确认；**落位一律按已拍板的独立布局图 `./tmp/design/<工程>-pcb-layout.md`（字符画，绘制前已再次向用户询问布局并拍板，见 [`../PCB布局图/PCB布局图.md`](../PCB布局图/PCB布局图.md)）执行**，不得拿原理图 `-sch-layout.md` 当代替；**画前坐标校正已完成**（见 [`../../坐标与数据模型/坐标与数据模型.md`](../../坐标与数据模型/坐标与数据模型.md)「画前坐标校正」），临时标尺已移除、`./tmp/design/<工程>-calib-pcb.json` 已留痕，发现原点/网格错位先回 3.5 步重校再画。
2. **同步与放置（逐件核验）**：`pcb import-changes` 同步器件与网表（差异超预期 = before/after 出现新增/消失网络或器件数与原理图回读不符 → 触发 P1 中断点）；按四档顺序 T1 安装孔 → T2 板边接口 → T3 主芯片 → T4 卫星件放置。
   - **截图硬门**：每放置/移动/修改一个器件必须**当次**运行 `python <SKILL_DIR>/scripts/visual-qa.py --pcb --project <工程> --pcb-doc <PCB页> --artifacts-dir ./tmp/snapshots`（截图 + 重叠/出框/drc 数据核验，stale 自动切前台重试）。
   - **通过判据**：**退出码 0 且本次落位产出新的 `pcb-` 截图产物**——两者缺一即**该件未完成，禁止落位下一个**；禁止整批落位后统一补截。
   - **失败处置**：exit 3 当场回移/修正后重跑；同一件重试 ≤2 次仍失败 → 命中中断点暂停并如实报告。
    - **档位与阶段记录**：`pcb stage confirm-tier` 记录档位、`confirm-layout` 签核布局；阶段推进以 `easyeda workflow status/advance` 为准，未确认时路由命令被 CLI 拒绝，不得 `--force` 绕过。
    - **布局同步回写**：实际落位偏离蓝图时，先在 `./tmp/design/<工程>-pcb-layout.md`「变更记录」追加新节（只增不改）并经用户认可后再动板；原理图布局文件 `<工程>-sch-layout.md` 归原理图侧独立维护，**禁止两边互相覆盖或合并成一份**。
3. **布线与铺铜（方法正本 [`../干涉布线/干涉布线.md`](../干涉布线/干涉布线.md)）**：网络标签-端口 + 向量-节点 + 干涉演算 + 硬编码档位——`route-critical` → `route-short`（障碍感知）→ 剩余长网逐段 `route-check.py` 演算通过后 `pcb track`/`via-hop` 落笔；创建 track/via/pour 逐笔验证 primitive；**迷宫自动布线（autoroute/export-dsn/import-autoroute）已弃用禁调用**；铺铜按「先铺后翻 PLANE 再 rebuild」顺序；`doc reload` 后须重跑 `pcb via-bond` 再判。
4. **丝印标注（ [`../丝印标注/丝印标注.md`](../丝印标注/丝印标注.md)）**：布线终检后落用户三类丝印——板型号、版权、功能指引（内容逐字来自用户，逐条回读 + 截图核对）。
5. **每步对账**：回读 `pcb list --include-pads`、`pcb net-classes`、`pcb report` 核对焊盘网络与铜长，再做下一步；命令条目见 [`../../嘉立创EDA指令索引/PCB指令/PCB指令.md`](../../嘉立创EDA指令索引/PCB指令/PCB指令.md)。

## 截图与清理

1. **验证图（逐件）**：逐件核验由 `visual-qa.py --pcb` 内部采集 `pcb snapshot`（`--previous-sha256` 检 stale，canvas-freeze 自动 `doc switch` 切前台重试 ≤2 次）；脚本自动盖 `pcb-` 前缀落 `./tmp/snapshots/`、滚动删到最近 3 张（与原理图分开计数，废帧即时删除，**Agent 无需手动清理**）；「未产出新图」判阻断，验证图只作纠错不作交付。
2. **归档图（逐部分）**：一个部分完成后截局部图与整板全图（均须 fresh），立即归档 `./tmp/pcb/`（命名 `pcb-<部件号>-<局部|全图>-<时间戳>.png`），作交付候选，不随快照清理删除；验收与交付一律读归档图。

## 检查美观与正确（截图 + 命令行双通道纠错）

1. **数据层（命令行）**：**一条 `python <SKILL_DIR>/scripts/pcb-gate.py --project <工程> --pcb-doc <页>` 跑完** `pcb drc --json`、`pcb check --strict`、`pcb layout-lint`、`pcb layout-score`、`pcb report`、`pcb net-classes` 并聚合 JSON 落 `./tmp/pcb/`（退出码 0 全过 / 3 阻断；硬门短路/重叠/出框一票否决）；需装配硬门时加 `--with-gate`（落 `pre_route_passed`）。
2. **呈现层（截图）**：先看 `./tmp/pcb/` 归档图（丝印是否压件或反向、位号是否可读、朝向是否一致、整板是否留白失衡——留白/均衡对照 `pcb layout-score` 的利用率与 tidy 维输出，WARN 记入报告交用户判，不单方升级为硬门），再跑 `python <SKILL_DIR>/scripts/visual-qa.py --pcb --project <工程> --pcb-doc <PCB页>`（退出码 0 通过 / 2 WARN / 3 阻断）自动评估；数据层结论始终为权威。
3. **双通道互验**：命令行与截图**都过** → 检查全部是否绘制完成；任一发现错误 → 回到「绘制（逐部分）」修改后重画重截、重跑命令行检查。**同一部分互验反复最多 3 轮**；满 3 轮仍不过即停止自动重试，按 [`../../处理设计问题/处理设计问题.md`](../../处理设计问题/处理设计问题.md) 摊牌。

## 全部完成与用户验收

1. **全部完成判定**：未完成 → 绘制下一部分并回到「绘制（逐部分）」；已完成 → 询问用户是否接受。
2. **用户接受** → 核对 `./tmp/pcb/` 归档图片齐全（每部分局部 + 整板全图，供技术文档插图），`pcb save` 确认 `saved:true`，按需导出制造文件。
3. **用户不接受** → 询问用户具体修改处（哪一块板区/哪个器件/哪条走线），记录后回到「绘制（逐部分）」修改。
4. **重跑检查**：任何修改后旧的门禁与对账结论失效，须重跑 `pcb drc` / `pcb check` / `layout-lint` 再回到验收。

## 判据与动机

- 放置期纠错**逐件**（与原理图一致）：每放/移/改一个器件必过截图 + 数据双检；`stage confirm-tier` 只签档位汇总不替代逐件核验；布线/铺铜图元仍逐笔验证、截图按部分归档。
- 绘制期纠错走双通道：命令行（数据层，权威）+ 截图（呈现层，stale 重取至 fresh）；`layout-score` 是质量表不是硬门，skipped/degraded 维「没测 ≠ 满分」。
- 每部分归档图存 `./tmp/pcb/` 不随快照清理——交付时作为技术手册插图来源。
- 未保存的改动不得当作已交付；未通过检查不得导出制造文件。
