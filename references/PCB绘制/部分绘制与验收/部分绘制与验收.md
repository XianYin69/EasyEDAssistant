# EasyEDAssistant Reference：PCB绘制 — 部分绘制与验收

> 本文件是「PCB绘制」第 3～8 步的分支细则（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 绘制（逐部分）

1. **技术细节拍板**：叠层、接地、电源轨、接口朝向等按 [`../用户PCB配置文件/用户PCB配置文件.md`](../用户PCB配置文件/用户PCB配置文件.md) 与用户确认；可先摊布局蓝图 `./tmp/plan/<工程>-pcb-layout.md` 评审。
2. **同步与放置（逐件核验）**：`pcb import-changes` 同步器件与网表（差异超预期触发 P1 中断点）；按四档顺序 T1 安装孔 → T2 板边接口 → T3 主芯片 → T4 卫星件放置，用 `pcb stage confirm-tier` 记录、`confirm-layout` 签核；**每放置/移动/修改一个器件即跑 `python3 scripts/visual-qa.py --pcb --pcb-doc <PCB页> --artifacts-dir ./tmp/snapshots`**（截图 + 重叠/出框/drc 数据核验，stale 自动切前台重试），**exit 0 才画下一个**，exit 3 当场回移/修正后重跑。
3. **布线与铺铜**：创建 track/via/pour 逐笔验证 primitive；铺铜按「先铺后翻 PLANE 再 rebuild」顺序；`doc reload` 后须重跑 `pcb via-bond` 再判。
4. **每步对账**：回读 `pcb list --include-pads`、`pcb net-classes`、`pcb report` 核对焊盘网络与铜长，再做下一步；命令条目见 [`../../嘉立创EDA指令索引/PCB指令/PCB指令.md`](../../嘉立创EDA指令索引/PCB指令/PCB指令.md)。

## 截图与清理

1. **验证图（逐件）**：逐件核验由 `visual-qa.py --pcb` 内部采集 `pcb snapshot`（`--previous-sha256` 检 stale，canvas-freeze 自动 `doc switch` 切前台重试 ≤2 次）；脚本自动盖 `pcb-` 前缀落 `./tmp/snapshots/`、滚动删到最近 3 张（与原理图分开计数，废帧即时删除，**Agent 无需手动清理**）；「未产出新图」判阻断，验证图只作纠错不作交付。
2. **归档图（逐部分）**：一个部分完成后截局部图与整板全图（均须 fresh），立即归档 `./tmp/pcb/`（命名 `pcb-<部件号>-<局部|全图>-<时间戳>.png`），作交付候选，不随快照清理删除；验收与交付一律读归档图。

## 检查美观与正确（截图 + 命令行双通道纠错）

1. **数据层（命令行）**：`layout-lint --gate`（落 `pre_route_passed`）、`pcb drc --json`、`pcb check`（DFM）、`pcb layout-score`（九维诊断）；硬门短路/重叠/出框一票否决。
2. **呈现层（截图）**：先看 `./tmp/pcb/` 归档图（丝印是否压件或反向、位号是否可读、朝向是否一致、整板是否留白失衡），再跑 `python3 scripts/visual-qa.py --pcb`（退出码 0 通过 / 2 WARN / 3 阻断）自动评估；数据层结论始终为权威。
3. **双通道互验**：命令行与截图**都过** → 检查全部是否绘制完成；任一发现错误 → 回到「绘制（逐部分）」修改后重画重截、重跑命令行检查。

## 全部完成与用户验收

1. **全部完成判定**：未完成 → 绘制下一部分并回到「绘制（逐部分）」；已完成 → 询问用户是否接受。
2. **用户接受** → 核对 `./tmp/pcb/` 归档图片齐全（每部分局部 + 整板全图，供技术文档插图），`pcb save` 确认 `saved:true`，按需导出制造文件。
3. **用户不接受** → 询问用户具体修改处（哪一块板区/哪个器件/哪条走线），记录后回到「绘制（逐部分）」修改。
4. **重跑检查**：任何修改后旧的门禁与对账结论失效，须重跑 `pcb drc` / `pcb check` / `layout-lint` 再回到验收。

## 判据与动机

- 放置期纠错**逐件**（与原理图一致）：每放/移/改一个器件必过截图 + 数据双检；`stage confirm-tier` 只签档位汇总不替代逐件核验；布线/铺铜图元仍逐笔验证、截图按部分归档。
- 绘制期纠错走双通道：命令行（数据层，权威）+ 截图（呈现层，stale 重取至 fresh）；`layout-score` 是质量表不是硬门，skipped/degraded 维「没测 ≠ 满分」。
- 每部分归档图存 `./tmp/pcb/` 不随快照清理——交付时作为技术手册插图来源。
- 未保存的改动不得当作已交付；未通过检查不得导出制造文件。
