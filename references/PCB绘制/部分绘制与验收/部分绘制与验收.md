# EasyEDAssistant Reference：PCB绘制 — 部分绘制与验收

> 本文件是「PCB绘制」第 3～8 步的分支细则（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 绘制（逐部分）

1. **技术细节拍板**：叠层、接地、电源轨、接口朝向等按 [`../用户PCB配置文件/用户PCB配置文件.md`](../用户PCB配置文件/用户PCB配置文件.md) 与用户确认；可先摊布局蓝图 `./tmp/plan/<工程>-pcb-layout.md` 评审。
2. **同步与放置**：`pcb import-changes` 从原理图同步器件与网表（差异超预期触发 P1 中断点）；按四档顺序 T1 安装孔 → T2 板边接口 → T3 主芯片 → T4 卫星件放置，用 `pcb stage confirm-tier` 记录、`confirm-layout` 签核。
3. **布线与铺铜**：创建 track/via/pour 逐笔验证 primitive；铺铜按「先铺后翻 PLANE 再 rebuild」顺序；`doc reload` 后须重跑 `pcb via-bond` 再判。
4. **每步对账**：回读 `pcb list --include-pads`、`pcb net-classes`、`pcb report` 核对焊盘网络与铜长，再做下一步。

## 截图与清理

1. **逐个部分两张图**：一个部分绘制完成后分别截取局部图与整板全图（`pcb snapshot`）；与上帧比对 `--previous-sha256` 标记 fresh/stale，stale 切前台重取。
2. **次数判定**：统计 `./tmp/snapshots/` 中 PCB 截图次数；大于 3 次 → 丢弃三次前截取的截图（保留最近 3 张），否则保留现有截图。
3. **命名**：截图存 `./tmp/snapshots/step-<索引>-<时间戳>.png`。

## 检查美观与正确

1. **数据层**：`layout-lint --gate`（落 `pre_route_passed`）、`pcb drc --json`、`pcb check`（DFM）、`pcb layout-score`（九维诊断）；硬门短路/重叠/出框一票否决。
2. **呈现层**：看丝印是否压件或反向、位号是否可读、朝向是否一致、整板是否留白失衡。
3. **判定**：正确且美观 → 检查全部是否绘制完成；否则 → 回到「绘制（逐部分）」修改后重画重截。

## 全部完成与用户验收

1. **全部完成判定**：未完成 → 绘制下一部分并回到「绘制（逐部分）」；已完成 → 询问用户是否接受。
2. **用户接受** → 保存 PCB 的全部与各部分的局部截图，`pcb save` 确认 `saved:true`，按需导出制造文件。
3. **用户不接受** → 询问用户具体修改处（哪一块板区/哪个器件/哪条走线），记录后回到「绘制（逐部分）」修改。
4. **重跑检查**：任何修改后旧的门禁与对账结论失效，须重跑 `pcb drc` / `pcb check` / `layout-lint` 再回到验收。

## 判据与动机

- 数据是权威、截图只做视觉终检；`layout-score` 是质量表不是硬门，skipped/degraded 维「没测 ≠ 满分」。
- 未保存的改动不得当作已交付；未通过检查不得导出制造文件。
