> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言；分支细则见子文件。

## 流程

1. **读取方案文件、下载的技术手册与 PCB 设计规范**（见 [`输入读取/输入读取.md`](输入读取/输入读取.md)、[`PCB设计规范/PCB设计规范.md`](PCB设计规范/PCB设计规范.md)）：方案与图纸、器件手册与封装、板级规范判据。
2. **生成用户 PCB 配置文件**（见 [`用户PCB配置文件/用户PCB配置文件.md`](用户PCB配置文件/用户PCB配置文件.md)）：按必答清单与用户逐项核对并落盘，作为设计基线；关键项未定不得开工。
3. **再次向用户询问布局并生成 PCB 字符画布局图**（见 [`PCB布局图/PCB布局图.md`](PCB布局图/PCB布局图.md)）：叠层与铜厚、电源轨与接地、阻抗与接口朝向、丝印与拼板等会改变做法的选项须用户拍板后再画；**绘制前必须生成独立布局文件 `./tmp/design/<工程>-pcb-layout.md`（字符画板框+分区+器件位，禁止复用/照抄原理图 `<工程>-sch-layout.md`）并再次向用户询问布局，拿到「按图开工」拍板前禁止进入第 4 步**。
3.5. **画前坐标校正**（见 [`../坐标与数据模型/坐标与数据模型.md`](../坐标与数据模型/坐标与数据模型.md)「画前坐标校正」）：正式放置前用数字+直线在 PCB 页画临时坐标标尺，核板框原点（mil，y-UP）、网格锚（SMD 25/通孔 50 mil 子栅）、板边露铜边距；字符画布局图（`./tmp/design/<工程>-pcb-layout.md`）同步带刻度边框核比例尺。核对通过后据标尺落位，**第 4 步正式绘制开始前移除全部坐标标尺**（`pcb prim-delete` 临时图元、字符画删刻度行/列），校正数据落 `./tmp/design/<工程>-calib-pcb.json` 留痕。
4. **绘制部分 PCB**（见 [`部分绘制与验收/部分绘制与验收.md`](部分绘制与验收/部分绘制与验收.md)）：按模块与四档顺序逐部分绘制；**布线一律走 [`干涉布线/干涉布线.md`](干涉布线/干涉布线.md)（网络标签-端口 + 向量-节点 + 干涉演算 + 硬编码档位；上游迷宫自动布线已弃用禁调用）**；**截图硬门**——每放置/移动/修改一个器件必须**当次**运行 `visual-qa.py --pcb` 产出截图（`pcb-` 前缀）且 `exit 0`；**本次落位无新截图产物 = 该件未完成 = 禁止落位下一个**，禁止整批落位后统一补截；每步回读对账。丝印（板型号/版权/功能指引）见 [`丝印标注/丝印标注.md`](丝印标注/丝印标注.md)，在布线终检后执行。
5. **逐件验证图与逐部分归档**：逐件核验的截图落 `./tmp/snapshots/`（滚动 3 张，只作纠错）；每个部分完成后局部图 + 全图归档 `./tmp/pcb/`（stale 重取至 fresh，交付图片候选，不随快照清理）。
6. **检查 PCB 是否美观和正确（截图 + 命令行双通道）**（同子文件）：数据层门禁与呈现层（归档图 + `visual-qa.py`）任一发现错误 → 回到第 4 步重画该部分。
7. **检查全部 PCB 是否绘制完成**：未完成 → 绘制下一部分并回到第 4 步；已完成 → 进入第 8 步。
8. **询问用户是否接受 PCB**（同子文件）：接受 → 核对 `./tmp/pcb/` 归档图片齐全（供技术文档插图）并 `pcb save` 确认 `saved:true`；不接受 → 询问用户修改处后回到第 4 步。

## 判据与动机

- 先读后画：板框、封装、焊盘与网络一律来自配置基线或回读，不凭记忆补封装、补网络。
- 放置期纠错**逐件**（与原理图一致）：每放/移/改一个器件必过截图 + 数据双检；`stage confirm-tier` 只签档位汇总，不替代逐件核验。命令行（`pcb drc` / `pcb check` / 回读）权威，截图呈现层终检，stale 不得判 fresh。
- 用户接受前不保存为交付基线；修改处未明确时不擅自改板。
- **截图是硬门不是建议**：无当次截图产物即该件未完成（见 [`../约束部分/步骤门禁/步骤门禁.md`](../约束部分/步骤门禁/步骤门禁.md) 第 4 条）；`visual-qa.py` 重试 ≤2 次仍失败 → 命中中断点，不得跳过继续画。
- **阶段推进走机器门禁**：`easyeda workflow status/advance` 与 `pcb stage confirm-tier/confirm-layout/confirm-outline`；未确认时路由命令会被 CLI 拒绝，不得 `--force` 绕过。
