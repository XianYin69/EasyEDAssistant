# EasyEDAssistant Reference：PCB绘制 — 干涉布线

> 本文件是 PCB 布线执行方法的**正本**（自然语言）：**已弃用上游迷宫自动布线**
> （`pcb autoroute` / `pcb export-dsn` / `pcb import-autoroute` 的 Freerouting 路线），
> 改用「**网络标签-端口 + 向量-节点 + 干涉演算 + 硬编码档位**」布线法。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 禁令（先读这条）

1. Agent **禁止调用** `pcb autoroute`、`pcb export-dsn`、`pcb import-autoroute`（含一切外部迷宫引擎、push-shove、.ses 回灌）；用户点名要求时先复述本禁令并转 [`../用户PCB配置文件/用户PCB配置文件.md`](../用户PCB配置文件/用户PCB配置文件.md) 中断点由用户书面拍板。违规按 [`../../约束部分/处罚机制/处罚机制.md`](../../约束部分/处罚机制/处罚机制.md) L3。
2. `pcb route-short` / `pcb route-critical` 是**障碍感知的向量路由器**（per-net MST + L 形/45°、交叉最少化），非迷宫档，允许使用；「过长的跳线留给迷宫档」的上游惯例对本项目不适用——长网由第 4 步人工向量分解处理。

## 输入（节点与端口）

3. **端口 = 焊盘**：`pcb list --include-pads --include-bbox` 回读器件焊盘坐标与网络名；**网络标签驱动**：连不连、连到哪只认 connectivity 网络名（`pcb nets` / 原理图 `sch connectivity` 为真值源），不认视觉走向。track/via 落笔一律带 `--net <名>` 完成端口绑定。
4. **档位 = 硬编码规则**：线宽/间距按 [`../../电气检查/硬编码规则/PCB/间距与线宽.md`](../../电气检查/硬编码规则/PCB/间距与线宽.md) 档位表正本（R1b 用户已拍板档），`pcb net-classes` 回读核对；route-check 内置默认档与此同源。

## 执行顺序（每网逐段，先关键后普通）

5. **关键网先行**：`pcb route-critical`（电源铺铜→差分实测→锁定）；差分/等长组用 `diff-pair`/`eq-group` 约束。
6. **短净空跳线批量**：`pcb route-short`（默认跳电源/地；电源走铺铜 `power-pour`/`pour` 不走细线）；跑前确认 `layout-lint` 交叉预期。
7. **剩余长网人工向量分解**：Agent 每段自己构造「起-终」两点向量（mil, y-up，`grid-snap` 落格），45°/90° 规整；跨层用 `via-hop`（换层两侧配套地孔，档位在用户配置 R2 内）；**每段落笔前必过第 8 步演算**。
8. **干涉演算（落笔门）**：`python <SKILL_DIR>/scripts/route-check.py --project <工程> --net <名> --x1.. --y1.. --x2.. --y2.. [--layer --width --role]`——对异网 track/via/焊盘/keepout region/板边 keep-in 做几何距离判定（判据＝第 4 条档位）；exit 0 才准 `pcb track` 落笔；exit 1 → 改向量/绕距/换层后**复检**；exit 3（回读失败）＝演算未成立，**禁止凭感觉落笔**，先修数据面。
9. **落笔后逐笔验证**：`pcb track-list`/`via-list` 回读 primitive 存在且 net 绑定正确；改动重置 `post_route_checked`。

## 让位与终检

10. 障碍无解时按序尝试：绕距 → 经批准换层（via-hop）→ `rip-up --net <障碍网>` 局部让位（被撕网重走第 5–9 步）→ 仍死结即命中中断点摊牌（布局缺陷回改放置，不开迷宫）。
11. **终检不变**：`pcb-gate.py`（drc/check/lint/score 聚合）+ 部分级 `pcb-` 归档截图 + `via-bond` reload 重跑纪律，全过才算布线完成；`pcb beautify` 只作收尾且先 dry-run。

## 判据与动机

- 迷宫自动布线产生不可解释、不可逐笔纠错的铜皮结果，与本项目「每笔可回读、每错可归因到段」的逐步执行门禁相悖——弃用。
- 人工向量 + route-check 演算把每一段的正确性前移到落笔前（drc 是事后判官，演算是事前判官）；两者都不得省略。
