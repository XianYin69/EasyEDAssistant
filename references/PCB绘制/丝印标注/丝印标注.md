# EasyEDAssistant Reference：PCB绘制 — 丝印标注

> 本文件是 PCB 丝印标注子步骤的正本（自然语言）：支持**用户添加板子型号丝印、版权丝印、功能指引丝印**。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。布线终检（`pcb-gate`）通过、`pcb beautify` 之后执行；
> 全部落笔遵守 [`../干涉布线/干涉布线.md`](../干涉布线/干涉布线.md) 同源的「每笔回读 + 截图硬门」纪律（丝印图元同样逐笔验证）。

## 三类用户丝印（内容一律来自用户提供，禁止 Agent 代拟）

1. **板子型号丝印**：型号/版本/日期码/序列号区/厂商标识（板角必含项，判据见 [`../../电气检查/硬编码规则/PCB/阻焊丝印与拼板.md`](../../电气检查/硬编码规则/PCB/阻焊丝印与拼板.md)）。向用户收集：型号字符串、版本号、标识位置（默认板角）。
2. **版权丝印**：版权声明行（如 `© <年份> <持有者>`）与可选 logo。**文字与授权由用户逐字提供**，Agent 不得自行拟写版权/商标内容；logo 走 `pcb silk-import-svg`（SVG 由用户提供）。
3. **功能指引丝印**：功能分区框与指引文字（电源区/RF 区/接口标识、按键/指示灯注解、下载口方向箭头等），帮助用户装配与使用。

## 执行序列

4. **收集与拍板（中断点）**：一次向用户摊三份清单——每条丝印的 **文字、字号、落位（区域或坐标）、层（顶/底/内外丝）**；用户没给的字段不猜、不留空默认，缺项回到本步补问。
5. **分区框先行**：`pcb silk-zone-outline` 按方案功能分区绘分组正交框；框内指引用 `pcb silk-add` 落文字；网络名注记用 `pcb silk-netnames`（区域限定），引脚功能注记用 `pcb silk-label-pads`（配合位号档）。
6. **逐条落位**：每条型号/版权/指引文字用 `pcb silk-add`（含 layer、字号、角度配置），落一条回读一条（silk 图元在 `pcb dump`/回读可见）；已落丝印调整用 `pcb silk-set`，位号整板收口用 `pcb silk-align`（碰撞避让）。
7. **合规自检（每条落位后）**：字号 ≥25 mil（极性 ≥40）、线宽 ≥5 mil、不上焊盘/过孔、距焊盘 ≥4 mil、不与器件外形框重叠（≥0.2 mm）、避开连接器/金手指接触面——与 [`../部分绘制与验收/部分绘制与验收.md`](../部分绘制与验收/部分绘制与验收.md) 呈现层互验一致：跑 `python <SKILL_DIR>/scripts/visual-qa.py --pcb --project <工程> --pcb-doc <页>` 截图核对 + `pcb check`。
8. **用户确认**：逐条截图摊给用户核对文字（错字/版权行逐字对）；不接受 → 回第 4 步改收集再落位。**丝印全部确认后**才做全板归档截图与 `pcb save`（并入部分绘制与验收的验收步）。

## 判据与动机

- 丝印是板上唯一直接给人读的内容：文字错误＝交付缺陷，所以内容只来自用户、逐条回读、逐条截图。
- 版权/商标内容属授权信息，Agent 代拟有法律风险，一律中断收集。
- 分区框与网络注记复用既有 CLI 能力（`silk-zone-outline`/`silk-netnames`/`silk-label-pads`/`silk-add`/`silk-import-svg`/`silk-set`/`silk-align`），不引入新工具链。
