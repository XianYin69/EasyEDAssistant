# EasyEDAssistant Reference：元件关系图

> 本文件收录「检查方案及敲定」中绘制元件/组件/部分/整体关系图的流程（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 流程

1. **取输入**：读取元件检查通过后的元件清单（位号、MPN、封装）与系统框图的模块划分。
2. **分层归属**：按「整体 → 部分 → 组件 → 元件」建立层级，例如「整板 → 电源部分 → DC-DC 组件 → U1 / L1 / C1」；每部分标注功能与对应的系统框图模块。
3. **绘制字符画关系图**：用嵌套框或树形字符画表达归属层级，元件行标位号与 MPN，部分行标功能名。
4. **数量对账**：关系图必须覆盖元件清单中全部元件，逐个核对无遗漏、无重复归属。
5. **与用户确认**：关系图摊给用户检查确认；确认后进入元件连接图。

## 字符画示例（示意）

```text
整板
├─ 电源部分            [电源]
│  ├─ DC-DC 组件
│  │  ├─ U1  IC1  同步降压
│  │  ├─ L1  4.7µH
│  │  └─ C1/C2  10µF
│  └─ 保护组件
│     └─ D1  TVS
└─ 主控部分            [数字/控制]
   ├─ U2  MCU
   └─ Y1  16MHz
├─ 树形层级   [方框]=系统框图模块归属
```

## 落盘工件

- 关系图落 `./tmp/design/<工程名>-part-tree.md`；与元件清单逐项对账的记录一并保留。

## 判据与动机

- 归属关系是 BOM 组织与原理图分页、模块框划分的依据，必须先定后画。
- 一个元件只允许归属一个部分，避免同一器件在不同分页重复出现。
- 覆盖不全或归属冲突即回退澄清，不静默带入后续检查。
