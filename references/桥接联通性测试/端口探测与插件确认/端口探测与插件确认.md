# EasyEDAssistant Reference：桥接联通性测试 — 端口探测与插件确认

> 本文件是「桥接联通性测试」第 2～3 步的分支细则（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 步骤

> **脚本化执行（首选）**：第 1、2 步由 `python <SKILL_DIR>/scripts/link-probe.py` 完成（TCP 探活 + 选定链路，
> 结果 `./tmp/init/link-probe.json`）；脚本只报「通/不通」，第 3 步插件安装与 EDA 打开确认仍须问用户。

1. **探测 MCP 端点**：访问 `http://127.0.0.1:7655/mcp`；可选一并看桥接端点 `ws://127.0.0.1:8765/bridge/ws`。可达后再探测 `60832` 以定优先级（正本：`references/lib/connection-setup.md` §1.1）。
2. **探测 Agent 端口**：MCP 可达且 `60832` 也连通 → 优先全程使用 CLI/daemon（批量写少往返）；仅 MCP 连通 → 全程使用 MCP；MCP 不可达时探测 `60832`（daemon），可达即选定 CLI/daemon 链路。两条都不可达则进入排查。
3. **询问用户排查**（两问，按顺序）：
   - 「是否已在嘉立创 EDA 及 Agent 工具中安装这两个插件？」——是则等待 10s 后回到第 1 步重试。
   - 否则「是否已打开嘉立创 EDA？」——是则等待 10s 后回到第 1 步重试。
4. **提示安装**：两问均为否时，提示用户安装嘉立创 EDA 及 JLCEDA MCP 插件、EasyEDA Agent 插件，等待用户确认后回到第 1 步。
5. **重试额度**：上述「等待 10s 后回到第 1 步」共用同一次 3 轮额度（正本见 [`../桥接联通性测试.md`](../桥接联通性测试.md) 第 5 步）；额度用尽即停止自动重试并转用户摊牌，不无限重探。

## 排查纪律（源自 §1.3）

- daemon 未启动：检查安装路径与启动日志，用 `easyeda daemon start --auto-update-skill=false`（监听 60832；**必须带该参数**，否则 daemon 默认 on 会静默覆写已安装 skill 目录，违反运行环境不可变）。
- daemon 正常但窗口列表为空：检查编辑器、登录态、扩展是否启用、是否允许外部交互。
- 同目标页出现多版本 windowId 或写请求超时：先回读确认最后一条写是否落地，再检查扩展管理器只保留所选渠道的连接器。

## 判据与动机

- 两条链路互斥替代，一旦选定全程使用；重复探测会制造误判与额外副作用。
- 等待 10s 是给插件与编辑器完成注册的时间窗，不是重试节流手段；期间不写盘。
- 用户未确认安装或未打开 EDA 时不自作主张重启服务或更换链路。
