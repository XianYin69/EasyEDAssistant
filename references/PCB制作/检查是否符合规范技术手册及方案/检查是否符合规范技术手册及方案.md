# EasyEDAssistant Reference：PCB制作 — 检查是否符合规范、技术手册及方案

> 本文件是「PCB制作」第 3 步的分支细则（自然语言），与原理图侧 [`../../原理图制作/检查是否符合技术手册及方案/检查是否符合技术手册及方案.md`](../../原理图制作/检查是否符合技术手册及方案/检查是否符合技术手册及方案.md) 对称。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 检查项

1. **网表与原理图一致**：`pcb import-changes` 的 before/after 计数与回读对账——新增/消失网络数为 0、PCB 器件数与 `sch connectivity --all-pages` 及 [`../../引脚索引/引脚索引.md`](../../引脚索引/引脚索引.md) 黄金表一致；任一差值非 0 即「超预期」，触发 P1 中断点，不自行取舍。
2. **封装与手册一致**：`pcb list --include-bbox --include-pads` 回读的封装型号、焊盘数与间距，逐项对照 [`../../元件检查/封装与引脚检查/封装与引脚检查.md`](../../元件检查/封装与引脚检查/封装与引脚检查.md) 登记的「元件 ↔ 手册」归属（`./tmp/datasheet/` 摘要与页码出处）；不符回元件检查流程处理，不就地改封装。
3. **规范硬门**：**一条 `python scripts/pcb-gate.py --project <工程> --pcb-doc <页> --with-gate` 跑完**：`pcb drc --json` 违例为 0（或有已登记豁免）；`pcb check` DFM 审计无阻断项；`pcb layout-lint --gate` 落 `pre_route_passed`；`pcb layout-score` 九维逐维记录，skipped/degraded 维按「没测 ≠ 满分」单列；聚合 JSON 落 `./tmp/pcb/`，退出码 0 才算本项过。
4. **约束与设计基线一致**：`pcb net-classes` 与 `pcb drc-rules` 的 live 线宽/间距阶梯对照 [`../../PCB绘制/用户PCB配置文件/用户PCB配置文件.md`](../../PCB绘制/用户PCB配置文件/用户PCB配置文件.md)（D 项）与 [`../../PCB绘制/PCB设计规范/PCB设计规范.md`](../../PCB绘制/PCB设计规范/PCB设计规范.md) 引用的硬编码 PCB 判据；叠层以 `pcb stackup show` 与 `pcb layers` 回读对照基线。
5. **归档图齐全且 fresh**：`./tmp/pcb/` 每部分局部图 + 整板全图齐全（[`../../PCB绘制/部分绘制与验收/部分绘制与验收.md`](../../PCB绘制/部分绘制与验收/部分绘制与验收.md) 归档纪律）；呈现层结论用 `python scripts/visual-qa.py --pcb --project <工程> --pcb-doc <PCB页>` 复核。

## 判定与分支

- 五项全过 → 判定「符合」，进入总索引第 4 步保存交付。
- 任一项不符 → 判定「不符合」，回到 [`../../PCB绘制/PCB绘制.md`](../../PCB绘制/PCB绘制.md) 第 4 步修改，修改后**只重跑未通过项**及受其影响的项（旧结论一律失效）。
- 命令报错/环境异常 → 标 `blocked`，先修环境（回 [`../../桥接联通性测试/桥接联通性测试.md`](../../桥接联通性测试/桥接联通性测试.md)），不当作设计 fail。
- 检查结论与各门禁 JSON 落 `./tmp/pcb/`，登记入方案与交付报告。

## 判据与动机

- 数据回读为权威、截图为呈现层终检；两者冲突以回读为准并把 stale 标为阻断项。
- 未通过本检查不得进第 4 步导出制造文件：与原理图侧「先改对再落盘」同一纪律。
- 「0 fatal」聚合数不等于全部通过：INFO/WARN 与未运行维度须单列（[`../../lib/verification-delivery.md`](../../lib/verification-delivery.md) §8.1）。
