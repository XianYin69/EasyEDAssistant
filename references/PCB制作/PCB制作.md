# EasyEDAssistant Reference：PCB制作

> 本文件是「PCB制作」步骤的总索引（自然语言）；触发时机：电路设计标准设计流程第 5 步，原理图制作之后。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言；绘制细则见 [`../PCB绘制/PCB绘制.md`](../PCB绘制/PCB绘制.md)。

## 流程

1. **桥接连通性测试**（见 [`../桥接联通性测试/桥接联通性测试.md`](../桥接联通性测试/桥接联通性测试.md)）：确认链路可用并通过门禁；原理图制作阶段已通过则沿用结论，不重复探测。
2. **绘制 PCB**（见 [`../PCB绘制/PCB绘制.md`](../PCB绘制/PCB绘制.md)）：读取方案文件、下载的技术手册与 PCB 设计规范，先生成用户 PCB 配置文件，再逐部分绘制并截图，用户验收后保存。
3. **检查 PCB 是否符合规范、技术手册及方案**（见 [`检查是否符合规范技术手册及方案/检查是否符合规范技术手册及方案.md`](检查是否符合规范技术手册及方案/检查是否符合规范技术手册及方案.md)）：不符合 → 回到第 2 步修改后只重跑未通过项；符合 → 进入第 4 步。**本步「绘制↔对照检查」整步回退最多 3 轮**，满 3 轮仍不符合即停止自动回退，按 [`../处理设计问题/处理设计问题.md`](../处理设计问题/处理设计问题.md) 摊牌。
4. **保存交付**：验收步已 `pcb save` 且第 3 步无改动 → 回读确认 `saved:true` 未回退；第 3 步引起修改 → 重新 `pcb save` 确认 `saved:true`；制造文件（Gerber/坐标）经官方 GUI「制造输出」导出（程序化无入口，`bom export`/`pcb export-dsn` 仅覆盖 BOM 与 DSN，见 [`../嘉立创EDA指令索引/PCB指令/检查与导出/检查与导出.md`](../嘉立创EDA指令索引/PCB指令/检查与导出/检查与导出.md)）；导出 PCB 截图与说明文件，本步骤结束，随后进入 [`../交付与清理/交付与清理.md`](../交付与清理/交付与清理.md)。

## 判据与动机

- 原理图与 PCB 以 `pcb import-changes` 同步：PCB 侧改动不回写原理图，差异须显式对账。
- 门禁数值运行时正本在 Go 代码与 JLC 官网；文档数值冲突时以代码与官网为准并回改文档。
- 未通过检查不得导出制造文件；保存以 `saved:true` 为准，daemon 防抖自动保存只作兜底。
- **本步骤结束前记账**：`python <SKILL_DIR>/scripts/progress-log.py --step 5 --name PCB制作 --cmd "python <SKILL_DIR>/scripts/pcb-gate.py --project <工程>" --art ./tmp/pcb/gate-<时间>.json --result pass`；未记账或 `pcb-gate` 非 0 = 本步未完成，不得进入「交付与清理」。
