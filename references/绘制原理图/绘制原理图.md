# EasyEDAssistant Reference：绘制原理图

> 本文件是「绘制原理图」步骤的总索引（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言；分支细则见子文件。

## 流程

1. **读取方案文件和下载的技术手册**（见 [`输入读取/输入读取.md`](输入读取/输入读取.md)）：方案与图纸、器件手册、元件与手册归属记录。
2. **读取原理图绘制规则**（同子文件）：分区、间距、短桩档位、走线与线宽、命名、功能框与标题、去耦分级。
3. **询问用户原理图信息的填写和技术细节**：页数与模块拆分、位号与 net 命名、图纸信息栏；属设计决策，须用户拍板后再画。
4. **绘制部分原理图**（见 [`部分绘制与截图/部分绘制与截图.md`](部分绘制与截图/部分绘制与截图.md)）：按模块逐个绘制；**每落位一个器件即运行 `visual-qa.py --schematic` 截图 + 越界核验，通过才画下一个**，每步回读对账。
5. **逐个部分截图与归档**：绘制好一个部分后分别截取一张局部图和一张全图，立即归档到 `./tmp/sch/`（交付图片候选，不随快照清理）；`./tmp/snapshots/` 仅作最近 3 张滚动工作快照。
6. **检查原理图是否美观和正确（截图 + 命令行双通道）**（同子文件）：数据层门禁（`sch gate --strict` 等）与呈现层（归档截图 + `visual-qa.py`）任一发现错误 → 回到第 4 步重画该部分。
7. **检查全部原理图是否绘制完成**：未完成 → 绘制下一部分并回到第 4 步；已完成 → 进入第 8 步。
8. **询问用户是否接受原理图**（见 [`用户验收与保存/用户验收与保存.md`](用户验收与保存/用户验收与保存.md)）：接受 → 保存原理图（`sch save` 确认 `saved:true`）并确认 `./tmp/sch/` 归档图片齐备（全图 + 各部分局部图，供技术文档插图）；不接受 → 询问用户修改处后回到第 4 步。

## 判据与动机

- 先读后画：器件、引脚、连接一律来自回读或方案文件，不凭记忆补脚、补连接。
- 绘制期纠错走双通道：命令行（数据层，权威）+ 截图（呈现层），任一发现错误即回修；截图不替代门禁。
- 每部分截图即时归档 `./tmp/sch/`，交付期作为技术手册插图来源；快照目录只做滚动工作区。
- 用户接受前不保存为交付基线；修改处未明确时不擅自改图。
