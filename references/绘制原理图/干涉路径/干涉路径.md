# EasyEDAssistant Reference：绘制原理图 — 干涉路径

> 本文件是原理图走线（路径绘制）执行方法的**正本**（自然语言），与 PCB 侧
> [`../../PCB绘制/干涉布线/干涉布线.md`](../../PCB绘制/干涉布线/干涉布线.md) **同一套方法**：
> 「网络标签-端口 + 向量-节点 + 干涉演算 + 硬编码档位」；**禁用一切迷宫/盲画式自动走线**。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 禁令

1. **禁止盲画路径**：不得不经节点演算直接甩多点 `sch wire` 折线赌连通；上游若在 sch 域引入任何 autoroute/迷宫类命令，一律比照 PCB 三件套禁用（违规按 [`../../约束部分/处罚机制/处罚机制.md`](../../约束部分/处罚机制/处罚机制.md) L3）。
2. `sch autoconnect` 是**确定性 pin 感知规划器**（自选方向/短桩档位、`no safe candidate = 硬拒不落笔`、幂等），非迷宫档，允许并作为短桩连线首选；批量必须走 `--spec`。

## 四要素（与 PCB 干涉布线同构）

3. **网络标签-端口**：连接链 = pin →（短桩 wire）→ `netflag`/`netport` 端口；wire 的 net 由共线合并派生，**端口名即网络标签**，与连接图/引脚索引的黄金 pin→net 表逐条对账（`sch connectivity` 为真值源，跨页用 `sch nets` 审计同名多轨/单脚网）。
4. **向量-节点**：手改路径一律逐段两点向量（正交为主，`sch wire` 全水平或竖直）；节点只认：引脚桩末端、flag/port 端点、既有 wire 端点/交点；坐标落格（`坐标与数据模型.md` 栅格），起终点必须落在节点上，禁止悬空节点。
5. **干涉演算（画前推演 + 画后即查）**：画前——由引脚坐标+短桩档位离线推算每段路径（同 PCB 的落笔前判定思想；原理图无独立演算脚本，演算由 autoconnect 规划器与 Agent 的格子几何推演承担）；画后**立即**跑机器门：`sch bridge-check`（共线合并短路 bridges + 孤儿桩 orphans，wire-tree 粒度）+ `sch check`（叠加 marker；`connect` 不幂等，重发叠加必被兜住）+ `sch layout-lint`（bbox 重叠）+ 标题栏 keepout（`sheet-geometry`）；任一 fail → `prim-delete` 精删该段重推，**不得带错继续下一段**。
6. **硬编码档位**：短桩长度与线宽按 [`../输入读取/输入读取.md`](../输入读取/输入读取.md) 走线规则正本（power 朝上 20–40、ground 朝下 10–40、netport 朝外 20–60；线宽信号 1/电源 2/总线 3）；去耦贴邻与分区档同表。

## 执行顺序（逐模块，与逐件截图硬门叠加）

7. 先模块内 `sch block-apply`/`compose→apply` 保护队列（确定性离线编译，非迷宫）；再 `autoconnect --spec` 批量短桩（幂等）；剩余跨模块连接按第 4–5 条逐段人工向量：推演 → 落笔 → bridge-check/check 即查 → 回读 pin→net 对账。
8. 每批次后 `sch check` 兜叠加 marker（既有纪律不变）；模块收口跑 `sch gate --strict` 四联；**跨模块走线冲突解不开时**：改端口位置/重新分区（回布局档）或摊牌，**不开盲画模式**。

## 判据与动机

- 原理图的「干涉」表现为电气拓扑错误（共线短路、孤儿桩、marker 叠加），bridge-check/check 就是它的干涉演算判官；逐段落笔逐段判与 PCB 的 route-check 前置演算等价（画后即查 ≤ 画前算不出的部分由逐段回环兜底）。
- 与 PCB 同法的目的：一条可解释纪律覆盖两层——每段路径可归因、可精删、可复审。
