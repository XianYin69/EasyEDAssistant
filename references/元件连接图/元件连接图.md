# EasyEDAssistant Reference：元件连接图

> 本文件收录「检查方案及敲定」中绘制元件间连接图的流程（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 流程

1. **取连接真值**：已有工程时跑 `python <SKILL_DIR>/scripts/sch-verify.py --project <工程>`（内含 `sch connectivity --all-pages` 的 pin→net 真值），以 [`../元件检查`](../元件检查/元件检查.md) 后的连接回读为准；尚未绘制原理图时以方案连接表为准，并在图上标注「待原理图核对」。
2. **绘制字符画连接图**：元件为节点（标位号），连接为带 net 名的边；电源、地、信号分别用不同记号，跨模块的连接标为 netport 边界。
3. **一致性核对**：连接图须与系统框图、元件关系图一致；节点与 net 名互相可追溯，冲突时回到上游修正而非就地改图（**同一冲突上下游往返最多 3 次，满次转 [`../处理设计问题/处理设计问题.md`](../处理设计问题/处理设计问题.md) 摊牌，禁止三图互踢**）。
4. **与用户确认**：连接图摊给用户检查确认；确认后进入引脚索引。**用户要求修改则重绘后再确认；同一图「绘制↔确认」往返最多 3 轮，满轮转 [`../处理设计问题/处理设计问题.md`](../处理设计问题/处理设计问题.md) 摊牌**。

## 字符画示例（示意）

```text
+5V ──┬── IC1.VIN        MCU 侧
      │                  ╭──────────╮
     C1 10µF             │ U1       │
      │                  │  TX >>UART_TX
     ⏚ GND               │  RX >>UART_RX
                         ╰──────────╯
   P=电源桩  ⏚=地  >>=netport（跨模块边界）
```

## 落盘工件

- 连接图落 `./tmp/design/<工程名>-connection.md`；与回读数据同源，便于逐条对账。

## 判据与动机

- 不凭空补连接：连接真值来自 CLI 回读或方案连接表，不靠截图或记忆推断。
- net 命名即信道，连接图上的 net 名必须与后续原理图一致，否则对账失效。
- 标注「待原理图核对」的连接属未证实项，不得在后续检查中当作已通过。
