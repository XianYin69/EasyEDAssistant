# EasyEDAssistant Reference：模拟接地策略

> 硬编码判据，来源模拟系统设计通例。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 域划分

- 单点接地：高增益/精密模拟（< mV 级信号链）优先与数字地共面但分区，汇聚点设在电源入口地。
- 割地判据：≥ 2 个地域（数字地/模拟地）才谈拆分；拆分后用磁珠或 0 Ω 单点连接，连接点唯一，多点连接判不通过（形成地环）。
- 现代多层板优先「完整地 + 分区布局」而非物理割地；割地仅在 16 bit 以上高精度或强噪声数字共存时使用。
- 电源子域命名（VANA / VDIG / VGND 等）明确区分，禁止同网名混走两类地域。

## 地环路控制

- 两个接地点之间禁止形成闭合环路包围敏感模拟走线。
- 屏蔽层/连接器外壳地走独立低阻抗路径回机壳接地点，不与信号地串联菊花链。
- 差分信号参考地：接收端地偏移 > 信号共模裕量时判不通过，需改隔离或差分接收。

## 布局判据

- 敏感模拟区（基准、仪表放大器、传感器接口）远离噪声源：时钟线/开关管/变压器 ≥ 10× 线宽距离，或加地墙（≥ 每 λ/20 缝合孔的过孔排）。
- 模拟地铜上禁止数字回流穿越（检查：任意数字信号走线的参考地平面下有模拟器件区域则标记不通过）。
- 大电流地路径（电机、电池充放）与小信号地路径汇接于星点后不再分开。
