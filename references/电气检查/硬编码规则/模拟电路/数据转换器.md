# EasyEDAssistant Reference：数据转换器（ADC / DAC）

> 硬编码判据，来源高速/精密转换器设计通例（12 bit+ 与 > 1 MSPS 从严）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 模拟输入

- 驱动 RC 抗混叠/去 kickback：串阻 10~330 Ω + 就近小电容（值按手册采样模型计算）；无驱动源阻抗时禁止把采样电容直接挂长走线。
- 输入走线与任何时钟/开关走线不平行、不交叉；必须交叉时正交且距离 ≥ 2 mm。
- 差分输入对内等长（偏差 ≤ 5 mil）且对称布线，避免共模转差模。

## 基准

- 基准引脚独立走线到基准源输出电容（10 µF + 100 nF C0G 贴基准源）；禁止与信号链共用采样路径走线。
- 多颗 ADC 共基准：开尔文菊花链，不共享高电流段；基准走线全程地屏蔽（两侧包地）。

## 数字接口回流

- SDO/DCLK/CS 等数字脚的地回流必须返回转换器自身 GNDD 引脚（若有 AGND/GNDD 分脚）：模拟地、数字地在芯片内部/单点外接，跨地分割走线判不通过。
- 并行总线（旧式）长度 ≤ 2 inch 并串 22~33 Ω；SPI 时钟 ≤ 25 MHz 时可不端接，> 50 MHz 按数字高速规则处理。
- 采样敏感期（SAR 转换中 / ΣΔ 调制）：数字侧禁止安排高翻转率信号紧邻走线，串扰预算超 1 LSB 判不通过。

## 布局分区

- 转换器置于模拟/数字分区边界「桥」上，模拟侧进、数字侧出，数字走线立即外逃，不得穿越模拟区。
