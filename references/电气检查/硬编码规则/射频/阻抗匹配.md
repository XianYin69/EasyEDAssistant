# EasyEDAssistant Reference：射频阻抗匹配

> 硬编码判据，来源射频布局通例（IPC-2141 计算 + 厂商 App Note）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## RF 传输线

- 单端 50 Ω，差分 100 Ω（±10%），线宽/间距按 [`../PCB/叠层与阻抗控制.md`](../PCB/叠层与阻抗控制.md) 的叠层实算。
- RF 走线最短化、单层优先；必须换层时换层点两侧加 ≥ 2 个地过孔。
- 禁直角：用 45°、圆弧或切角；弯曲半径 ≥ 3× 线宽。
- RF 走线下方完整地、无分割、无其他走线穿越；两侧包地孔间距 ≤ λ/20（见 [`地缝合与屏蔽.md`](地缝合与屏蔽.md)）。
- 残桩控制：匹配支节（stub）超出焊盘 ≤ 0.2 mm，多余走线蚀刻去除（"短截线修剪"）。

## 匹配网络元件

- 全部用 C0G/NP0 电容、高 Q 电感（Q ≥ 20 @ 工作频率）、0201/0402 小封装；禁止 X7R/X5R 用于匹配。
- 元件摆放遵循「串联元件走直线、并联元件短腿下地」；π 型网络的并联电容下地过孔贴元件 ≤ 0.3 mm。
- 电容电压降额与自谐振：SRF ≥ 3× 工作频率，否则换更小容值多只或更高质量件。
- 预留调试位：默认 π 型（串 + 两并），量产可置 0 Ω/NC 灵活改 L 或 C 型；NC 位丝印标注。

## 检查项

1. RF 路径上有无跨越地分割、有无平行包地不足段。
2. 匹配元件旁是否有 NC 改件空间（调试可操作性）。
3. PA 输出到天线端口之间损耗预算是否按 0.1 dB/mm 级线损复核。
