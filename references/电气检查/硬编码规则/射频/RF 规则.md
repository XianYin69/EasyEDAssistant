# EasyEDAssistant Reference：射频 (RF) 规则

> 本文件固化 RF 电路设计规范（硬编码真值）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 阻抗匹配与线宽

- 单端信号：目标 50Ω，按叠层计算线宽（IPC-2141 / Saturation Online）。
- 差分信号：目标 100Ω ±10%，间距 ≤ 3× 线宽。
- λ/4 馈电：最短化走线长度，避免转角 ≥ 90°。

## 天线 keepout 与地缝合

- 全层天线 keepout：RF 器件周围 ≥ 3× 板厚，禁止任何走线与过孔。
- 地缝合过孔：间距 ≤ λ/20（频率对应），紧贴 RF 回路。
- 巴伦镜像布局：两侧完全对称，等长布线。

## 低容 ESD 防护

- 天线端口加 TVS 或限幅器，ESD 器件贴接口。
- 射频路径优先使用共模扼流圈 + 串阻组合。
