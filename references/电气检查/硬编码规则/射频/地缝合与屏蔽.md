# EasyEDAssistant Reference：地缝合与屏蔽

> 硬编码判据，来源射频/混合布局通例。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 地缝合过孔（Via Stitching）

- 沿 RF 走线两侧包地孔：间距 ≤ λ/20（工作频率对应自由空间波长；2.4 GHz → ≤ 6 mm，5.8 GHz → ≤ 2.5 mm），距包地铜边 ≤ 0.3 mm。
- 屏蔽腔四周（shield can 接地墙）孔间距 ≤ λ/20 且角部必打孔，防腔体缝隙泄漏。
- 换层过孔对：信号过孔旁 ≤ 0.5 mm 内 ≥ 2 个地过孔，保证回流连续。
- 两层地平面之间的缝合密度：每 ≥ 25 mm² 至少 1 孔（防腔模谐振；高频从严）。

## 屏蔽罩（Can）

- 屏蔽罩接地焊盘宽 ≥ 1 mm、间距 ≤ 3 mm 连续成墙（缝隙 > λ/20 时泄漏按缝隙天线计算）。
- 罩内元件高度 + 0.5 mm < 罩高；罩下禁布调试跳线/需返修器件。
- 敏感 RF 区与数字区各用独立罩，禁止一罩盖混合域。

## 共面波导与地墙

- 共面波导（CPWG）：侧地间距按阻抗计算值 ±0.1 mm，侧地缝内不得有其他网络穿越。
- 模拟/数字分界地墙：沿分界线双排过孔（间距 ≤ λ/20 或 ≤ 1 mm 通用档）。
- 检查项：RF 回路上任意位置的地孔缺失导致回流断点（跨缝走线）即标记不通过。
