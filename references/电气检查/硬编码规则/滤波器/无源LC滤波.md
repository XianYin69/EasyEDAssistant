# EasyEDAssistant Reference：无源 LC 滤波

> 硬编码判据，来源无源滤波设计通例。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 元件选型

- 滤波电容用 C0G/NP0（f c > 10 MHz）或 X7R（低频去耦）；禁止 Y5V/Z5U（容值漂移 > 50%）。
- 电容 DC 偏压效应：X5R/X7R 在额定电压 50% 偏压下容值可跌 40~80%，按实际偏压查曲线定值，不许用标称值算 fc。
- 公差预算：C ±10%/L ±20% 使 fc 漂移 ≥ ±7%，fc 设计点按最坏情况仍满足阻带要求才通过。
- 电感 SRF ≥ 3× 截止频率；功率电感用于滤波时确认 DCR 与饱和电流不劣化 Q。

## 拓扑判据

- Pi 型（源阻抗低→负载）：第一并联电容承担尖峰，置于最前。
- T 型两端串联注意直流压降；LC 低通源端接时 L 靠源（源为电压型）。
- 陷波/串并组合：并联支路 SRF 即工作点上移失效点，用网络分析仪级模型复核。
- 高 Q（> 50）窄带滤波对元件漂移极敏感，量产选 Q ≤ 20 或加调谐预留 π 位。

## 布局

- 滤波器整体置于「噪声源侧」入口（接口→滤波→IC），跨板区分界时滤波在受保护侧之外。
- 并联支路下地过孔贴元件 ≤ 0.3 mm；串联元件走线直线化，残桩 ≤ 0.2 mm。
- 相邻滤波器通道间加地隔离或 ≥ 3× 线宽距离，防耦合旁通（高频时滤波器间距按 [`../射频/地缝合与屏蔽.md`](../射频/地缝合与屏蔽.md)）。
