# EasyEDAssistant Reference：LED 与 OLED 驱动

> 硬编码判据，来源 LED 驱动 IC 与面板电源通例。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 串并联架构

- 每串电流必须恒流源独立设定；多 LED 直接并联而无均流（恒压驱动）判不通过（Vf 离散 ±0.2 V → 电流失衡 > 2×）。
- Boost 串：最大工作电压 = ΣVf_max × 1.1，OVP 设在 ΣVf_max × 1.2~1.3（任一 LED 开路时全压加到输出，靠 OVP 与 TVS 钳位保护，开路钳位判据）。
- Buck 串：Vin_min ≥ ΣVf_max + 电感/采样压降 + 15% 余量；Buck-Boost 用于 Vf 总和跨 Vin 场景。
- 检流电阻置于 LED 串低侧（恒流环反馈取样），精度 ±1%、TC ≤ 100 ppm；高侧检流时放大器耐压覆盖共模顶。

## 调光与闪烁

- PWM 调光频率 ≥ 200 Hz（人眼无感下限），摄像/车载场景 ≥ 3 kHz；混合调光时模拟深度 ≤ 10~20%（LED 光效非线性区）。
- 调光期间恒流恢复时间 < PWM 导通期的 10%，否则判不通过（灰阶失真）。

## 热与寿命

- LED 结点温度：照明级 Tj ≤ 125 °C、显示级 ≤ 105 °C 设计档；热路径：焊盘过孔阵 → 铝基板/厚铜，热阻核算按 [`../热设计/热设计规则.md`](../热设计/热设计规则.md)。
- 每瓦光损耗发热进散热器预算；灯珠排布均热（相邻结温差 > 20 °C 致色度离散，判不通过）。
- 色温/波长分档：同批 bin 一致（BOM 锁定 bin 号），大电流驱动加速光衰 → 按 60~80% 额定电流设计。

## OLED / 面板电源

- 多轨面板（ELVDD/ELVSS/AVDD）：上电顺序与掉电顺序严格按面板手册（核心先上后下），PGOOD 链实现，禁止各轨独立自然上电。
- 每轨输出电容与去耦贴 PMIC 指定脚；面板 FPC 连接器 pin 定义与轨序丝印双重核对。
