# EasyEDAssistant Reference：激光与光电安全

> 硬编码判据，来源激光二极管与光电检测设计通例（IEC 60825 框架）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 激光二极管（LD）防护

- LD 对 ESD 极端敏感（CDM < 100 V 档常见）：驱动走线全程不裸露，装配期引脚短接（磁珠/0 Ω 运输档），电源先于信号建立；违反判不通过。
- 禁止开路驱动：恒流源失联（连接器拔开）瞬间产生高压尖峰击穿 LD；电流路径必须与「连接器在位检测」联锁，检测脚断开 = 立即关断（硬件路径，非软件轮询）。
- 上电时序：先温控（TEC 达设定）→ 慢启动电流爬升（ms 档）→ 调制；反序致波长跳变与 facet 损伤。
- APC 环路：监控 PD 跨阻放大器（TIA）贴 LD ≤ 5 mm，Rf 100 k~1 MΩ、并联 C 1~10 pF C0G；环路带宽 ≥ 5× 调制频率下限复核稳定裕度（相位 ≥ 45°）。
- Class 3B/IV 产品：双通道独立互锁（钥匙开关 + 外壳联锁）串联在电流路径，任一失效仍可关断；出光指示与延迟启动按 IEC 60825 档位。

## 光电检测（PD/传感器）

- 跨阻放大：Rf 按信号电流 × 目标电压定，输入偏置电流 Ib ≤ 信号最小电流的 1/10（选 JFET/CMOS 输入级）；T 节点走线 ≤ 3 mm、加 guard。
- 环境光抑制：调制 LED + 带通（中心频点 RC 双 T 或 MFB），或遮光罩 + 红光滤片；无调制的光控开关在日光下判误动作风险不通过。
- 光电耦合传输：CTR 全温降额 0.5 计算限流电阻（复用 [`../工控与通信/数字隔离与工业IO.md`](../工控与通信/数字隔离与工业IO.md) 光耦判据）。
- 雪崩光电二极管（APD）：高压偏置（数十~数百 V）独立分区，按 [`../安全与EMC/电气间隙与爬电距离.md`](../安全与EMC/电气间隙与爬电距离.md) 校核间距；纹波 < 0.1% 否则增益噪声淹没。
