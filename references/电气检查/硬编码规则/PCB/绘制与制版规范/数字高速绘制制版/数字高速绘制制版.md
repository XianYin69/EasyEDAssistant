# EasyEDAssistant Reference：数字高速绘制制版规范

> 主导类型为高速差分/总线/HDI-BGA/多时钟域数字的 PCB 绘制与制版硬编码判据（通例级，冲突优先级见 [`../绘制与制版规范.md`](../绘制与制版规范.md)）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

1. **叠层底线**：≥100Mbps 信号或 BGA 出线需求优先 4 层起（信号-地-电源-信号，[`../../叠层与阻抗控制.md`](../../叠层与阻抗控制.md)）；高速线所在层必须紧邻完整地/电源参考面，跨分割 = 判不合格。
2. **阻抗受控网清单先行**：USB(90Ω 差分)/以太网(100Ω)/LVDS·MIPI/HDMI 等按 [`../../../数字电路/总线与存储接口.md`](../../../数字电路/总线与存储接口.md) 与 [`../../../接口连接器/接口索引.md`](../../../接口连接器/接口索引.md) 声明差分对与等长组，再布线；`pcb diff-pair`/`pcb eq-group` 约束先落。
3. **等长与对内 skew 档位**：组内/对内匹配阈值取 [`../../../数字电路/高速信号布线.md`](../../../数字电路/高速信号布线.md) 分档（DDR 按字节组+命令/地址组）；`pcb report` 读 spread 复核，超档 = 回修。
4. **拐点与换层**：全板走线 45° 或圆弧、禁锐角与孤立直角（[`../../间距与线宽.md`](../../间距与线宽.md)）；高速线换层在过孔旁 ≤50 mil 内并排放两个地回流孔（通例），长残桩换层（>30 mil stub）改布线避免，背钻属高成本档需 D 系列拍板。
5. **时钟线待遇**：最高频单端网络（时钟/晶振输出）走内层带状优先，两侧 ≥3W 地guard+缝合孔（[`../../../数字电路/晶振与时钟.md`](../../../数字电路/晶振与时钟.md) 与 [`../../间距与线宽.md`](../../间距与线宽.md) 3W 条）。
6. **BGA 出线策略**：按扇出密度选狗骨/蝶形/in-pad via：pitch ≥0.8mm 常规狗骨即可；≤0.5mm 需盘中孔时声明树脂塞孔工艺（`fab-rules` byLayerCount.6 note，6 层+），并回 [`../../过孔与焊盘.md`](../../过孔与焊盘.md) BGA 条款核环宽。
7. **去耦与电源完整性**：每个电源引脚第一去耦电容焊盘直接过孔落内电层（孔贴焊盘 ≤20 mil，通例），顺序与容值档按 [`../../../数字电路/去耦策略.md`](../../../数字电路/去耦策略.md)；电源入口 net-class 线宽按 [`../../../电源/电源规则索引.md`](../../../电源/电源规则索引.md) 电流档。
8. **测试点制版**：烧录/调试口按 [`../../../数字电路/调试接口.md`](../../../数字电路/调试接口.md) 预留；BGA/密脚 IC 至少每电源网 1 个测试点、关键低速网抽测，覆盖率与点径按 [`../../../测试与可制造性/DFM与DFT规则.md`](../../../测试与可制造性/DFM与DFT规则.md)。
9. **SMT 装配制版**：贴片元件本体间距 ≥0.5mm（贴片头避让，通例）、拼板方向与接料带一致；0402/QFN 批量板丝印标 1 脚并在装配面；手焊档位 0603 下限记入用户配置（[`../../../../../PCB绘制/用户PCB配置文件/用户PCB配置文件.md`](../../../../../PCB绘制/用户PCB配置文件/用户PCB配置文件.md)）。
10. **制版声明**：阻抗公差、铜厚、最小线宽档（4/5/10 mil）随下单声明（[`../../叠层与阻抗控制.md`](../../叠层与阻抗控制.md) 与 `lib/fab-rules-jlcpcb.json` byLayerCount 档）；`pcb check` DFM 审计 0 项后才导制造文件。
