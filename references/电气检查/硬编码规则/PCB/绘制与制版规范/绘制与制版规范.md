## 使用方法

1. 从 [`../../../../检查方案及敲定/检查方案及敲定.md`](../../../../检查方案及敲定/检查方案及敲定.md) 的方案判出板的主导类型；多类型板**叠加**适用各文件全部条款，冲突按优先级收紧不放宽。
2. 本目录条款与通用五文件（[`../PCB规则索引.md`](../PCB规则索引.md) 间距线宽/载流/过孔焊盘/阻焊丝印拼板/叠层阻抗）**同时过**，通用条款打底、类型条款加严。
3. 类型条款中被「见 X」引用的阈值以 X 为正本，本目录不重抄第二套数值；发现本目录数值与正本不符时以正本为准并回改本行。
4. 绘制期由用户 PCB 配置文件的走线策略项（拐点角度/等长/铺铜）落实到具体网；制版期把叠层+阻抗+铜厚声明写进下单备注（D5/叠层与阻抗控制）。

## 依据来源

- IPC-2221B / IPC-2152 / IPC-7351B 通例；JLCPCB 能力页（经 `lib/fab-rules-jlcpcb.json` 留证，2026-07-01 采集）。
- 各电路类型单点故障域判据：本总览同级 电源/射频/数字电路/模拟电路/安全与EMC 子域。
