# EasyEDAssistant Reference：RF与高频绘制制版规范

> 主导类型为射频收发/天线/匹配网络/GHz 时钟的 PCB 绘制与制版硬编码判据（通例级，冲突优先级见 [`../绘制与制版规范.md`](../绘制与制版规范.md)）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

1. **叠层底线**：RF 走线层必须有紧邻的完整地参考层且该层在 RF 区域禁止开槽、禁止其他信号穿越（[`../../../数字电路/高速信号布线.md`](../../../数字电路/高速信号布线.md) 与 [`../../叠层与阻抗控制.md`](../../叠层与阻抗控制.md)）；两层板做 RF 时 RF 元件集中一角、顶层铺地网格加密到 λ/20 缝合（λ 按最低工作频率算）。
2. **特性阻抗**：RF 传输线按目标 Z0（通常 50Ω）用 [`../../../公式/射频与传输线.md`](../../../公式/射频与传输线.md) Wheeler/IPC-2141 公式结合叠层实算线宽，误差档 ±10%（通例）；下单必须附叠层+阻抗声明（[`../../../../../lib/pcb-design-spec.md`](../../../../../lib/pcb-design-spec.md) D5/D7），`fab-rules.impedanceNote`：Z0 不可从平台数据反推，外部计算后声明。
3. **共面波导缝合**：RF 走线两侧地缝合过孔间距 ≤ λ/20、距线 ≥2× 线宽（[`../../../射频/地缝合与屏蔽.md`](../../../射频/地缝合与屏蔽.md)），同网间距可低至 4 mil 但 RF 段按本条加严。
4. **天线区制版**：天线投影区全层禁铜（`pcb antenna-keepout` 强制，[`../../../射频/天线与keepout.md`](../../../射频/天线与keepout.md)），天线净空到板边 ≥ 手册值；**拼板禁止 V-Cut 穿过天线区与 RF 走线区**（切割应力与地断开），改 stamp holes+铣刀（通例）。
5. **RF 接口焊盘**：G-S-G 排布（信号居中、两地夹持）+ 信号焊盘四周缝合孔；同轴连接器金属壳接地 ≥4 过孔直连地平面（[`../../../射频/射频规则索引.md`](../../../射频/射频规则索引.md)）。
6. **禁锐角与枝节**：RF 走线禁止直角/锐角折线与开路枝节（stub），拐角 45° 或圆弧、圆弧半径 ≥3× 线宽（通例，加严 [`../../间距与线宽.md`](../../间距与线宽.md) 图形质量条）；多余枝节长度 >λ/20 判不合格。
7. **元件档位**：匹配网络与 RF 通路用 0402 及以下 C0G/NP0、精度 ±0.1%（通例：0603 焊盘寄生 ~0.5nH 级，>2.4GHz 必换小封装）；预留 0Ω 串联+对地 π 型调试位（[`../../../射频/阻抗匹配.md`](../../../射频/阻抗匹配.md)）。
8. **RF 电源去耦**：RF 有源器件电源引脚 LC/磁珠隔离按 [`../../../射频/RF电源与偏置.md`](../../../射频/RF电源与偏置.md)，去耦电容地脚用独立过孔直达地平面、不与数字回流共用同一孔。
9. **阻焊与表面处理**：RF 焊盘阻焊开窗用 LPI 精确开窗（防塞焊），天线馈点优选沉金 ENIG（ [`../../阻焊丝印与拼板.md`](../../阻焊丝印与拼板.md)）；RF 区禁用喷锡大圆角（尺寸一致性差，通例）。
10. **测试与留证**：RF 测试用预留 π 型衰减/直连 SMA 位，不得用长微带飞线引到测试点；测量口 50Ω 参考到频谱仪后按 [`../../../../../专业技术规范检查/专业技术规范检查.md`](../../../../../专业技术规范检查/专业技术规范检查.md) 通道回读留证。
