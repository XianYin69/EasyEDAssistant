# EasyEDAssistant Reference：电源电路绘制制版规范

> 主导类型为开关电源/电池充电/大电流配电的 PCB 绘制与制版硬编码判据（通例级，冲突优先级见 [`../绘制与制版规范.md`](../绘制与制版规范.md)）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

1. **功率环路最小化**：Buck/Boost 热回路（输入电容-开关节点-电感/续流-地）按 [`../../../电源/Buck热回路.md`](../../../电源/Buck热回路.md) 判据执行；板级加严：热回路包围面积 ≤ 该模块占板面积的 10%（通例），超出 = 布局不合格重摆。
2. **线宽按载流分档**：一切电源走线取 [`../../载流与温升.md`](../../载流与温升.md) IPC-2152 档 + 20% 余量；外层主干即使电流小也不低于 20 mil（`fab-rules` recommended.trackWidthPowerMil，兼作机械强度与返工余量）。
3. **电源走铺铜块不走细线**：≥500mA 的轨一律 `pcb power-pour`（2 层）或内电层（4 层，[`../../叠层与阻抗控制.md`](../../叠层与阻抗控制.md)）；单段 <20 mil 的"针尖"收窄（neck-down）只允许出现在器件焊盘引出第一跳。
4. **开关节点（SW/LX）铺铜最小化**：SW 网络铜皮只覆盖焊盘+最短连接，与他网间距 ≥6 mil（`fab-rules` recommended.clearanceMil）、距地铜不留感应狭缝；禁止 SW 铺铜伸入反馈/FB 走线下方。
5. **回流单点**：输入电容、输出电容、芯片 GND 脚的回流在功率地同一点汇合后单点接信号地（[`../../../电源/电源去耦与接地.md`](../../../电源/电源去耦与接地.md)）；多个功率回流共用一段细线 = 判不合格。
6. **散热制版**：≥2W 器件焊盘下过孔阵按 [`../../../热设计/热设计规则.md`](../../../热设计/热设计规则.md) 档位执行（0.3/0.6mm 通孔、间距约 1mm 阵，通例）；顶层铜厚 ≥2oz 的电源板按 `fab-rules` byCopperWeight 把最小线宽/间距升到 6.5 mil 再核。
7. **极性器件丝印**：电解/钽/肖特基/芯片引脚 1 的极性标记在器件轮廓外装配可见，丝印字高 ≥40 mil、距焊盘 ≥6 mil（`fab-rules` manufacturingMin.silkTextHeightMil/padToSilkMil，见 [`../../阻焊丝印与拼板.md`](../../阻焊丝印与拼板.md)）。
8. **AC-DC 安规距离**：一次/二次侧电气间隙与爬电按 [`../../../安全与EMC/电气间隙与爬电距离.md`](../../../安全与EMC/电气间隙与爬电距离.md) 电压档执行；光耦本体正下方禁止走非安全短路的铜与过孔，隔离带上开铣槽（最小 0.8mm 铣刀直径，通例）。
9. **大电流端子制版**：≥3A 端子用 ≥1oz 铜、铺铜挂锡开窗（阻焊开窗面积 ≤ 焊盘，防锡珠）；过孔阵列载流按 [`../../载流与温升.md`](../../载流与温升.md) 单孔档折算，孔数不足判不合格。
10. **反馈与软启动走线**：FB/SS/EN 等小信号高阻节点走线距 SW/电感 ≥3× 线宽（[`../../间距与线宽.md`](../../间距与线宽.md) 3W 条款加严为"敏感-噪声源"对），必要时包地；采样点取自输出电容铜皮根部而非负载端细线。
