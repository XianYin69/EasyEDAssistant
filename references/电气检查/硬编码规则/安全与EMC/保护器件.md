# EasyEDAssistant Reference：保护器件协调

> 硬编码判据，来源过流/过压保护协调通例。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 器件职责分工

- 保险丝：分断持续过流（能量小、时间长）；MOV/GDT：泄放浪涌大能量（IEC 61000-4-5 级）；TVS：钳位快速瞬态（EFT/ESD 级）。三者不可互相替代。
- 协调顺序：源 → 保险丝/断路器 → MOV/GDT → TVS → 被保护电路；每级间用退耦阻抗（≥ 5 Ω 或 1~10 µH）利用时间差让前级先导通。
- TVS 必须放在 MOV/GDT 之后（否则 MOV 不动作时 TVS 单扛能量烧毁）。

## 选型判据

- 保险丝：冷电阻与功耗计入效率预算；分断能力 ≥ 预期故障电流（市电入口 ≥ 100 A 档）。
- MOV 压敏电压 Vrms 档 ≥ 1.4× 最大持续工作电压；并联在保险丝后、可触及面之前。
- GDT 直流击穿电压 ≥ 1.2× 峰值工作电压，且需串热脱扣或配合退化电路防续流焊接短路。
- 自复件（PPTC）仅用于内部电子线路；涉及安规主保护用一次性保险丝。

## 失效安全

- 保护器件失效模式核查：MOV 短路 → 必须被保险丝切断（否则起火风险，判不通过）。
- 双保险：一次侧保险丝 + 二次侧 OCP（电子保险丝/限流）独立实现，不共用控制环路。
- 丝印标注：所有安全相关器件位号加 ⚑ 或 "SAFETY" 标识，BOM 注明认证型号（不允许未认证替代）。
