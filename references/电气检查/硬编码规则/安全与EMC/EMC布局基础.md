# EasyEDAssistant Reference：EMC 布局基础

> 硬编码判据，来源 EMC 设计通例（传导 + 辐射发射/抗扰）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 源头控制

- 一切发射源于环路：di/dt 环路（开关回路、时钟回路）面积每减半，远场辐射降 ≈ 6 dB；热回路判据见 [`../电源/Buck热回路.md`](../电源/Buck热回路.md)。
- 时钟是最强发射源：时钟走线内层化 + 包地，禁止时钟出板边、禁止时钟到接口连接器直连（经滤波）。
- 开关节点（SW、变压器绕组、栅极驱动）铜皮最小化（dV/dt 天线）。

## 分区与界面

- 单板三区：噪声源区（DCDC/时钟）— 敏感区（RF/ADC）— 接口区（连接器）；接口区贴板边成排，滤波统一放「板内侧」一线（滤波带）。
- 连接器金属壳至少 2 点接地且距板边地过孔 ≤ λ/20；I/O 走线不穿越板中央（远离时钟区）。
- 板边地过孔排（缝合）：沿板轮廓每 ≤ λ/10（通用 ≤ 5 mm）打地孔防腔体缝隙辐射。

## 回流与缝隙

- 信号换层点旁必须就近有地孔（无参考连续即潜在缝隙天线）。
- 机壳开孔/散热缝与内部时钟线正对时按缝隙天线评估（缝长 > λ/4 时强辐射）。
- 电缆是主要耦合天线：所有出板线经过滤波 + 屏蔽层 360° 端接到面板地。

## 检查项

1. 最大 3 个 di/dt 环路面积是否已被压缩并标注。
2. 接口滤波器件是否位于「连接器-板内」路径的连接器侧第一站。
