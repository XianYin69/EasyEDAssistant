# EasyEDAssistant Reference：Buck 热回路

> 硬编码判据，来源 TI / ADI 电源 App Note 通例。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 热回路（di/dt 最大环路）最小化

- 热回路 = 输入电容「+ 端 → VIN 脚 → SW 脚 → 电感 → 输出电容 → GND → 电容「-」端」中由输入电容承担换流的部分；输入陶瓷电容必须贴放：正极到 VIN 脚 ≤ 2 mm，负极到 GND 过孔 ≤ 2 mm。
- 输入电容总 ESL 最小化：多只并联、小封装优先（0402 < 0603 < 0805），禁止把输入电容甩到 5 mm 之外。
- 高 di/dt 节点（SW）判据：铜皮面积「够用即可」——满足载流与散热前提下最小化，SW 铜皮每 1 mm² 约 1.2 pF 寄生，直接决定开关振铃与 EMI。
- SW 铜皮上禁止走任何信号线、禁止跨越到其他层（除 IC 内部），GND 层在 SW 正下方必须完整地（不作铜皮挖空）。
- 电感选屏蔽式（一体成型/磁罩），与敏感模拟区距离 ≥ 5 mm 或磁场朝向避开。

## 功率地与反馈

- 功率地（电容 GND、IC GND 功率脚）用短而宽的直连回 IC 散热盘下过孔阵，不与小信号地共用长路径。
- 反馈网络（FB 分压）：上端接输出电容「+」的正 Kelvin 点，下端接 IC GND 脚旁；FB 走线距 SW ≥ 3 mm 或走在内层（有完整地屏蔽）。
- 自举电容贴 BOOT/SW 脚 ≤ 3 mm。
- 输出电容「-」到 IC GND 的回流路径上禁止串过其他器件的接地焊盘（共阻抗判据）。

## 检查项

1. 输入电容是否 VIN/GND 双孔直连（无长绕线）。
2. SW 铜皮是否最小化且无跨层、无线下走线。
3. FB 采样点是否取自输出电容正端（而非负载端或电感远端）。
