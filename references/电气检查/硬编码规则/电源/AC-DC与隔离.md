# EasyEDAssistant Reference：AC-DC 与隔离

> 硬编码判据，来源 IEC 62368-1 / 反激设计通例。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 一次侧 / 二次侧分区

- 隔离带（初/次侧分界）必须贯通整板，禁止任何走线斜跨；唯一允许跨越路径：光耦、Y 电容、共模电感、变压器磁芯下净空区。
- 一次侧大电流环路（整流桥-变压器-滤波电容）布置于板一侧并最小化；二次侧同步整流/滤波独立分区。
- 高压节点（L/N、母线电容、原边 MOS 漏极）用丝印 + 警示框标识，禁布元件与过孔于其放电半径内。

## 隔离间距

- 初/次侧电气间隙与爬电距离判据见 [`../安全与EMC/电气间隙与爬电距离.md`](../安全与EMC/电气间隙与爬电距离.md)；基础判据：230 VAC 系统隔离带间距 ≥ 6.4 mm（裸铜）/ 8.0 mm（含爬电）。
- 板厂铣槽深度计入隔离验证；槽口两端开圆头（止裂）且端部间距不缩小爬电路径。
- 一次侧内部（L-N 之间）间距 ≥ 3.0 mm（污染等级 2）。

## 回流与滤波

- Y 电容跨接隔离带提供共模回流，其接地焊盘到各自地铜路径短粗；初次侧地之间禁止任何其它低阻连接。
- EMI 入口顺序：保险丝 → MOV → X 电容 → 共模电感 → Y 电容；顺序错判不通过。
- 反馈光耦跨带摆放：初级晶体管侧接地（原边）走最短距离到原边控制 IC 的 COMP/FB 脚。
- 变压器磁芯下方禁布走线与铜，禁布敏感模拟线（漏磁耦合路径）。
