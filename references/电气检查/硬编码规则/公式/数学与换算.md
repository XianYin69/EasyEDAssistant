# EasyEDAssistant Reference：数学与换算

> 电路计算所需数学工具与工程速算。编辑遵守 RULE_EDIT.md：≤ 50 行、自然语言。

## 对数与分贝

- dB 增益：G = 20log(A2/A1)（电压/电流）；G = 10log(P2/P1)（功率）。
- 速算：+6 dB≈×2 电压、+20 dB=×10 电压、+3 dB=×2 功率、+10 dB=×10 功率。
- ln 与 log10：ln(x) = 2.303×log10(x)；e ≈ 2.718，e^−1 ≈ 0.368（1τ 残值）。
- 指数衰减/增长常用：e^−5 ≈ 0.0067（3τ→0.05、5τ→<1% 整定判据来源）。

## 复数与相量

- 相量：U = |U|∠φ ↔ U = |U|×e^(jφ) = a + jb；j = √−1，j² = −1。
- 串并联复阻抗法则同电阻（用 Z 代替 R）；分压式：U2 = U×Z2/(Z1+Z2)。
- 欧拉：e^(jθ) = cosθ + j·sinθ；正弦稳态全用相量域乘除代换微积分。

## 代数与近似

- 二次方程：x = [−b ± √(b²−4ac)]/(2a)；判别式 Δ = b²−4ac 决定 RLC 阻尼（Δ<0 振荡）。
- 小量近似（|x|≪1）：(1+x)^n ≈ 1+nx；e^x ≈ 1+x；sin x ≈ x（弧度）；√(1+x) ≈ 1+x/2。
- 并联两电阻偏差：R ≈ R1(1−R1/R2) 当 R2 ≫ R1（近似取值判断）。
- 泰勒一阶保留误差判据：二阶项/一阶项 < 5% 才允许线性化。

## 工程换算

- 单位前缀：µ = 10⁻⁶、n = 10⁻⁹、p = 10⁻¹²、k = 10³、M = 10⁶、G = 10⁹。
- 常用组合：MHz×pF×kΩ 无量纲匹配；1/(2π×1 kΩ×1 nF) ≈ 159 kHz（速算锚点）。
- 频率周期：T = 1/f；1 GHz→1 ns，1 MHz→1 µs，50 Hz→20 ms。
- 角度：180° = π rad；相位裕量 45° ≈ π/4 rad。
- 英制线：1 mil = 0.0254 mm；1 inch = 25.4 mm（4 mil ≈ 0.1 mm 速记）。
- 温标：K = °C + 273.15；ΔT 在 K 与 °C 下数值相同。
- 电阻/电容 E 系列：E24（±5%）、E96（±1%）取最接近标称并校核偏差对判据的影响。
- 算术校验习惯：代入前先归一到 SI 基本单位再计算，结果用数量级粗验（10 的幂心算）。
