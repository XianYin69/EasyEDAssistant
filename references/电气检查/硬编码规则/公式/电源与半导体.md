# EasyEDAssistant Reference：电源与半导体公式

## DC-DC 理想变换式（连续导通）

- Buck：Vout = D×Vin；电感纹波 ΔIL = (Vin−Vout)×D/(L×f_sw)；ΔIL ≈ (20~40)%Iout 为经济档。
- Boost：Vout = Vin/(1−D)；ΔIL = Vin×D/(L×f_sw)；输出电容纹波 ΔU = Iout×D/(C×f_sw)。
- Buck-Boost/SEPIC 反相族：|Vout| = D/(1−D)×Vin。
- 反激：Vout = Vin×(Ns/Np)×D/(1−D)；原边峰值 Ipk = 2×Pout/(η×Vin_min×D_max)。
- 正激：Vout = Vin×(Ns/Np)×D；磁复位占空比 D_max ≤ 0.5（单绕组复位）。
- 电容纹波（Buck 输出）：ΔU = ΔIL×ESR + ΔIL/(8×C×f_sw)，两项都要校核。

## 半导体

- PN 结：I = Is×(e^(U/Vt) − 1)；热电压 Vt = kT/q ≈ 26 mV（25 °C），每 −2 mV/°C 硅 Vf 随温降。
- BJT 放大区：Ic = β×Ib；Vce_sat ≈ 0.1~0.3 V；Ebers-Moll 简化：Ic ≈ Is×e^(Vbe/Vt)。
- MOS 饱和区（恒流）：Id ≈ ½×µnCox×(W/L)×(Vgs−Vth)²；导通电阻 Rds_on ≈ 1/[µnCox×(W/L)×(Vgs−Vth)]。
- MOS 开关损耗：P_sw ≈ ½×V×I×(tr+tf)×f_sw；栅极驱动功率 P_gate = Qg×Vgs×f_sw。
- 栅极驱动电阻：Rg 决定 tr/tf 与振铃折中，τ_gate ≈ Rg×Ciss，tr ≈ 2.2×τ_gate。
- 齐纳稳压：Iz_min ≤ Iz ≤ Iz_max = Pz/(Vz−Vin_min)，负载电流变化要落在余量内。
- JFET 恒流管：I = I_dss×(1−Vgs/Vp)²，饱和区压差 ≥ |Vp|−|Vgs| 才准。

## 热与电池

- 热阻链：Tj = Ta + P×(θJC + θCS + θSA)；温差=功率×热阻（类比欧姆定律）。
- 电池续航估算：t(h) ≈ C(Ah)×η / I_load；低温 0.6~0.8 系数（-20 °C）。
- 电容 ESR 发热：P_rms = I_ripple_rms²×ESR，超手册纹波电流额定判不通过。
