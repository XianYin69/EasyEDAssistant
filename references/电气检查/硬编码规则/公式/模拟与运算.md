# EasyEDAssistant Reference：模拟与运算公式

> 小信号线性近似下的运放/晶体管判据。编辑遵守 RULE_EDIT.md：≤ 50 行、自然语言。

## 运放理想八式

- 虚短虚断（负反馈线性区）：U+ ≈ U−，I+ ≈ I− ≈ 0。
- 反相放大：A = −R2/R1；同相放大：A = 1 + R2/R1（≥1）。
- 电压跟随：A = 1（缓冲高阻源）；差分放大：A = R2/R1（四电阻匹配 ≤0.1% 时 CMRR 达标）。
- 加法器：Uout = −Rf×(U1/R1 + U2/R2 + …)；积分器：Uout = −(1/RC)×∫Uin·dt；微分器对偶（易振荡，需串阻限带宽）。
- 仪表放大整体：A = (1 + 2R1/Rg)×R2/R3（三运放结构）。

## 频域与精度限制

- 增益带宽积：GBW = A_cl × f_c（闭环）；可用带宽 = GBW/闭环增益，预算不足判不通过。
- 压摆率限幅：dU/dt_max = SR；正弦满幅要求 SR ≥ 2π×f×U_peak。
- 建立时间：到 0.1% 阶跃 ≈ 8~12 × τ（τ = 1/(2π×f_cl)），精密采样场景必核。
- 输出噪声折算：e_n_total = e_n×√(带宽×矩形系数)×噪声增益；电阻热噪声 e_n = √(4kTRB) ≈ 0.13 nV/√Hz×√(R/Ω)。
- CMRR = 20log(差模增益/共模增益) dB；PSRR 同义（电源侧）。
- 失调： Vos_total = Vos×噪声增益 + Ib×R_B；精密 DC 路径需选零漂移或校准。

## 反馈与稳定

- 环路增益：Aβ；相位裕量 PM ≥ 45°（<30° 振荡风险判不通过），增益裕量 GM ≥ 6 dB。
- 巴克豪森振荡条件：环路增益 |Aβ| ≥ 1 且相位 0°/360° 的频率存在即起振。
- 容性驱动：输出串 R_iso = √(L/C)（约 10~50 Ω）或在反馈环外取样。

## 振荡器频率

- 文氏桥/Wien：f0 = 1/(2πRC)，起振增益 ≥ 3（含 1% 精密匹配）。
- 相移三节 RC：f0 = 1/(2π√6·RC)，衰减 1/29。
- 晶体：f 由切型与负载电容定，CL 匹配按谐振器手册（同数字域晶振篇）。
