# EasyEDAssistant Reference：交流、谐振与磁公式

> 正弦稳态与磁性器件判据。编辑遵守 RULE_EDIT.md：≤ 50 行、自然语言。

## 正弦量与阻抗

- 有效值：U_rms = U_peak/√2（正弦）；P = U_rms×I_rms×cosφ。
- 感抗 X_L = 2π×f×L；容抗 X_C = 1/(2π×f×C)；复阻抗 Z = R + j(X_L − X_C)。
- 串联谐振：f0 = 1/(2π√(LC))，Z 最小 = R，电流放大 Q 倍。
- 并联谐振：f0 同上，Z 最大，电感电流 = Q × 总电流（谐振升流危险点）。
- 品质因数：串联 Q = X/R = (1/R)√(L/C)；并联 Q = R/X；带宽 BW = f0/Q。
- 功率因数校正目标 cosφ ≥ 0.95；补偿电容 Q_c = P×(tanφ1 − tanφ2)。
- 三相：U_line = √3×U_phase；P = √3×U_line×I_line×cosφ。

## 互感与磁

- 互感电压：U2 = −M×dI1/dt；耦合系数 k = M/√(L1×L2)。
- 同名端规则：电流从两绕组同名端流入时磁通相加（异名端反接电感抵消判不通过）。
- 理想变压器：U1/U2 = N1/N2 = I2/I1；阻抗反射 Z' = Z×(N1/N2)²。
- 电感能量：E = ½×L×I²；电感电压电流关系 U = L×dI/dt（与暂态篇一致）。
- 磁芯饱和裕度：B_max = U×D/(N×Ae×f)（反激），按手册 B_sat 的 70~80% 封顶。
- 自谐振：任何电感有 SRF = 1/(2π√(L×C_par))，使用频率 ≤ SRF/3。

## 交流信号完整性

- −3 dB 点：|Z分压| = 0.707 直传值；级联 RC 无缓冲时 fc 互相加载，需按传递函数复算。
- 上升沿近似：t_r ≈ 0.35/BW（GHz→ns，一阶系统）。
