# EasyEDAssistant Reference：射频与传输线公式

> 分布参数与射频链路判据。编辑遵守 RULE_EDIT.md：≤ 50 行、自然语言。

## 传输线

- 特征阻抗：Z0 = √(L'/C')；有损线 Z0 = √[(R+jωL)/(G+jωC)]。
- 相位速度：v = c/√εr_eff；波长：λ = v/f = c/(f×√εr_eff)。
- 电长度换算：90° = λ/4；30° = λ/12；短线 < λ/10 可按集总近似（判据分界）。
- 反射系数 Γ = (ZL−Z0)/(ZL+Z0)；回波损耗 RL = −20log|Γ| dB；驻波比 VSWR = (1+|Γ|)/(1−|Γ|)。
- 插损 IL = −20log|S21| dB；功率增益 G = −IL（匹配网络）。
- λ/4 阻抗变换器：Z_in = Z0²/ZL（选 Z_line = √(Z0×ZL) 实现匹配）。

## 微带/带状线速算（FR-4 εr≈4.4，参考面完整）

- 带状线（内层，d 介质厚，w 线宽）：Z0 ≈ 60/√εr × ln[2b/(0.8w+t)]（b 到两平面距离和，单面时 b=d）。
- 微带（外层，d 到地）：Z0 ≈ 87/√(εr+1.41) × ln[5.98d/(0.8w+t)]；50 Ω 单端对应 w ≈ 1.6~2.0×d。
- 差分：Zdiff ≈ 2×Z0×(1−0.48×e^(−0.96×S/h))；耦合增强（S 减小）→ Zdiff 降低。
- 走线电感 ≈ 1 nH/mm，过孔电感 ≈ 0.5~1 nH（0.3 mm 孔，短 stub），贴片电容 ESL ≈ 0.4~0.7 nH。

## 功率与损耗

- dBm ↔ W：P(dBm) = 10log(P/1mW)；0 dBm=1 mW，30 dBm=1 W；+3 dB ×2，−10 dB ÷10。
- 自由空间损耗：FSPL(dB) = 32.4 + 20log(f_MHz) + 20log(d_km)。
- 趋肤深度：δ = √(ρ/(π×f×µ))；铜 20 °C：δ ≈ 66 µm/√f_MHz → 高频走线仅表面 3~5δ 导电。
- 介质损耗 ∝ f×tanδ×√εr；FR-4 tanδ≈0.02 在 >6 GHz 严重，需高速板材（Megtron/Rogers）。
- 接收功率：Prx = Ptx + Gtx + Grx − FSPL − 其他损耗（dB 域全加减）。

## 天线与调制

- 各向同性增益换算 dBi = dBd + 2.15；半波偶极子 ≈ 2.15 dBi。
- 天线孔径（参考）：Ae ≈ λ²×G/(4π)。
- 噪声底：N = −174 dBm/Hz + 10log(BW) + NF；SNR = Prx − N。
- EVM、BER、调制阶数：属链路层，超出本域，走厂商手册。
