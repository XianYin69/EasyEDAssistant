# EasyEDAssistant Reference：暂态与一阶二阶公式

> RC/RL/RLC 开关与暂态判据。编辑遵守 RULE_EDIT.md：≤ 50 行、自然语言。

## 一阶 RC / RL

- 时间常数：RC 电路 τ = R×C；RL 电路 τ = L/R。
- 充电：U(t) = Ufinal × (1 − e^(−t/τ))；放电：U(t) = U0 × e^(−t/τ)。
- 整定时间：到 63.2% 用时 1τ，95% 用 3τ，99.3% 用 5τ；消抖/延时按目标百分比反推 τ。
- RC 低通截止：f c = 1/(2π×R×C)；角频率 ωc = 1/τ。
- 电容换路：Uc 不能突变（i = C×dUc/dt）；电感换路：IL 不能突变（U = L×dIL/dt）。
- 电容冲击电流：刚接通瞬间 I = U/R_loop（ESR+线阻），用于保险丝/MOS 峰值校核。
- 电容储能：E = ½×C×U²；断电保持时间估算 t ≈ C×(U1²−U2²)/(2×P)（恒功率近似）。
- 电感续流：断开瞬间电压尖峰 U = L×dI/dt，必须给出钳位路径（TVS/二极管/RCD）。

## 二阶 RLC

- 串联谐振衰减判据：阻尼比 ζ = (R/2)×√(C/L)；ζ<1 振荡、ζ=1 临界、ζ>1 过阻尼。
- 固有频率：f0 = 1/(2π×√(L×C))（串联/并联同式，理想）。
- 并联 RLC 阻抗峰在 f0，串联 RLC 阻抗谷（陷波）在 f0——滤波器/去耦陷频设计用。
- 过冲与 ζ：二阶阶跃过冲 ≈ e^(−πζ/√(1−ζ²))；ζ = 0.707 时过冲 ≈ 4.3%（最平坦设计档）。

## 传输延迟

- RC 互连分布延迟（经验）：t_pd ≈ 0.4×R×C（单位长度网络总 R、总 C）。
- 长线传播延迟：t = L_线 × √(εr_eff)/c；FR-4 表层 ≈ 6.7 ns/m，内层 ≈ 8.4 ns/m。
- 检查项：跳变沿 < 5×传播延迟时必须按传输线端接处理，禁止当集总 RC 看。
