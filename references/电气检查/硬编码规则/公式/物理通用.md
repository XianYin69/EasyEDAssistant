# EasyEDAssistant Reference：物理通用公式

> 电磁、热、力等与硬件设计相关的通用公式。编辑遵守 RULE_EDIT.md：≤ 50 行、自然语言。

## 电磁基础

- 库仑力：F = k×q1×q2/r²；k = 8.99×10⁹ N·m²/C²；电场 E = F/q。
- 平行板电容：C = ε×A/d；ε = ε0×εr，ε0 = 8.85×10⁻¹² F/m；边缘忽略条件：d ≪ √A。
- 长直导线磁场：B = µ0×I/(2π×r)；µ0 = 4π×10⁻⁷ H/m；r 为垂直距离。
- 螺绕环/长螺线管：B = µ0×µr×n×I（n 为匝/米）；磁通 Φ = B×A。
- 洛伦兹力：F = q×v×B×sinθ；载流导线 F = B×I×L×sinθ。
- 位移电流/安培-麦克斯韦：∮B·dl = µ0×(I_cond + I_disp)（高频近场估算用）。
- 电磁波：c = λ×f = 3×10⁸ m/s（真空）；介质中 v = c/√εr。
- 平面波阻抗：η ≈ 120π ≈ 377 Ω（自由空间）。

## 热学

- 热传导（傅里叶）：P = k×A×ΔT/d；铜 k≈401、FR-4 k≈0.3、空气 k≈0.026 W/(m·K)。
- 自然对流：P = h×A×ΔT；h ≈ 2~10 W/(m²K)（空气自然对流），风冷 ×5~10。
- 比热温升：ΔT = E/(m×c)；铜 c≈385、FR-4 c≈1100 J/(kg·K)（脉冲负载瞬态校核）。
- 热辐射（斯特藩-玻尔兹曼）：P = ε×σ×A×(T⁴ − T_env⁴)，σ = 5.67×10⁻⁸ W/(m²K⁴)，<150 °C 通常 <5% 总散热。
- 热膨胀（CTE）：ΔL = α×L×ΔT；FR-4 z 向 α ≈ 15~20 ppm/°C（BGA 焊点疲劳校核用）。

## 单位常数速查

- k_B = 1.38×10⁻²³ J/K；q = 1.60×10⁻¹⁹ C；Vt = kT/q ≈ 26 mV @ 25 °C。
- 电流密度：J = I/A；通用 PCB 外层 1 oz 铜（35 µm）每 mm² ≈ 30 A 极限，长期按 10 A/mm² 降额（与 IPC-2152 温升档相互印证）。
- 电阻功率降额（通用档）：0402 1/16 W、0603 1/10 W、0805 1/8 W、1206 1/4 W（25 °C 环境，85 °C 降至 50%）。
