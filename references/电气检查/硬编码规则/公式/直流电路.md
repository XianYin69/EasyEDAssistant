# EasyEDAssistant Reference：直流电路公式

> 线性电阻网络稳态判据。编辑遵守 RULE_EDIT.md：≤ 50 行、自然语言。

## 基本定律

- 欧姆定律：U = I × R；电导 G = 1/R。
- 功率四式：P = U×I = I²×R = U²/R = U×I；电阻功耗超降额值判不通过。
- 基尔霍夫：任一节点 ΣI(入) = ΣI(出)；任一回路 ΣU(升) = ΣU(降)。

## 等效化简

- 电阻串联 R = R1+R2+…；并联 R = 1/(1/R1+1/R2)，两并联速算 R = R1×R2/(R1+R2)。
- 电容恰相反：串联 1/C = Σ1/Ci，并联 C = ΣCi。
- 电感与电阻同向：串联 L = ΣLi，并联 1/L = Σ1/Li。
- 分压：Uout = Vin × R2/(R1+R2)（空载）；带载时按负载并入 R2 复算。
- 分流：I1 = Itotal × R2/(R1+R2)（两支路）。
- Δ-Y 变换：Y 臂 = 相邻两 Δ 边积 ÷ Δ 三边和；对称时 R_Y = R_Δ/3。
- 电源等效：电压源 U 串 R ↔ 电流源 I=U/R 并 R（诺顿/戴维南互换）。
- 叠加定理：线性网络中多源响应 = 每源单独作用之和（不适用范围：功率）。

## 导线与接触

- 导线电阻：R = ρ × L / A；铜 ρ = 1.72×10⁻⁸ Ω·m（20 °C）。
- 温度漂移：R(T) = R20 × [1 + α×(T−20)]；铜 α ≈ 0.00393/°C。
- 回路压降预算：ΔU = 2×L×I×ρ/A（去+回），ΔU > 5% 电源电压判不通过。
- 短路电流估算：I_sc ≈ U / R_源内阻（含线阻），用于分断能力校核。

## 常用电流密度与容量

- 电解电容漏电流：I_leak ≈ U×C×0.01~0.03（µA，U 为 V、C 为 µF 时系数视厂家）。
- 电池容量换算：Ah × 标称电压 ≈ Wh；持续放电电流 = C 率 × Ah。
