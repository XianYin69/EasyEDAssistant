# EasyEDAssistant Reference：电气检查

## 流程

1. 查询电气规则：先从硬编码规则（[`硬编码规则/硬编码规则总览.md`](硬编码规则/硬编码规则总览.md)）读取内置判据；若遇未知场景则用 [`../浏览器检索/浏览器检索.md`](../浏览器检索/浏览器检索.md) 联网补充。
2. 判断电气规则是否通过：所有规则均通过 → 标记电气规则通过；任一未通过 → 中断并处理设计问题（见 [`../处理设计问题/处理设计问题.md`](../处理设计问题/处理设计问题.md)），处理后跳回第 1 步重新检查。**同一未通过判据「检查↔处理」往返最多 3 轮**（额度随每次进入电气检查重计，与处理设计问题自身 3 轮熔断同源）；满 3 轮仍不通过即停止自动回环、转用户拍板（改方案 / 明确豁免并记入方案文件 / 调整需求 / 中止），不得无限重查。

## 判据与动机

- 硬编码规则优先（IPC-2221B / IPC-7351B / IEC 62368 等标准已固化在子域判据中）。
- 联网查询仅作为已知限制外的补充，不替代硬编码真值。
