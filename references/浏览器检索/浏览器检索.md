> 用于「处理设计问题」第 1 步：联网搜索可能的解决方案，见 [`../处理设计问题/处理设计问题.md`](../处理设计问题/处理设计问题.md)。

## 触发条件（任一）

- 未知 MPN / LCSC C 号 / 器件封装：手册关键参数、典型应用未查到。
- 命令报错 / daemon 返回未知 code / 图元行为异常。
- 需要跨平台核对选型、行情、库存、替代品。
- 遇到已知限制外的新症状。

## 检索方式

- **先定区域**：联网/查价/下载手册前先按 [`网络环境检测/网络环境检测.md`](网络环境检测/网络环境检测.md) 跑 `net-probe.py` 判 `region`——大陆（谷歌不可达）优先 `item.szlcsc.com`/`hqchip.com` 等大陆平台，境外用国际渠道；一次会话缓存 `./tmp/init/net-env.json`。
- 工具：`websearch`（首查）、`webfetch`（取正文）；不执行页面 JS、不做账号登录。
- 优先站点：中文经验（博客园、知乎、CSDN、电子发烧友、嘉立创论坛）；英文工程问答
  （Stack Overflow、EEVblog、EE 百科等）；器件与选型（region=cn→**szlcsc.com 优先**、
  华秋、JLCPCB；region=global→厂商官网、DigiKey、Mouser、LCSC）；标准规范（IPC/JEDEC/IEC、JLCPCB 能力页）。
