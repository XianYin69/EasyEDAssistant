> 本文件自 `references/lib/external-resources.md` §13.1 片段改写而来（自然语言）。
> 用于「处理设计问题」第 1 步：联网搜索可能的解决方案，见 [`../处理设计问题/处理设计问题.md`](../处理设计问题/处理设计问题.md)。

## 触发条件（任一）

- 未知 MPN / LCSC C 号 / 器件封装：手册关键参数、典型应用未查到。
- 命令报错 / daemon 返回未知 code / 图元行为异常。
- 需要跨平台核对选型、行情、库存、替代品。
- 遇到已知限制外的新症状。

## 检索方式

- 工具：`websearch`（首查）、`webfetch`（取正文）；不执行页面 JS、不做账号登录。
- 优先站点：中文经验（博客园、知乎、CSDN、电子发烧友、嘉立创论坛）；英文工程问答
  （Stack Overflow、EEVblog、EE 百科等）；器件与选型（厂商官网、DigiKey、Mouser、
  立创商城、LCSC）；标准规范（IPC/JEDEC/IEC、JLCPCB 能力页）。

## 落盘工件

- 学习笔记：`./tmp/learning/<topic>.md`，固定字段（时间/触发/URL/摘要/关键参数/
  工程映射/未证实项）。

## 纪律

- 学习笔记是证据链，不是新知识真值；不静默合并进判据，结论须走中断点请用户拍板。
