# EasyEDAssistant Reference：原理图制作

> 本文件是「原理图制作」步骤的总索引（自然语言）；触发时机：电路设计标准设计流程第 4 步。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言；分支细则见子文件。

## 流程

1. **桥接连通性测试**（见 [`../桥接联通性测试/桥接联通性测试.md`](../桥接联通性测试/桥接联通性测试.md)）：确认 MCP 或 Agent 链路可用并通过门禁，标记「桥接连通性测试通过」后才进下一步。
2. **绘制原理图**（见 [`../绘制原理图/绘制原理图.md`](../绘制原理图/绘制原理图.md)）：读取方案文件与已下载技术手册、按绘制规则逐部分绘制并截图，用户接受后保存截图。
3. **检查原理图是否符合技术手册及方案**（见 [`检查是否符合技术手册及方案/检查是否符合技术手册及方案.md`](检查是否符合技术手册及方案/检查是否符合技术手册及方案.md)）：不符合 → 回到第 2 步继续绘制或修改；符合 → 进入第 4 步。
4. **保存交付**（见 [`../绘制原理图/用户验收与保存/用户验收与保存.md`](../绘制原理图/用户验收与保存/用户验收与保存.md)）：验收步已 `sch save` 且此后无改动 → 回读确认 `saved:true` 未回退即可；第 3 步检查引起过修改 → 重新 `sch save` 并确认 `saved:true`；核对 `./tmp/sch/` 归档截图齐全，本步骤结束，进入 [`../PCB制作/PCB制作.md`](../PCB制作/PCB制作.md)。

## 判据与动机

- 未通过桥接连通性测试不得开始绘制：链路不通时写操作无落点、回读结果不可信。
- 未通过对照检查不得保存交付：先改对再落盘，避免把不合格图面存成后续基线。
- 保存以 `saved:true` 为准，daemon 防抖自动保存只作兜底，不能当作已保存。
- 检查通过前任何方案变更都会使结论失效，须重跑本步骤的对照检查。
