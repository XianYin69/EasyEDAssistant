# EasyEDAssistant Reference：系统框图

> 本文件收录「检查方案及敲定」中用字符画绘制系统框图的流程（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 流程

1. **取输入**：读取初步方案与元件清单，确认功能模块划分、电源域与对外接口（来源：处理用户需求、元件检查结论）。
2. **绘制字符画系统框图**：一个功能模块一个字符画框，框内标模块名与关键器件位号；模块间用箭头表示信号与电源流向，模块边界标注接口与电源域。
3. **节点落实核对**：每个模块节点必须能映射到方案中的实际器件或模块；映射不到的节点显式标「未落实」，不得留空或凭印象补——「未落实」须在用户确认前补映射（回元件检查/处理用户需求）或记入待办并由用户拍板取舍，否则视为框图未完成。
4. **与用户确认**：把框图摊给用户检查，用户答复「确认」即视为确认（答复内容与时间记入落盘文件决策头）；确认后进入元件关系图。**用户要求修改则按其意见重绘后再确认；同一框图「绘制↔确认」往返最多 3 轮，满轮仍不能定稿即转 [`../处理设计问题/处理设计问题.md`](../处理设计问题/处理设计问题.md) 摊牌**，不得无限返工。框图是评审材料，本身不写 EDA 图元。

## 字符画示例（示意）

```text
╭────────────────╮   +5V    ╭───────────────╮   UART   ╭──────────╮
│ 电源模块 IC1   │─────────▶│ 主控 U1       │─────────▶│ 接口 J1  │
│  [电源]        │    ⏚     │  [数字/控制]  │    ⏚     │  [接口]  │
╰────────────────╯          ╰───────┬───────╯          ╰──────────╯
                                    │ SPI
                                    ▼
                            ╭───────────────╮
                            │ 存储 U2       │
                            ╰───────────────╯
→ 信号流   ⏚ 地   [方框]=功能模块
```

## 落盘工件

- 框图落 `./tmp/design/<工程名>-block-diagram.md`；模块名与后续原理图 net 命名保持一致，便于对账。

## 判据与动机

- 框图先于原理图评审：先定模块划分与信号流，避免直接画图导致的返工。
- 模块名与 net 名一致，才能让后续 `sch connectivity` 回读与框图对得上。
- 框图不替代仿真、不替代电气检查，属规划层工件。
