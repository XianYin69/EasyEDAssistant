# EasyEDAssistant Reference：约束 — 处罚机制

> 处罚对象是「违反约束的处置」，按情节分级；处置以恢复现场与保持证据完整为先。

## 约束条款（分级处置）

1. **L1 立即改正**：命名或格式不合规、留证字段缺失、截图数量超限未清理。停止该次写入，改正后继续，不追溯。
2. **L2 回退重做**：无出处结论进入下一步、用未核实数值完成选型或改电路、跳过对账或检查宣称通过、**跳步或合并步骤执行、未写进度账目即推进、绘制期无当次截图产物仍继续落位**（见 [`../步骤门禁/步骤门禁.md`](../步骤门禁/步骤门禁.md)）。撤销该步结论，回到对应检查步骤重跑，并在报告中记录回退原因。
3. **L3 停止并通报**：运行产物写入 skill 目录或逃逸到工作区外、提交被禁文件或密钥、绕过格式门禁（`--force-unsafe`、伪造扩展名）、**运行期改写 skill 组件 / 下载可执行或 `.eext` 插件 / 执行任何检查更新或版本门禁步骤（联网查最新版本、`update --check`、`skill status`、以 `versionGate` 非 ok 阻断等——更新检查已全面禁用）/ 调用已弃用的迷宫自动布线（`pcb autoroute`、`pcb export-dsn`、`pcb import-autoroute`）/ 绕过 `route-check` 干涉演算门凭感觉落笔 / 启动 daemon 未带 `--auto-update-skill=false`**。停止任务、恢复仓库与工作区到安全状态、在交付报告中如实通报。
4. **L4 收回授权**：同一会话内重复同类违规，或用户已明确否决仍推进。收回已授权范围（不再沿用授权静默执行），后续每步走中断点逐项确认。
5. **处置通用要求**：已落盘的写操作无 undo，不得偷偷回滚或覆盖；必须报告已生效步骤、影响范围与恢复动作。
6. **处罚不换豁免**：任何处罚后的恢复路径都不得以放宽硬门、省略检查或降低留证标准为条件。

## 违规后果（本条自身的执行）

- 未按级别处置（例如该停止却继续推进、该通报却静默修正）本身构成 L3 违规。
- 争议项按 [`../约束部分.md`](../约束部分.md) 总则的裁决优先级处理，并交用户拍板。
