# 约束：布局计算纪律

> 本文件管「PCB/原理图布局与边距计算的纪律」（自然语言）。编辑遵守 RULE_EDIT.md：文本 ≤ 50 行。

## 约束条款

1. **先问排布意图**：跑 `layout-calc.py` 或进入任何放置/分区计算**之前**，必须一次向用户摊清排布需求——①功能分区有哪些、谁占大面积/谁贴边；②哪些件必须固定位置或朝向（接口/安装孔/天线/用户手摆）；③信号流方向（左→右/上→下）与模块先后；④热源与怕热件相对要求、RF 净空区；⑤对称/阵列/等距偏好与规整粒度（哪些允许 align/distribute）；⑥用户给出的参考板/草图。答复记入 `./tmp/design/<工程>-layout-intent.md`；**未拿到答复不得开始计算与落位**（P0 中断等答复，禁止代填默认或把「没提」当「随意」）。
2. **先算后摆**：用户 PCB 配置文件（D1–D20+R1–R5）全部拍板、落盘 `./tmp/design/<工程>-pcb-spec.md` 之前，Agent **禁止进入放置/布线阶段**；未落盘的配置视为未完成，不可凭经验默认。
3. **边距/位置必须先算**：进入放置后、每档器件落位前，用 [`scripts/layout-calc.py`](../../../scripts/layout-calc.py) 计算三件事——①器件→板边距（`pcb edge`）与露铜边距（默认 copper-margin 20 mil）；②同档器件间边距（`pcb gap`，手工焊档 hand 下限 40 mil、大焊盘烙铁通道 60 mil、回流焊档 reflow 下限 20 mil）；③功能分区矩形划分（`pcb zone`，gutter ≥ 50 mil）。分区与档位的**输入参数取自第 1 条排布意图答复**，不得自拟。结果三行留痕进进度账本（见计算纪律），不得口头估算直接落位。
4. **自动规整工具的使用边界**：`pcb align`/`distribute`/`auto-place`/`refine` 是**在用户意图明确、配置基线已定后的规整工具**，可用于阵列对齐、卫星件收敛、分区收口；**禁止无依据重排用户手摆件**（手摆 = P0 immovable）；调用前先复述本条边界并让 Agent 自检配置基线是否存在。
5. **走线角度默认 45°**：`angle check` 默认 `--allow 0,45`，90° 直角折线为违规；R1 档位指定圆弧档时允许 arc 代替 90° 折角。`route-check` 只验干涉，不走角度判定——角度由本步独立过门。
6. **布局计算覆盖原理图**：原理图侧同样须先问排布意图（第 1 条同等生效：分页方式、信号流、模块主次），再用 `sch gap` / `sch edge` 验模块间距（rc 80–120、ic-small 200–280、ic-mid 280–400、mcu-neighbor 400–600 raw）与贴边/禁区（标题栏 keepout）。
7. **布局文件分开 + 绘制前再次询问**：原理图布局（`./tmp/plan/<工程>-sch-layout.md`）与 PCB 布局（`./tmp/design/<工程>-pcb-layout.md`）是**两份独立文件，互不复制、互不覆盖**；PCB 落位前必须依 pcb-spec + layout-intent + 计算结果生成**字符画布局图**并**再次向用户询问布局**，拿到「按图开工」拍板前禁止放置/布线；落位偏离蓝图先追加「变更记录」并重新签核（只增不改）。正本见 [`../../PCB绘制/PCB布局图/PCB布局图.md`](../../PCB绘制/PCB布局图/PCB布局图.md)。**新建元件图**（`./tmp/newpart/<型号>-newpart.md`，引脚说明+字符画符号，建库前向用户摊技术细节并拍板）是第三份独立文件，与两张布局图互不代替（见 [`../../元件检查/新建元件与替代方案/新建元件与替代方案.md`](../../元件检查/新建元件与替代方案/新建元件与替代方案.md)）。

## 违规后果

- 未问排布意图就计算/落位，或跳过第 1–3 条直接进入放置 → 命中 **P0 中断点**：停止并回问用户，把答复与计算结果回填 `./tmp/design/` 基线后再继续。
- 调用自动规整工具而未确认第 4 条边界 → 同 **P0 中断**：先锁定用户已摆件的坐标基准（`pcb list --include-bbox --json` 快照），再执行；快照不通过则暂停执行。
- 直走直角未过 `angle check` → 布线阶段门禁（部分绘制与验收 步）阻断（exit 3）。
