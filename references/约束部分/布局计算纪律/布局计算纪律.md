# 约束：布局计算纪律

> 本文件管「PCB/原理图布局与边距计算的纪律」（自然语言）。编辑遵守 RULE_EDIT.md：文本 ≤ 50 行。

## 约束条款

1. **先算后摆**：用户 PCB 配置文件（D1–D20+R1–R5）全部拍板、落盘 `./tmp/design/<工程>-pcb-spec.md` 之前，Agent **禁止进入放置/布线阶段**；未落盘的配置视为未完成，不可凭经验默认。
2. **边距/位置必须先算**：进入放置后、每档器件落位前，用 [`scripts/layout-calc.py`](../../../scripts/layout-calc.py) 计算三件事——①器件→板边距（`pcb edge`）与露铜边距（默认 copper-margin 20 mil）；②同档器件间边距（`pcb gap`，手工焊档 hand 下限 40 mil、大焊盘烙铁通道 60 mil、回流焊档 reflow 下限 20 mil）；③功能分区矩形划分（`pcb zone`，gutter ≥ 50 mil）。结果三行留痕进进度账本（见计算纪律），不得口头估算直接落位。
3. **自动规整工具的使用边界**：`pcb align`/`distribute`/`auto-place`/`refine` 是**在用户意图明确、配置基线已定后的规整工具**，可用于阵列对齐、卫星件收敛、分区收口；**禁止无依据重排用户手摆件**（手摆 = P0 immovable）；调用前先复述本条边界并让 Agent 自检配置基线是否存在。
4. **走线角度默认 45°**：`angle check` 默认 `--allow 0,45`，90° 直角折线为违规；R1 档位指定圆弧档时允许 arc 代替 90° 折角。`route-check` 只验干涉，不走角度判定——角度由本步独立过门。
5. **布局计算覆盖原理图**：原理图侧同样须用 `sch gap` / `sch edge` 验模块间距（rc 80–120、ic-small 200–280、ic-mid 280–400、mcu-neighbor 400–600 raw）与贴边/禁区（标题栏 keepout）。

## 违规后果

- 跳过第 1–2 条直接进入放置 → 命中 **P0 中断点**：停止并回问用户配置项，把计算结果回填进配置基线后再继续。
- 调用自动规整工具而未确认第 3 条边界 → 同 **P0 中断**：先锁定用户已摆件的坐标基准（`pcb list --include-bbox --json` 快照），再执行；快照不通过则暂停执行。
- 直走直角未过 `angle check` → 布线阶段门禁（部分绘制与验收 步）阻断（exit 3）。
