# EasyEDAssistant Reference：约束 — 记忆链

> 「记忆链」指跨步骤、跨会话可反查的出处记录链：谁在什么时候依据什么得出什么结论。

## 约束条款

1. **来源三要素**：每个关键结论必须同时留下出处（手册 URL + 页码，或回读命令与文件）、时间（UTC ISO）、定责（用户拍板 / Agent 推断 / 未核实）；缺一即视为未成立。
2. **最小记忆链**：`./tmp/init/workspace-init.md`（cwd 与工作区比对）→ 方案与基线（`./tmp/design/`，含 `-pcb-spec.md`）→ 选型与手册摘要（`./tmp/parts/`、`./tmp/datasheet/`、`./tmp/downloads/index.json`）→ 检查结论与图纸（`./tmp/plan/`、`./tmp/sch/`、`./tmp/pcb/`、`./tmp/snapshots/`）→ 交付报告与手册。
3. **链文件正本**：记忆链以 `./tmp/chains/memory.jsonl` 为机器可读正本，**只经 `python <SKILL_DIR>/scripts/chain-log.py add memory` 追加**（每条含 t/step/claim/src/by），禁止手编、改写或重排既有行；初始化部分用 `chain-log.py init` 建立，推进前用 `verify` 查三要素齐备。
4. **元件归属**：每个器件须有「元件 ↔ 技术手册」所有者关系记录（MPN / URL / 版本 / 页码），后续所有检查反查此记录而不重复取数。
5. **证据链不是真值**：学习笔记、比价缓存、下载审计属证据链，可引用但不得当作新知识真值，也不得静默合并进硬编码判据；结论要改判据须走中断点请用户拍板。
6. **断链处理**：记忆链文件缺失或截图 stale 时，标注缺失工件并向用户重取；不凭对话记忆推断现场状态，恢复前先回读确认写操作已落盘。
7. **提升与清理**：记忆链随 `./tmp/` 清理；需要跨会话保留的内容必须提升为工作区正式文件或入库文档，否则视为一次性证据。

## 违规后果

- 无出处的结论 → 判「未核实」，不得进入下一步；已据此改过的方案回退。
- 静默把检索结论并入判据或标准件表 → 按 [`../处罚机制/处罚机制.md`](../处罚机制/处罚机制.md) L2 回退并走修订流程。
