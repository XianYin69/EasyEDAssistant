# EasyEDAssistant Reference：约束 — 逻辑链的存储

> 「逻辑链」指从输入到结论的推导过程本身，必须与结论一起持久化，可被他人复算。

## 约束条款

1. **四段齐备**：逻辑链 = 输入（方案参数与手册值）→ 推导（公式、代入值、单位）→ 结论（可行 / 有条件可行 / 不可行）→ 拍板（用户答复与时间），四段须在同一文件或互链文件中可追溯。
2. **存放位置**：推导落 `./tmp/calc/<topic>.md`（可配同名 json）；结论落 `./tmp/design/<工程>-feasibility.md`；逻辑框图落 `./tmp/design/<工程>-logic.md`；已拍板与未决项写各文件的「决策头」。
3. **链文件正本**：推导链以 `./tmp/chains/logic.jsonl` 为机器可读正本，**只经 `python <SKILL_DIR>/scripts/chain-log.py add logic` 追加**（每步带 `--from-node/--to-node` 节点名，供 `verify` 校验连续性）；断裂或缺四段要素即打回补链。
4. **数值带出处**：推导中每个数值须带手册页码、命令回读或规范条款出处；未读到的参数标「未核实」，不填猜测值、不据此完成选型或改电路。
5. **可复算**：公式引用判据库（含公式域）而不手抄常数；单位与 SI 前缀显式写出，避免 `mΩ` 与 `MΩ` 一类的量级误读。
6. **只增不改**：方案变更后旧链路失效，追加新链路并注明取代关系，不全量重写历史；破坏性改写须用户确认。只增不改同时是推理侧前缀缓存复用的前提（见 [`../上下文存储压缩机制/上下文存储压缩机制.md`](../上下文存储压缩机制/上下文存储压缩机制.md) 第 8 条）。
7. **双向反查**：结论须能反查到图纸与数据（引脚索引黄金表、`sch connectivity` 回读、`pcb report` 结果），不接受「只有结论、没有链路」的存储。

## 违规后果

- 只给结论不给推导 → 打回重做，该结论不计入通过项。
- 用未核实数值推进选型或改动电路 → 立即停止并回退该步骤，按 [`../处罚机制/处罚机制.md`](../处罚机制/处罚机制.md) L2。
