# EasyEDAssistant Reference：约束 — 计算纪律

> 本文件是「设计执行期数值计算」的正本（自然语言）：一切电气/设计数值必须经三件计算器演算并留痕，
> 禁止心算、禁止无记录的外部工具。编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 三件计算器（本地、零联网、只打印不落盘）

| 工具 | 角色 | 调用 |
|---|---|---|
| 科学计算器 | 表达式/SI 前缀（2k·10u）/复数阻抗（直角↔极坐标）/单位换算 | `python <SKILL_DIR>/scripts/calc-scientific.py '<expr>' [--var K=V] [--format polar] [--convert '10mil mm']` |
| 电气计算器 | 欧姆/分压(E24)/LED 限流/RC-fc/**IPC-2152 载流档**/过孔载流/**Hammerstad 阻抗近似**/λ4/dB | `python <SKILL_DIR>/scripts/calc-electrical.py <子命令> …` |
| 设计计算器 | **LDO 热预算**/BUCK 电感与输出电容/电池续航/晶振 CL/电阻串并联容差(worst·RSS)/铜面散热近似 | `python <SKILL_DIR>/scripts/calc-design.py <子命令> …` |

`--help` 查全部子命令与参数；参数一律支持 SI 前缀书写。

## 纪律

1. **凡进入方案、参数表、图纸或进度账本的数值，先过计算器**：欧姆定律及以上公式一律三件计算器演算；心算、估写在聊天里"顺手带过"的数值不得进基线。
2. **留痕**：计算器输出三行（公式/代入/结果）整行复制进账目 `cmd:` 字段或对应证据文件（如去耦表、阻抗表旁）；无演算记录的数值视同未核实。
3. **档位取严**：`ipc2152`/`via-current`/`copper-heat` 输出为标准公式/经验近似，与 [`../../电气检查/硬编码规则/PCB/间距与线宽.md`](../../电气检查/硬编码规则/PCB/间距与线宽.md)、[`../../电气检查/硬编码规则/PCB/载流与温升.md`](../../电气检查/硬编码规则/PCB/载流与温升.md) 及板厂当季参数冲突时**取更严者**；`impedance` 明示 ±10% 近似——正式阻抗以板厂叠层工具复核（走浏览器检索步骤）。
4. **干涉演算不互替**：PCB 走线段落笔前仍必过 `route-check.py`（几何门）；计算器的 IPC 档只给"多宽能载多大流"，不判"这根线撞不撞"。
5. **近似声明**：脚本中标注"经验/近似/保守"的字样必须原样转述给用户，不得把近似值包装成精确值。
6. 三件计算器不写文件、不联网、无副作用；退出码 0 成功 / 2 参数错误——参数错误不得靠凑数绕过。
