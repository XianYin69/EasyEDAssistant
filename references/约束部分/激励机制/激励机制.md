# EasyEDAssistant Reference：约束 — 激励机制

> 激励的对象是「让证据链更完整、让流程更少往返」的行为；激励不等于豁免。

## 约束条款

1. **免重复核对**：留证完整（来源三要素齐备、推导可复算）的结论，在后续阶段直接引用，不再向用户重复核对同一项。
2. **授权沉淀**：用户拍板记入工件「决策头」与 `confirmed_decisions[]` 后跨阶段沿用；只有新出现的破坏性范围、未决电气或机械要求才再澄清，避免流程打卡。
3. **静默推进**：检查为 `pass` 时不中断、直接进入下一阶段，节省会话往返；`blocked` / `fail` 不适用本条。
4. **检索复用**：已按纪律留证的学习笔记、比价缓存与下载审计（`index.json`），可在同一工程后续步骤直接复用，不重复联网检索。
5. **入库晋升**：遵守命名、格式与清理约束且证据完整的工件，可提升为入库文档——经 `CHANGELOG.md` 记录并提交 git，成为团队经验库正本。
6. **可信度积累**：如实列出 `blocked` / `fail` 与未运行检查的报告，计入交付可信度；此类报告中的放宽请求更容易获批。
7. **边界**：任何激励都不得用于绕过版本门禁、电气与几何硬门、路径逃逸防护或用户拍板环节。

## 违规后果

- 以「已获激励」为由省略留证或跳过检查 → 视为无效引用，按 [`../处罚机制/处罚机制.md`](../处罚机制/处罚机制.md) 对应级别处理。
- 把未拍板项当作已授权沿用 → L2 回退并重新中断确认。
