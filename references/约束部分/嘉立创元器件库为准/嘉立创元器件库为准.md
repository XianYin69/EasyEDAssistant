# EasyEDAssistant Reference：约束 — 嘉立创元器件库为准

> 本文件是「元器件身份以嘉立创 EDA 系统库为唯一真值」硬门禁的正本（自然语言）。

## 约束条款

1. **唯一真值源**：一切器件选型、放置、换绑、BOM 以嘉立创 EDA 系统库（含立创商城 LCSC C 号）为准，经 `easyeda lib search` / `easyeda lib by-lcsc` 解析出 `libraryUuid + uuid` 后方可落图；放置参数只能来自该解析结果。
2. **选型链顺序**：`blocks search` → `lib search` / `lib by-lcsc` → `parts-select.py`（`--online` 查嘉立创实时目录，basic/preferred/库存/价格排序）；禁止用搜索引擎结果、第三方库或记忆中的 UUID 直接放置。
3. **非嘉立创库器件＝豁免门禁**：需要个人库/社区库/第三方库器件时，必须先向用户出示差异（库来源、封装核验结果），经用户拍板并在 `./tmp/chains/memory.jsonl` 记录豁免（`--by user`）后方可使用；不得静默替换或混用。
4. **新建元件**：封装/符号不符或**库中确无该器件**（`lib search`/`lib by-lcsc` 无身份）时，按元件检查流程以 `lib symbol`/`lib footprint`/`lib device build` 新建，**几何唯一依据是该器件技术文档**（`./tmp/datasheet/` 摘要 + 下载手册原件，缺的尺寸标「未核实」回问用户，不得猜值）；新建件须回读验证并登记入选型链；新建失败同一元件最多 2 次尝试，超限走替代方案或中断处理设计问题。
5. **LCSC C 号锚点**：每个通过检查的器件在记忆链登记 MPN ↔ LCSC C 号 ↔ deviceUuid 归属关系；BOM 交付前用 `bom-enrich.py` 补全 C 号，无法解析出 C 号的器件不得进入交付 BOM。

## 违规后果

- 未经 `lib` 解析直接放置、或放置参数与 `lib by-lcsc` 结果不符 → 该器件判定无效，撤销落位并回退本步，按 [`../处罚机制/处罚机制.md`](../处罚机制/处罚机制.md) L2。
- 静默使用非嘉立创库器件（无用户拍板、无豁免链记录）→ L2 回退 + 补记豁免链；重复 ≥2 次 → L4 收回授权。
