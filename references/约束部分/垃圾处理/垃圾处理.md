# EasyEDAssistant Reference：约束 — 垃圾处理

> 「垃圾」指运行产物、缓存与被禁格式文件污染版本库或工作区。

## 约束条款

1. **产物只落工作区**：截图、清单、回读 JSON、蓝图一律写 `./tmp/` 对应子目录（相对 `cwd`）；禁止写入 skill 目录，禁止 `../` 逃逸到工作区外。
2. **先交付后清理**：工作结束时按序执行——生成技术手册与功能手册与交付报告 → 需保留的图片导出到正式路径 → 再删除 `./tmp/` 全部子目录与文件，并在报告中记录删除清单摘要（目录 → 文件数）。
3. **数量上限**：快照类产物只保留最近 3 张关键截图，超过即丢弃更早的；基线截图会话结束清理。
4. **不入库**：`tmp/` 必须在 `.gitignore` 中；禁止创建或提交 `.txt`、`.log`、`.tmp`、`.bak`、`.old`、`*.pyc`、`__pycache__/`、`*.swp`、编辑器临时文件与环境注入目录（`.kilo/`）。
5. **暂存自律**：提交前先看 `git status`，只暂存本次意图文件，不用全量暂存吞掉无关产物。
6. **异常收尾**：中断或异常结束同样执行清理，未完成部分在报告中注明缺失工件；用户明确要求保留时不删，仅提示其不入库。

## 违规后果

- 产物落入 skill 目录或工作区外 → 立即停止、移出并恢复版本库到安全状态，按 [`../处罚机制/处罚机制.md`](../处罚机制/处罚机制.md) L3。
- 被禁格式文件入库 → 撤销该文件与相关提交；紧急修复产生的临时文件未即时清理 → L1 改正。
