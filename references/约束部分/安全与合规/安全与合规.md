# EasyEDAssistant Reference：约束 — 安全与合规

> 本文件是「文件内容安全、权限与版本控制」正本（自然语言），由 `FILE_CREATION_POLICY.md` v2.0 迁入。

## 约束条款

1. **内容安全**：任何新建或修改的文件不得包含 API 密钥、账号口令、令牌、内部文档或内网地址；示例与夹具一律用占位值（`<project>`、`C123456`、`127.0.0.1`）。
2. **提交前自查**：提交前看 diff，确认无凭据、无运行产物、无被禁格式；一旦发现密钥类内容入库，立即撤销该提交范围并通知用户轮换凭据，不得只在后续提交里删除（历史仍可见）。
3. **路径与逃逸**：一切读写限定在工作区根及其子目录；参数清洗与工作区边界校验的正本在 [`../../../FILE_CREATION_POLICY.md`](../../../FILE_CREATION_POLICY.md) §3（Path Traversal Guard），不得绕过。
4. **下载与外部资源**：格式白/黑名单、协议限制、大小上限与审计以 [`../../../scripts/net-download-policy.md`](../../../scripts/net-download-policy.md) 为准；不存在 `--force` 越过判定；两处常量与文档不一致时以策略文件为准并同步脚本。
5. **权限控制**：不为新建文件放宽文件权限或添加可执行位；不修改 `.gitignore` 既有排除项来「让产物入库」；目录创建只走 [`../创建操作流程/创建操作流程.md`](../创建操作流程/创建操作流程.md) 的审批路径。
6. **版本控制**：运行产物与 tmp 内容不入库；`.kilo/` 等环境注入文件不入库；长期保留的外部资料须先由用户指定正式目录再复制，随后清理 tmp。

## 违规后果

- 敏感信息入库、绕过路径校验或格式门禁 → [`../处罚机制/处罚机制.md`](../处罚机制/处罚机制.md) L3：停止任务、恢复安全状态、在交付报告中通报。
- 权限或 `.gitignore` 被放宽 → L1 立即还原；重复发生升 L4 收回授权。
