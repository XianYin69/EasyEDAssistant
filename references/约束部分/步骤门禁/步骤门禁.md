# EasyEDAssistant Reference：约束 — 步骤门禁

> 本文件是「逐步执行」的正本：防跳步、防合并、防漏留证、绘制期强制截图。
> 任一条触发即按违规后果处置，不由 Agent 自行判定「不适用」或「本次可省」。

## 约束条款

1. **逐步铁律**：标准流程六步（初始化部分 → 处理用户需求 → 检查方案及敲定 → 原理图制作 → PCB制作 → 交付与清理）必须**按序逐步**执行；禁止跳步、禁止合并多步、禁止跳过子步骤、禁止把后续步骤的产物提前产出以「省事」。
2. **未留证不推进**：每步完成必须在 `./tmp/init/progress.md` 追加账目，字段齐全（步骤号与名 / 时间 UTC / 证据命令 / 证据产物路径 / 结果）；缺任一字段，或产物路径不存在 → 该步视为**未完成**。
3. **边界自检**：进入下一步前必须逐条回答——① 上一步完成判据（见该步文档）是否逐条满足？② 证据产物是否已落盘且可回读？③ 是否有未决项或未运行检查被当成了通过？任一为否 → 停在原步，不得推进。
4. **绘制期截图硬门**：绘制原理图/PCB 期间，**每落位、移动或修改一个器件必须当次产出截图产物**（`visual-qa.py` 的截图路径，`sch-`/`pcb-` 前缀）且 `exit 0`；**本次落位无新截图产物 = 该件未完成 = 禁止落位下一个**。禁止整批落位后统一补截，禁止以「稍后补」「时间不够」跳过。
5. **机器门禁优先**：PCB 阶段推进必须走 `easyeda workflow status/advance` 与 `pcb stage confirm-tier/confirm-layout/confirm-outline`；未确认时路由类命令会被 CLI 拒绝，不得用 `--force` 绕过。
6. **失败不得静默跳过**：`visual-qa.py` 退出 3 或命令报错 → 重试（同一件 ≤2 次）后仍失败即命中中断点，保持暂停态并如实报告；不得跳过核验继续画。
7. **回退只重跑未通过项**：回退后仅重跑未通过项及其受影响项，不整段重跑；但不得以「增量」为名跳过必跑项。

## 进度账本格式（`./tmp/init/progress.md`）

每步一条（子步骤另起一行）；字段以 `|` 分隔：

```text
- [x] <步骤号> <步骤名> | t: <UTC ISO> | cmd: <证据命令> | art: <产物路径> | result: <pass|fail|blocked>

- [x] 1 初始化部分 | t: 2026-09-17T01:00:00Z | cmd: easyeda health | art: ./tmp/init/workspace-init.md | result: pass
```

校验：`python scripts/check-progress.py`（缺步 / 缺字段 / 产物不存在 → 退出码 1 并列出待补项）。
**写入一律用 `python scripts/progress-log.py --step N --name <名> --cmd <命令> --art <产物> --result pass|fail|blocked`**（幂等：同步一步只留一条；cwd 在 skill 仓库会被拒绝），不要手编文本。

## 违规后果

- 跳步、合并步骤、未留证推进、跳过边界自检 → 按 [`../处罚机制/处罚机制.md`](../处罚机制/处罚机制.md) **L2**：撤销该步结论，回退到最早未完成的步骤重做，并在交付报告记录回退原因。
- 绘制期无截图产物仍继续落位 → 同样 L2；已落器件须逐件补跑核验后才算完成。
- 同一会话重复同类违规 ≥2 次 → **L4** 收回授权，后续每步先经用户确认再执行。
