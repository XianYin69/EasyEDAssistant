# EasyEDAssistant Reference：约束 — 文件与文件夹创建范围

> 本文件是「允许 / 禁止创建哪些文件与文件夹」的正本（自然语言），由 `FILE_CREATION_POLICY.md` v2.0 迁入。

## 约束条款

1. **工作区（设计执行期）**：允许在工作区 `./tmp/` 的契约子目录内创建产物——`init/`、`sch/`、`pcb/`、`plan/`、`design/`、`parts/`、`calc/`、`datasheet/`、`snapshots/`、`baseline/`、`learning/`、`downloads/`（含 `datasheet|docs|images|data|edalib|manufacturing` 子目录与 `index.json`）；允许在工作区根目录创建项目交付文档（技术手册、功能手册、交付报告）与用户指定的正式交付目录。
2. **skill 仓库（编辑期，配合 [`../../../RULE_EDIT.md`](../../../RULE_EDIT.md)）**：根目录只修改既有文件（`SKILL.md`、`RULE_EDIT.md`、`FILE_CREATION_POLICY.md`、`README.md`、`CHANGELOG.md`），不在根目录新建文件夹；`scripts/` 存 `.py` 与其配套 `.md` 政策；`references/lib/` 存 `.md`/`.json` 正本文件；`agents/` 只存 `.yaml`/`.json` 定义；`references/` 存 `.md`，允许按「总索引 + 子文件」建子文件夹（主文档与文件夹同名、子文件与其子文件夹同名），新增步骤文档须登记 `SKILL.md` 路由；`Sample/` 目录存上游 skill 存档（仅 `.md` 与 `LICENSE`）。
3. **禁止类型（任何位置）**：`.txt`、`.log`、`.tmp`、`.temp`、`*.bak`、`*.old`、`*.pyc`、`__pycache__/`、`*.swp`、`*~`、环境注入目录（`.kilo/`）产物；含密钥、凭据、内部地址或敏感文档的文件。
4. **禁止位置**：skill 目录内的 `tmp/` 或任何运行产物目录；工作区根以外的任意目录（含 `../` 向上逃逸）；`Sample/`、`agents/` 下的新子文件夹。
5. **例外**：位于**工作区** `./tmp/` 下的运行产物子目录是允许且必需的，前提是被工作区 `.gitignore` 排除；「禁止临时工作目录」针对的是 skill 目录内或工作区外的临时目录。

## 违规后果

- 类型或位置不合规 → 立即停止并改正（[`../处罚机制/处罚机制.md`](../处罚机制/处罚机制.md) L1）。
- 产物落入 skill 目录或逃逸工作区、提交被禁文件 → L3 停止并通报。
