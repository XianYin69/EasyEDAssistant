# EasyEDAssistant Reference：约束 — 运行环境不可变

> 本文件是「设计执行期运行环境不可变」的正本（自然语言）：skill 本体只读、禁下载可执行与 EDA 插件、禁查最新版本、connector 版本钉定（只回退、不升级）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 一、skill 本体只读（禁止运行期自我更新）

1. 设计执行期**禁止任何改写 skill 目录组件的行为**：不得执行 `easyeda skill sync`、`easyeda skill status`、`easyeda update`（含 `--skill-only`）、`easyeda update --version/--local-dir`，也不得用 `write`/`edit`/复制等方式改动 `SKILL.md`、`references/`、`scripts/`、`agents/`、`Sample/`、`CHANGELOG.md`（那些改动只能由人按 [`../../../RULE_EDIT.md`](../../../RULE_EDIT.md) 在编辑期做）。
2. **启动 daemon 必须显式关闭技能自同步**：`easyeda daemon start --auto-update-skill=false`，并建议设 `EASYEDA_SKILL_PRESERVE=1`。daemon 的 `--auto-update-skill` **默认为 on**，启动时会静默覆写已安装的 skill 目录（`~/.claude/skills`、`~/.codex/skills`、`~/.agents/skills`）——这是运行期改 skill 的主要通道，不加该参数即违规。
3. 发现 skill 目录被外部改写（版本或内容突变、出现非本次编辑的 diff）→ 立即停止任务、保留现场并报告用户，不得就地续跑或自行恢复。

## 二、禁下载可执行文件与 EDA 插件

4. 禁止下载或落地任何可执行体与 EDA 插件包：`.exe` `.dll` `.so` `.dylib` `.bin` `.com`、脚本 `.sh` `.ps1` `.bat` `.cmd` `.vbs` `.js` `.jar`、归档 `.zip` `.rar` `.7z` `.tar` `.gz` 等，以及 **EDA 插件/扩展包 `.eext`**（含任何 marketplace/侧载扩展、`.esmt`、插件清单包）。
5. 唯一取物通道是 `python <SKILL_DIR>/scripts/net-download.py`，其黑名单为权威拦截点；**没有任何参数能越过格式判定**（无 `--force`、也无 `--yes`）。用户手工提供的插件包也不得由 Agent 安装或导入 EDA。
6. 需要插件/新能力时只能**报告并请用户在其环境外自行安装**，安装动作不属于本 skill 的设计执行期。

## 三、更新检查全面禁用（不查 latest，也不做版本门禁）

7. 禁止一切「检查更新」类步骤（用户指令 2026-09-18）：不跑 `easyeda update --check`、`--check --exit-code`、`easyeda skill status/sync`（其语义即 "installed vs latest release"），不访问 GitHub Release 比版本。**本机版本对齐同样不再是门禁**：`versionGate` 非 ok 不阻断、不判 blocked、不要求新开会话。
8. 会话自检只剩两件事（`python <SKILL_DIR>/scripts/link-probe.py`，零联网）：链路探活 + `compat` 接口漂移探测（`--help` 自描述，漂移只 WARN 不阻断，脚本按 `cli_compat` 自适应降级）；`versionGate`/组件版本**仅记录进报告**备查。移除版本判定的理由：它自身曾是断点（误解析即误杀），而其合法修复渠道（升级）被本约束禁止——判定与处置脱节的预检不成立。
9. 行为异常时的离线真值通道：对照**本地 connector 源码快照**——`python <SKILL_DIR>/scripts/connector-src/eext-src.py report|apis|verify`（正本 `Sample/easyeda-agent-connector/`，含上游 `extension/` 全部 TS 源与 tag/commit/sha256 清单），以源码为真值而不是以版本比对为真值。
10. `health` 完全不可达 ≠ 版本问题：按链路不通走桥接排查环；确需组件升级才可继续时 → 记 `blocked` 写清「需用户在维护窗口自行处理」并等用户新开会话，Agent 不得代查代升。

## 四、connector 版本钉定（只回退，不升级）

11. 本项目**只使用且只基于钉定版本的 connector 开发**：钉定值 = 源码快照 `.snapshot.json` 的 `connector_version`（当前 v1.5.1，随快照更新而改，勿在别处硬编码数字）。CLI/daemon/connector 三件套都应处于钉定线；patch 级漂移按上游规则同 major.minor 内兼容，但 connector 以钉定包为准。
12. **一切自动更新通道关闭**：插件市场不启用/装后立即关掉「原地自动更新」；daemon 保持 `--auto-update-skill=false`；对 EDA 市场升级弹窗、release 通知一律不响应（响应=违规，检查更新本就禁用）。
13. 发现任何非钉定版本（link-probe `version_gate.pin.mismatch`，或用户在扩展管理器看到版本 ≠ 钉定）→ **处置方向是删除新版、回到钉定版**：用户在维护窗口卸载高版本 connector，用 `python <SKILL_DIR>/scripts/connector-src/eext-src.py eext` 取钉定包重导入并完全重启 EDA；Agent 职责＝检测、如实报告、给出该指引，**不得代卸/代装**。

## 违规后果

- 运行期改 skill 组件、启动 daemon 未带 `--auto-update-skill=false`、下载可执行/`.eext`、执行任何检查更新/版本门禁步骤 → [`../处罚机制/处罚机制.md`](../处罚机制/处罚机制.md) **L3**：停止任务、恢复环境原状、在交付报告中通报。
- 检测到 connector/组件版本偏离钉定而**未报告**，或代用户装卸/升级插件、接受市场自动更新 → 同 **L3**。
- 同一会话重复发生 → **L4** 收回授权。
