# PCB 设计规范与必答清单（PCB Design Spec Checklist）

> SKILL.md §4.2 / §11.2 / §11.5 / §13.3 引用的**运行时清单正本**：
> Agent 进入 PCB 阶段（P0 起）前，须逐项向用户核对本文件的
> **§2 必答清单**；用户答复落到**工作区** `./tmp/design/<project>-pcb-spec.md`
> 作为设计基线；未拍板前不进入 `pcb import-changes` 与四档放置（§4.2）。
> 与 §4.2/§4.7/§4.8 判据表互补——本文件是"问用户要什么"，那些节是"定了之后怎么做"。

## 2. 必答清单（Agent 在 P0 逐项向用户核对）

| # | 决策项 | 提问要点 | 影响 |
|---|---|---|---|
| D1 | **板框尺寸与形状** | 长 × 宽（mm）、圆角半径、异形边？有机械图还是先粗布后收紧？ | P0 immovable 参考；`pcb outline-round` / `outline-fit` |
| D2 | **安装孔规格** | 数量（默认四角）、M2.5/M3/M4、孔心距板边（≥3 mm）、铜柱/沉头 | `pcb mount-holes` keep-out 半径 |
| D3 | **叠层结构** | 2 层 / 4 层 / 6 层；每层用途（TOP/GND/PWR/BOT 或信号分区）；总厚度 | §4.7 PLANE 生成顺序；`pcb power-planes` |
| D4 | **铜厚** | 1 oz（默认）/ 2 oz / 内外层分别？ | 电流线宽分档（§4.7 表） |
| D5 | **电源轨清单** | 每条轨的电压、峰值电流、来源（外部/板载 buck/LDO） | 线宽分级、bulk 电容、铺铜策略 |
| D6 | **接地策略** | 单 GND / AGND+DGND / 加 PGND；几处地平面 | §4.4 星形/割地；§4.7 内电层 |
| D7 | **阻抗控制网络** | 单端 50Ω 与差分 100Ω 具体哪些 net；参考层与线宽目标 | §4.3 RF 匹配；`pcb report` 验收 |
| D8 | **关键接口位置** | USB/DC jack/HDMI/天线/排针/按键：所在边、开口朝向、拔插走廊 ≥200 mil | P0 immovable；§4.2 边缘连接器 |
| D9 | **RF 天线形式** | PCB 天线 / 陶瓷 / IPEX 外接；频段；净空半径 | §4.3 全层 keepout |
| D10 | **封装下限** | 手焊（0603）/ 回流（0402/QFN 可用）；混合？ | §4.9 手焊/贴片；`layout-lint --gate` |
| D11 | **热预算** | >0.5 W 器件清单；自然对流 / 强制风冷 / 散热铜皮 / 金属壳传导 | §4.9 热 keep-out；`>500 mil` 开阔铜 |
| D12 | **测试点覆盖** | 关键 net / 每条电源轨是否有 TP；探测面（顶/底）；pad ≥40 mil | §4.9 测试点集中 |
| D13 | **丝印规范** | 位号/极性/逐脚功能/厂商 logo/日期码；装配后可见；镜像处理 | §4.2 丝印；`pcb layout-score --only tidy` |
| D14 | **隔离/安全间距** | 是否有 HV/LV 隔离；爬电/间隙要求（IEC 62368）；开槽 | §4.1 P1；§4.5 隔离 |
| D15 | **DFM 目标厂** | JLCPCB（默认，`fab-rules-jlcpcb.json`）/ 华秋 / 其他 | 最小线宽/间距/via 尺寸 |
| D16 | **拼板 / 单片** | 是否 panelize；V-cut / 邮票孔；工艺边宽 | 制造阶段决策 |
| D17 | **颜色与阻焊** | 绿/黑/白/哑光；开金手指/沉金/OSP | 制造文件 |
| D18 | **未用引脚策略** | 显式 NC / 上拉 / 接地；不悬空 | §4.5 数字电路 |
| D19 | **成本档位** | Basic part（免 feeder 费）优先 vs 全 standard 表；量产数量 | §5.6 选型 |
| D20 | **交付验收线** | `pcb drc` 0 fatal + WARN 清单？`pcb check` DFM 全通？`layout-lint --gate` pass？ | §8.1 五层验证 |

## 4. 与 §11.5 中断机制的关系

- **强制中断**（D1/D2/D8 未定即不能开工，P0 immovable）
- **条件中断**（D3–D7、D9–D20 缺则影响设计或超范围；已授权或唯一正确答案则静默通过）

## 5. 常见陷阱（问漏 / 猜错代价）

- 未问 D4 铜厚 → 电源轨线宽默认 1 oz 算，实际 2 oz 需求 → DRC 大面积过细。
- 未问 D6 地策略 → 4 层用双 PLANE 后发现要 AGND/DGND → 只能全 SIGNAL 分区 pour 返工。
- 未问 D8 接口位置 → 主芯片已摆好才发现 USB 对侧 → T1 重排。
- 未问 D9 天线形式 → 板框固定才知要外接 IPEX → 板边无空间。
- 未问 D10 封装下限 → 布局完成才发现用户手焊，0402 全部返工 0603。
