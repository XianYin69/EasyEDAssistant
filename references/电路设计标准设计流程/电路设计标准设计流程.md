# EasyEDAssistant Reference：电路设计标准设计流程

> 本文件是「电路板设计标准设计流程」的总索引；SKILL.md §2「第一次设计」时执行。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行。

## 流程

电路板设计标准设计流程依次执行六步：先进行「初始化部分」（见 [`../初始化部分/初始化部分.md`](../初始化部分/初始化部分.md)：询问工作区路径、建立 ./tmp/、建立初始化文件）；然后「处理用户需求」（见 [`../处理用户需求/处理用户需求.md`](../处理用户需求/处理用户需求.md)：澄清需求、明确目标与验收标准）；接着「检查方案及敲定」（见 [`../检查方案及敲定/检查方案及敲定.md`](../检查方案及敲定/检查方案及敲定.md)：方案评审、强制中断点拍板）；再进行「原理图制作」（见 [`../原理图制作/原理图制作.md`](../原理图制作/原理图制作.md)：桥接连通性测试 → 绘制原理图 → 对照技术手册及方案检查 → 保存）；然后「PCB制作」（见 [`../PCB制作/PCB制作.md`](../PCB制作/PCB制作.md)：读取 PCB 设计规范与用户配置文件 → 绘制 PCB → DRC 检查 → 保存）；最后进行「交付与清理」（见 [`../交付与清理/交付与清理.md`](../交付与清理/交付与清理.md)：生成交付文档 → 用户确认 → 交付报告 → 清理 ./tmp/）。

## 逐步执行门禁（强制）

> 六步必须**按序逐步**执行，禁止跳步、合并步骤、跳过子步骤：见 [`../约束部分/步骤门禁/步骤门禁.md`](../约束部分/步骤门禁/步骤门禁.md)。
> 每步完成须在 `./tmp/init/progress.md` 留账目（步骤号与名 / 时间 / 证据命令 / 产物路径 / 结果），缺项或产物不存在则**不得推进**；校验 `python scripts/check-progress.py`。
