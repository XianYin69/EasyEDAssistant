# EasyEDAssistant Reference：成本及预算检查

> 本文件收录「成本及预算检查」步骤的流程（自然语言）。触发时机：检查方案及敲定第 1 项检查。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 流程

1. **询问用户预算及期望成本**：问清单板目标成本、总预算与批量档位（如 1/100/1000 片）；用户未给出时不得假设，留空继续会失去判定基准。
2. **联网查询价格**：调用 [`../浏览器检索/浏览器检索.md`](../浏览器检索/浏览器检索.md) 子流程，按 BOM 逐料查询立创商城/DigiKey/Mouser 等渠道，取用户批量档对应单价为准（跨档价仅作趋势）。
3. **计算成本**：单片成本 = Σ(料价 × 数量 × 损耗率) + 板厂制板/贴片工程费分摊 + 结构/包装件；损耗率取用户给定值，未给定时默认 5% 并在方案文件决策头标注「默认值待确认」；汇总列表落 `./tmp/` 方案文件。
4. **判断是否超过用户预算**：未超 → 标记「通过成本及预算检查」，并把成本数字、批量档与取价时间写入方案文件、在后续交付报告中提示（自动通过也须留痕供用户复核）；超出 → 进入第 5 步。
5. **联网查询替代方案**：再次调用 [`../浏览器检索/浏览器检索.md`](../浏览器检索/浏览器检索.md) 检索参数等效、价格更低的替代料号（引脚兼容优先），列「原器件 vs 替代器件」关键参数与价差对照表。
6. **询问用户是否接受替代方案**：接受 → 修改方案（BOM 与原理图选型更新；替代料换绑走 [`../元件检查/新建元件与替代方案/新建元件与替代方案.md`](../元件检查/新建元件与替代方案/新建元件与替代方案.md)，指令条目见 [`../嘉立创EDA指令索引/器件库与块/器件库与块.md`](../嘉立创EDA指令索引/器件库与块/器件库与块.md)），跳回第 2 步重新查价核算，通过后标记「通过成本及预算检查」；不接受 → 进入第 7 步。
7. **询问用户是否接受采用原方案**：接受 → 标记「通过成本及预算检查」，并把超预算原因与用户决定记入方案文件；不接受 → 回到第 5 步继续联网查询替代方案。第 5～7 步合计最多 3 轮；满 3 轮仍无更优替代或用户仍不接受时停止自动循环，改为向用户摊牌（继续检索 / 接受原方案 / 调整需求或预算 / 中止本步骤），未获答复保持暂停态。

## 判据与动机

- 方案任何一次变更后，旧成本结论即失效：必须回第 2 步重算，禁止沿用旧数标记通过。
- 检索无更优替代时如实报告「无更优方案」，仍走第 7 步由用户拍板；不得静默超预算通过。
- 价格记录须含时间/渠道/批量档三要素（浏览器检索纪律：是证据链不是永久真值），复跑检查时允许重新取价。
