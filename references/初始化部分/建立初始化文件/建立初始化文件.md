# EasyEDAssistant Reference：建立初始化文件

> 本文件收录 `cwd` 与 `tmp/` 就绪后读取工程基线、生成工具探针清单及保存基线截图的规定。
> 原正本出处：`references/lib/connection-setup.md` §2（第 2、6、7 步）。

## 初始化文件与工件清单

在工作区 `./tmp/` 准备就绪后，Agent 必须自动完成以下初始化读盘与工件生成：

### 1. 读取目标工程基线（第 2 步）

运行底层 API/CLI 获取工程上下文，确保对目标项目状态完全可见：

```bash
easyeda health --project <project>
easyeda doc ls --project <project> --json
easyeda sch connectivity --all-pages --project <project> > project-connectivity.json
easyeda sch list --project <project> --doc <page-uuid> \
  --include-device-identity --include-pins --include-bbox --include-wires > page-before.json
easyeda sch sheet-geometry --project <project> --doc <page-uuid> --json
```

### 2. 工具与插件探针（第 6 步）

Agent 必须自动运行工具探针脚本获取嘉立创 EDA 内建工具与已安装插件清单：

```bash
python3 scripts/tool-probe.py --project <project>
```

- **产出**：
  - `./tmp/eda-tools-manifest.json`
  - `./tmp/eda-tools-guide.md`
- **用途**：供后续设计步骤查阅并按需调用专用工具或插件（如导入/导出、高级布线、铺铜管理等）。

### 3. 基线截图（第 7 步）

读取工程基线（原理图 PDF 导图或 PCB 视口快照）后，**Agent 自动保存**首张截图：

- **路径**：`./tmp/baseline/<timestamp>-baseline.png`（自动按时间戳命名）。
- **用途**：作为后续差异对比、`visual-qa.py` 评估及复盘的参考基准。
