# EasyEDAssistant Reference：向用户询问工作区路径

> 本文件收录会话建立与端口连通后"向用户询问工作区绝对路径并确认 `cwd`"的规定。
> 原正本出处：`references/lib/connection-setup.md` §1.1 / §1.2；SKILL.md 主干 §1。

## 规则与判据

- **触发时机**：端口连通（MCP HTTP `7655` 成功，或 daemon `60832` 成功）后、
  **先于任何**工程读取、离线规划、`health` 和 EDA 操作。
- **询问动作**：Agent 主动向用户询问其 EDA 工程（原理图/PCB 文件所在目录）的**绝对路径**。
- **比对与确认**：
  1. 将用户提供的绝对路径与 Kilocode 会话报告的 `workspace root` 进行比对。
  2. **以用户指定的绝对路径作为本会话的运行时根目录 `cwd`**（所有运行产物 `./tmp/`、
     截图、回读 JSON、导图的落地根）。
  3. 用户指定路径与 Kilocode `workspace root` 不一致时，**以用户指定路径为准**，
     并提示用户确认当前会话的工作区是否与该路径匹配。

## 动机与安全约束

- **防止逃逸**：决定权从"隐式继承 Kilocode `workspace root`"改为"显式向用户核对"，
  确保运行产物不会误落入 skill 目录（`~/.kilocode/skills/EasyEDAssistant/`）
  或错误工程目录。
- **遵守 `FILE_CREATION_POLICY.md`**：所有产物解析到 `cwd`；`Path(__file__)` 派生位置
  指向 skill 目录，禁止用于运行产物。
