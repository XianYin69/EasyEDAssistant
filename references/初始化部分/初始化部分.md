# EasyEDAssistant Reference：初始化部分

> 本文件是会话初始化流程的总览（功能正本在 `references/lib/connection-setup.md` §1、§2，
> 对应 SKILL.md 主干 §1 连接速览与 §3 工作主线第 1–7 步）。
> 初始化拆为三个环节，各由本目录同名子文件夹内的 markdown 展开：
> **向用户询问工作区路径 → 在工作区建立tmp文件夹 → 建立初始化文件**。

## 初始化流程（按序执行）

1. **向用户询问工作区路径**——端口连通后、任何工程读写前确认运行时 `cwd`。
   详见 [`向用户询问工作区路径/向用户询问工作区路径.md`](向用户询问工作区路径/向用户询问工作区路径.md)。
2. **在工作区建立tmp文件夹**——`cwd` 确认后建立 `./tmp/` 及初始化所需子目录。
   详见 [`在工作区建立tmp文件夹/在工作区建立tmp文件夹.md`](在工作区建立tmp文件夹/在工作区建立tmp文件夹.md)。
3. **建立初始化文件**——基线 JSON、工具与插件清单、基线截图。
   详见 [`建立初始化文件/建立初始化文件.md`](建立初始化文件/建立初始化文件.md)。

## 前置与边界

- 初始化在链路选择完成后进行：MCP 与 CLI/daemon 是**替代关系非级联备用**，
  先 `7655`（MCP HTTP）后 `60832`（daemon），检到可用链路即全程使用、不重试另一条
  （正本：`references/lib/connection-setup.md` §1.1）。
- **版本门禁先于一切**：CLI/daemon 链路会话第一条命令
  `easyeda update --check --exit-code`，非 0 停止任务并报告版本差异，
  升级后必须新开会话（正本：`references/lib/connection-setup.md` §1.2）。
- 运行产物禁止写入 skill 目录、禁止逃逸出工作区
  （`FILE_CREATION_POLICY.md` §1.3/§2.4/§5.2）；所有产物落工作区 `./tmp/`
  （目录契约正本：`references/lib/verification-delivery.md` §8.4）。
- 初始化完成后回到主干 §3 工作主线继续（澄清需求 §11、子域判据 §4 等）。
