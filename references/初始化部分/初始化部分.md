# EasyEDAssistant Reference：初始化部分

> 本文件是工作区初始化流程的总览（总索引）。
> 初始化纯粹聚焦于**询问工作区路径**、**建立 tmp 目录**与**建立初始化文件**，
> 不包含连接 EDA、本机环境自检或执行 EDA 读写等后续动作。

## 初始化核心范围（三步）

1. **向用户询问工作区路径** —— 确认运行时根目录 `cwd`（与 Kilocode workspace root 比对）。
   详见 [`向用户询问工作区路径/向用户询问工作区路径.md`](向用户询问工作区路径/向用户询问工作区路径.md)。
2. **在工作区建立 tmp 文件夹** —— 在 `cwd` 下建立隔离的 `./tmp/` 运行产物目录及契约子目录。
   详见 [`在工作区建立tmp文件夹/在工作区建立tmp文件夹.md`](在工作区建立tmp文件夹/在工作区建立tmp文件夹.md)。
3. **建立初始化文件** —— 固化本会话初始化状态（`./tmp/init/workspace-init.md`）并建步骤进度账本（`./tmp/init/progress.md`）。
   详见 [`建立初始化文件/建立初始化文件.md`](建立初始化文件/建立初始化文件.md)。

## 严格边界说明

- **纯工作区准备**：本目录所定义的初始化动作不触发任何编辑器/DAEMON 连接、
  不执行本机环境自检、不调用 EDA API 读写原理图或 PCB。
- 连接 EDA 与后续读基线、运行工具探针等属于后续的正式工作流（详见 `references/lib/connection-setup.md`）。
- **异常处置**：用户指定路径不存在、不可写或指向 skill 目录 → 停止初始化并向用户报告，重新询问路径，不静默换目录、不自行创建（细则见 [`建立初始化文件/建立初始化文件.md`](建立初始化文件/建立初始化文件.md)）。
- **安全合规**：所有操作严格限定在工作区内，禁止逃逸出工作区或污染 skill 目录
  （`FILE_CREATION_POLICY.md` §1.3/§2.3/§3）。
- **本步骤结束前记账**：`python <SKILL_DIR>/scripts/progress-log.py --step 1 --name 初始化部分 --cmd <路径确认/建目录命令> --art ./tmp/init/workspace-init.md --result pass`；账本由 [`建立初始化文件/建立的文件/建立的文件.md`](建立初始化文件/建立的文件/建立的文件.md) 建头，未记账 = 本步未完成，不得进入「处理用户需求」。
