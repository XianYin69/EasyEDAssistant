# EasyEDAssistant Reference：交付与清理 — 清理

> 本文件是「交付与清理」第 5～6 步的分支细则（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 顺序（不得颠倒）

1. **先交付**：按 [`../交付文档/交付文档.md`](../交付文档/交付文档.md) 生成手册，按 [`../交付报告/交付报告.md`](../交付报告/交付报告.md) 出报告。
2. **再导图**：需要保留的截图/导图先导出到手册引用路径或用户指定的正式交付目录（非 skill 目录）。
3. **后清理**：删除 `./tmp/` 全部子目录与文件（含未引用的中间产物）；快照类只保留最近 3 张的规则在会话中已生效，此处整体删除。
4. **记摘要**：在交付报告中记录删除清单摘要（目录 → 文件数）与「tmp 已清理」。

## 例外与异常

- 用户明确要求保留 tmp 产物时不删除，改为提示其不入库（`.gitignore` 已排除 `tmp/`）。
- 会话中断或异常结束时同样执行清理，未完成部分在报告中注明缺失工件。
- 清理前确认没有「尚未交付但只存在于 tmp」的成果：发现即先导出再清理。
- 不得把 tmp 产物提交 git；发现已暂存则撤销暂存并说明。

## 判据与动机

- 交付物（手册、报告、正式目录内的图片）是长期资产；`./tmp/` 是一次性运行产物，留着会污染工作区并造成后续会话误读。
- 清理前先核对成果，避免把未交付内容随 tmp 一起删掉。
