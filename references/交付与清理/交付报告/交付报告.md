# EasyEDAssistant Reference：交付与清理 — 交付报告

> 本文件是「交付与清理」第 4 步的分支细则（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 报告字段（缺一不可）

1. **修改范围**：本次动了哪些页面/模块/网络；「不动」的部分列作回归对照。
2. **源数据与图面差异**：回读数据与官方导图的差异点；截图 stale 时标注为阻断项。
3. **各验证层结果**：拓扑（`design-diff`/`connectivity-diff`）、几何（`layout-lint`/`layout-score`）、电气（`sch gate --strict`/`pcb drc`/`pcb check`）、呈现（导图）、保存（`saved:true`）逐层给出 pass/fail/blocked。
4. **已保存页面**：显式保存过的文档与确认结果。
5. **未解决问题与未运行检查**：如实列出；`blocked`（环境问题）与 `fail`（设计问题）分开陈述，聚合数不得当「全部通过」。
6. **清理摘要**：`./tmp/` 删除清单（目录 → 文件数）与「tmp 已清理」声明。

## 判定与门禁

- 任一门为 `fail`/`blocked` 或存在未运行检查 → 报告中显著标注，且不宣称整板交付完成。
- 局部完成只写局部：不得用「已交付」概括未完成部分。
- 报告与用户确认结果一并发给用户；用户要求补充则回到 [`../交付文档/交付文档.md`](../交付文档/交付文档.md) 或对应步骤补齐。
