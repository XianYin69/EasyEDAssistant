# EasyEDAssistant Reference：单步执行 — 执行与回写

> 本文件是「单步执行」第 3～4 步的分支细则（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 执行纪律

1. **只执行被选步骤**：其余步骤不重跑、不顺手改动；发现其它步骤的问题时报告并询问，不静默处理。
2. **写前读**：任何写操作前回读被改对象的新鲜快照（器件/引脚/网络/几何/规则）；位号或 primitiveId 不明确时不盲写。
3. **先探链路**：本会话首次写操作前按 [`../../桥接联通性测试/桥接联通性测试.md`](../../桥接联通性测试/桥接联通性测试.md) 完成链路与门禁检查；同一会话内不重复探测。
4. **验证后保存**：按步骤文档的门禁跑完检查再 `save`，确认 `saved:true`；关键步骤后截图（保留最近 3 张）。
5. **中断不推进**：命中中断点保持暂停态，不猜默认值落笔；等待期间只做纯读取。

## 回写内容

- **状态**：本步骤执行到哪一步、是否完成、未决项清单；并追加一条 `./tmp/init/progress.md` 账目（`- [x] <步骤号> <名> | t: … | cmd: … | art: … | result: …`），缺账目即视为该步未完成。
- **绘制期逐件留证**：原理图/PCB 落位每件的截图产物路径须记入账目 `art:` 字段（`sch-`/`pcb-` 前缀）；无当次截图 = 该件未完成，禁止落位下一个。
- **结论与出处**：判定结果 + 来源三要素（出处 / 时间 / 定责），落对应 `./tmp/` 工件。
- **决策与授权**：用户拍板项与新增授权范围，记入工件决策头，供后续沿用。
- **中断记录**：未获答复时标 `checkpoint_pending: <阶段>`，便于后续恢复。

## 报告要求

- 回复用户时给出：已完成、未完成、需用户决定的三段式摘要；不把局部完成说成整步完成。
- 未运行检查与 WARN 清单如实列出；聚合结果不得当「全部通过」。
