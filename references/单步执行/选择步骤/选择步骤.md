# EasyEDAssistant Reference：单步执行 — 选择步骤

> 本文件是「单步执行」第 2 步的分支细则（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 步骤

1. **列出可执行步骤**：标准流程六步——初始化部分、处理用户需求、检查方案及敲定、原理图制作、PCB制作、交付与清理（见 [`../../电路设计标准设计流程/电路设计标准设计流程.md`](../../电路设计标准设计流程/电路设计标准设计流程.md)）；先读 `./tmp/init/progress.md` 账本标出各步已完成/未完成（`python <SKILL_DIR>/scripts/check-progress.py` 可校验），不凭对话记忆判断进度。
2. **列出可用单动作**：链路与门禁检查、基线回读、检查项单跑（成本及预算 / 元件 / 电气 / 专业技术规范）、图纸导出与截图、文档生成（技术/功能手册）、清理 `./tmp/`。
3. **询问用户**：明确询问本次执行哪一个（步骤或动作），并说明该选择会影响哪些产物；用户未指定时给出「按上下文推荐」的理由供其选择，不替代用户决定。
4. **确认授权范围**：只在该步骤内执行；需要改动其它步骤产物时先说明并取得同意（沿用已授权范围，不重复索取）。

## 边界

- 用户选择的是「整步」还是「单动作」要区分：整步按其步骤文档走完整流程，单动作只做该操作并回写结论。
- 步骤所需前置未满足（如 PCB制作 要求原理图已验收）时，先提示缺口并请用户决定补齐还是改为执行前置步骤。
- 选择结果记入上下文文件，便于续跑与复盘。
