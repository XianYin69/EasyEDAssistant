# EasyEDAssistant Reference：元件检查 — 封装与引脚检查

> 本文件是「元件检查」第 2 步的分支细则（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 步骤

1. **回读当前元件数据**：从工程中取出该元件的封装名、焊盘数量、引脚编号与引脚名（具体命令以 CLI 自描述 `--help` / `actions` 为准）。
2. **逐项核对**：把封装型号、引脚数量、引脚编号、引脚名称、引脚功能与电气类型逐条对照技术手册的封装图与引脚表。
3. **判定**：
   - 封装及引脚定义有问题（封装型号不符、引脚数不符、编号或功能错位、缺散热焊盘等）→ 回到总索引第 3 步「询问用户是否需要建立新元件」。
   - 无问题 → 标记「单个元件检查通过」，并建立元件与技术手册间的所有者关系。
4. **建立所有者关系**：在方案元件表登记该元件的 MPN、手册 URL、手册版本与页码、封装名，形成「元件 ↔ 技术手册」的归属记录，供后续检查反查。

## 判据与动机

- 引脚定义以手册为准，不以库内现成封装或历史习惯为准。
- 所有者关系让电气检查与专业技术规范检查能反查手册，避免无出处的引用。
- 本步结论只覆盖单个元件，不替代整板电气检查与专业技术规范检查。
