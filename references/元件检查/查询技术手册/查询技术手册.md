# EasyEDAssistant Reference：元件检查 — 查询技术手册

> 本文件是「元件检查」第 1 步的分支细则（自然语言）。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 步骤

1. **确定待查对象**：从方案元件清单取出当前元件的 MPN / 立创 C 号 / 封装名；信息不全时先向用户补齐，不猜测。
2. **联网查询**：调用 [`../../浏览器检索/浏览器检索.md`](../../浏览器检索/浏览器检索.md) 子流程，`websearch` 首查、`webfetch` 取正文；优先厂商官网、DigiKey、Mouser、立创商城 / LCSC、JLCPCB 等来源的官方数据手册。
3. **判定是否查到**：
   - 查到且正文可读、含封装图与引脚定义 → 记下手册来源（URL / 版本 / 页码）与关键参数，回到总索引第 2 步「检查当前元件封装」。
   - 查不到，或只有营销页、选型页、二手转述而无引脚定义 → 回到总索引第 3 步「询问用户是否需要建立新元件」。

## 落盘与留证

- 检索笔记落 `./tmp/learning/<元件>.md`：时间、触发、URL、摘要、关键参数、工程映射、未证实项。
- 手册来源与引用页码同步写入方案文件，作为「元件 ↔ 技术手册」所有者关系的依据。

## 判据与动机

- 无官方手册不得凭型号推断封装与引脚：推错会把错误封装带进原理图与 PCB。
- 检索结果与笔记是证据链而非真值；与厂商手册冲突时以官方手册为准并标注差异。
