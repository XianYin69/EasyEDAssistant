# EasyEDAssistant Reference：嘉立创EDA指令索引 — PCB指令·放置与布局

> `pcb` 域同步/放置/板框/叠层/层管理条目。参数以 `easyeda pcb <命令> --help` 为准。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

| 指令 | 一句话用途 |
|---|---|
| `pcb board-info` / `pcb docs` / `pcb list` | 读 Board（sch↔PCB 绑定）与 PCB 清单 / 工程内 PCB 文档 / 已放置器件 |
| `pcb new-board` | 为未绑定原理图新建 Board + 空白 PCB（普通更新不迁走现有绑定） |
| `pcb import-changes` | 原理图网表/器件同步进 PCB（差异超预期触发中断点） |
| `pcb add-component` | 放并连**一只**封装（import-changes 不好使时的工作替代） |
| `pcb floorplan --spec` | 从 S0 信号流规划功能带（只读） |
| `pcb arrange` / `pcb auto-place` | 粗排种子（按共享网聚簇/网格）/ 把卫星件吸到所连芯片引脚 |
| `pcb place-constrained` | 分档放置：边缘必放件（连接器/模组/IPEX）贴板边并锁定，其余合法化 |
| `pcb refine` | 分数驱动布局精修，逐步可回滚（默认 dry-run） |
| `pcb move` / `pcb align` / `pcb distribute` / `pcb grid-snap` | 相对平移 / 对齐 / 等距 / 落格（mil 尺度，排除锁定件） |
| `pcb modify` | 摆位主入口：移/转/翻面/锁/位号 |
| `pcb lock` / `pcb delete` | 批量锁/解锁（回读验证）/ 按 id 删器件 |
| `pcb mount-holes` | 板框四角放 M3 安装孔（碰撞检查后 MULTI 层挖槽，不盲放） |
| `pcb outline-get/set/clear` | 读/闭合物 Polygon 设（mil, y-up）/删当前板框 |
| `pcb outline-round` / `pcb outline-fit` | 圆角矩形板框 / 收紧板框贴合器件+边距（提利用率） |
| `pcb slot` | 挖槽/异形孔（MULTI 层 fill 铣穿） |
| `pcb stackup` | 铜层数 + 内层类型（signal/plane）查询设置 |
| `pcb layers` / `pcb layer-set` / `pcb layer-visibility` | 列层（含当前层/铜厚数）/ 切活动编辑层 / 显隐聚焦 |
| `pcb stage` | 流程门：status / confirm-tier（T1–T4 逐档）/ confirm-layout（P2）/ confirm-outline（P3）/ reset |
| `pcb nets` | 列当前 PCB 全部网络（名/长度/颜色），网络全集对账用 |
| `pcb sync-designators` / `pcb sync-attrs` | 占位位号（U?/C?）按 uniqueId 从原理图修复 / 空属性回填 |
| `pcb dump` | 整板只读几何快照（离线 fixture 采集用） |
