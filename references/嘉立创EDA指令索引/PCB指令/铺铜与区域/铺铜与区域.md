# EasyEDAssistant Reference：嘉立创EDA指令索引 — PCB指令·铺铜与区域

> `pcb` 域铺铜/电源分布/禁布区条目。PLANE 生成顺序不能反——正本见 [`../../../lib/design-rules.md`](../../../lib/design-rules.md) §4.7。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

| 指令 | 一句话用途 | 关键纪律 |
|---|---|---|
| `pcb pour` | 按闭合 Polygon 铺铜并绑网（通常 GND） | net 必绑；动态 pour 优于静态 fill |
| `pcb pour-list` / `pcb pour-delete` | 列铺铜（可按网筛）/ 按 primitiveId 删 | — |
| `pcb pour-fit` | GND/电源铺铜自动贴合板框并内缩 | — |
| `pcb pour-clean` | 清 netless 死铜 | 配合 `pcb check` 的 netless-pour 项 |
| `pcb pour-rebuild` | 布局/布线变更后重算全部铺铜 | `doc reload` 后、铜形变化后必跑再验证 |
| `pcb power-pour` | 2 层电源分布：GND 双面铺铜 + 每轨局部 pour | 电源走铺铜块不走细 track |
| `pcb power-planes` | 4 层：GND 内电层 + 电源内层 + via 缝合 | 顺序：信号层先铺该网→`stackup set --plane` 翻内电层→rebuild；先翻再铺会掉 L1 netless；两层升级须显式 `--allow-stackup-change` |
| `pcb fill` | 绑网填充区域（异形大块铜）create/list/delete | — |
| `pcb region` | 禁布/规则区域 create/list/delete | 天线/RF 用 no-pours 全层 |
| `pcb antenna-keepout` | 自动在 RF/天线件末端生成全层无铜 keep-out | `pcb check` 的 antenna-keepout 规则强制，硬门不可放宽 |

## 铺铜禁忌（与检查联动）

1. 天线/RF 下方各层禁铜；晶振底部禁铺铜穿越；差分对之间不铺铜。
2. 铜面或 via 修改后查 anti-pad、热连接、EP 接地——命令成功≠连通。
3. 新鲜板：本会话新建未 reload 的 PCB 按创建时规则快照 reflow，`doc reload` 后 rebuild 才按 live 规则生效。
