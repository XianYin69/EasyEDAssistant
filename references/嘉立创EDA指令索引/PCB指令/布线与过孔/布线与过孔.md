# EasyEDAssistant Reference：嘉立创EDA指令索引 — PCB指令·布线与过孔

> `pcb` 域布线条目。交互式布线菜单无 `eda.*` API（见 [`../../../lib/verification-delivery.md`](../../../lib/verification-delivery.md) §9），程序化布线以下列命令为限。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## CLI 命令

| 指令 | 一句话用途 |
|---|---|
| `pcb track` | 两坐标间在指定层画铜线（mil, y-up）——逐笔创建后逐笔验证 primitive |
| `pcb track-list` / `pcb track-delete` | 列走线（可按网/层筛）/ 按 primitiveId 精删（rip-up 是网级，这是手术级） |
| `pcb route-short` | 短净空跳线自布：逐网 MST + L 形走线（默认跳过电源/地，`--route-power` 强制） |
| `pcb route-critical` | P7.0 关键网先行：电源铺铜→差分配对走通并实测→锁定 |
| `pcb rip-up` | 撕线（删 track+via），`--net` 限定范围；板框与锁定件安全 |
| `pcb clear-routing` | 原生 clearRouting（@alpha 可能不可用——优先 rip-up） |
| `pcb export-dsn` | 导出 Specctra DSN（**必须含禁布区**） |
| `pcb autoroute` | 外部 Freerouting 引擎（DSN→SES→import→DRC）；无 engine 配置时只导 DSN |
| `pcb import-autoroute` | 导入布线结果（.ses / autoroute .json） |
| `pcb beautify` | 直角走线圆角化收尾（先 dry-run；处理后仍需 DRC/连通/长度复核） |

## 过孔与图元动作（CLI 无顶层封装 → 走 actions/call）

| 动作 | 用途 | 备注 |
|---|---|---|
| `pcb.via.create` / via-hop | 落过孔、跨层跳线 | 真值查 `easyeda actions`；嵌入焊盘 via 在 `doc reload` 后会被重置 netless → reload 后、DRC/铺铜前重新绑定 |
| 泪滴 teardrop | **无 API** | 制造前在 UI 右键手动加 |

## 布线纪律

1. 先关键网后普通信号；稠密板默认交用户点原生「自动布线」（人机协作档）。
2. 电源走铺铜不走细线（route-short 默认跳电源即为此）；2 层剩余 No-Connection 多为铺铜到不了散点电源焊盘——需 via 缝合或专层。
3. 布线变更重置 `post_route_checked`，重新过门才可交付。
