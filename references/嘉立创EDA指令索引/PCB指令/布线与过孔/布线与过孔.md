# EasyEDAssistant Reference：嘉立创EDA指令索引 — PCB指令·布线与过孔

> `pcb` 域布线条目。交互式布线菜单无 `eda.*` API（见 [`../../../lib/verification-delivery.md`](../../../lib/verification-delivery.md) §9），程序化布线以下列命令为限。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## CLI 命令

| 指令 | 一句话用途 |
|---|---|
| `pcb track` | 两坐标间在指定层画铜线（mil, y-up）——逐笔创建后逐笔验证 primitive |
| `pcb track-list` / `pcb track-delete` | 列走线（可按网/层筛）/ 按 primitiveId 精删（rip-up 是网级，这是手术级） |
| `pcb route-short` | 短净空跳线自布：逐网 MST + L 形走线（默认跳过电源/地，`--route-power` 强制） |
| `pcb route-critical` | P7.0 关键网先行：电源铺铜→差分配对走通并实测→锁定 |
| `pcb rip-up` | 撕线（删 track+via），`--net` 限定范围；板框与锁定件安全 |
| `pcb clear-routing` | 原生 clearRouting（@alpha 可能不可用——优先 rip-up） |
| `pcb export-dsn` | 【已弃用】Specctra DSN 导出（迷宫布线输入）；本项目禁调用 |
| `pcb autoroute` | 【已弃用】外部 Freerouting 迷宫引擎（DSN→SES→import→DRC）；本项目**禁调用**，见 [`../../../PCB绘制/干涉布线/干涉布线.md`](../../../PCB绘制/干涉布线/干涉布线.md) |
| `pcb import-autoroute` | 【已弃用】迷宫布线结果回灌（.ses / autoroute .json）；本项目禁调用 |
| `pcb beautify` | 直角走线圆角化收尾（先 dry-run；处理后仍需 DRC/连通/长度复核） |
| `python <SKILL_DIR>/scripts/route-check.py` | **人工向量段落笔前干涉演算门**（异网 track/via/pad/keepout/板边距离判定，档位源自硬编码 间距与线宽.md；exit 0 才准落笔） |

## 过孔（CLI 顶层命令）

| 指令 | 一句话用途 |
|---|---|
| `pcb via` | 在 (x,y) 落一个过孔（hole+外径，mil y-up），逐笔验证 primitive |
| `pcb via-list` / `pcb via-delete` | 列过孔（可按网筛）/ 按 primitiveId 精删 |
| `pcb via-bond` | 把无网络的封装内 via（EPAD 散热孔）绑定到所在焊盘的网络；**`doc reload` 后会被重置 netless，reload 后、DRC/铺铜前必须重跑** |
| `pcb via-hop` | 换层跳线：stub→via→hop-track→via→stub（可选 bond 填充）；换层两侧配套地孔 |
| `pcb via-stitch` | 矩形区内批量网格过孔（散热 / GND 缝合） |

## 无 CLI 封装的动作（走 actions/call 或 GUI）

| 动作 | 用途 | 备注 |
|---|---|---|
| `pcb.via.create` 族 | 细粒度图元动作 | 真值查 `easyeda actions`；常规放孔优先上面的 `pcb via` |

## 布线纪律（正本在 PCB绘制/干涉布线/）

1. **方法钉死**：网络标签-端口 + 向量-节点 + 干涉演算 + 硬编码档位；**上游迷宫自动布线已弃用**——先关键网（`route-critical`）、再短净空跳线（`route-short` 障碍感知档），剩余长网由 Agent 逐段构造向量、**每段先过 `route-check.py` 再 `pcb track`**；禁止整板交给自动引擎"赌一把"。
2. 电源走铺铜不走细线（route-short 默认跳电源即为此）；2 层剩余 No-Connection 多为铺铜到不了散点电源焊盘——需 via 缝合或专层。
3. 布线变更重置 `post_route_checked`，重新过门才可交付。
