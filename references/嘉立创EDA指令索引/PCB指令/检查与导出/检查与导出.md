# EasyEDAssistant Reference：嘉立创EDA指令索引 — PCB指令·检查与导出

> `pcb` 域检查/约束/丝印/保存快照条目。验证分层正本见 [`../../../lib/verification-delivery.md`](../../../lib/verification-delivery.md) §8.1–§8.3。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 门禁与检查

| 指令 | 一句话用途 |
|---|---|
| `pcb drc --json` | 归一化违规清单（可能聚合数——INFO/WARN 单列，0 fatal≠全过） |
| `pcb check` | DFM 审计：锐角/悬空铜/坏 via/颈缩/3W 耦合（只读） |
| `pcb drc-rules` / `pcb drc-rules-set` | 读当前 DRC 规则配置 / 只升不清的间距规则修正 |
| `pcb report` | 只读设计报告：逐网长、net-class 合计、差分 skew、等长 spread |
| `pcb nets` | 列当前 PCB 网络全集（名/长度/颜色），网表对账第一屏 |
| `pcb net-classes` | 打印线宽阶梯（signal/power-branch/power-trunk/high-current/gnd） |
| `pcb diff-pair` / `pcb eq-group` | 差分对约束 / 等长网络组约束（create/list/delete，布线前声明） |
| `pcb layout-lint` / `pcb layout-score` | 放置质量+可布性预测（`--gate` 是硬门）/ 九维打分逐件归因（诊断非硬门） |
| `scripts/pcb-gate.py` | 本表检查序列一键封装（drc/check/lint/score/report/net-classes → `./tmp/pcb/gate-*.json`，0 全过 / 3 阻断；`--with-gate` 推进 `pre_route_passed`） |

## 丝印

| 指令 | 一句话用途 |
|---|---|
| `pcb silk-align` | 位号对齐避让（不重叠） |
| `pcb silk-set` / `pcb silk-add` | 批量调既有丝印位置/旋转/字号 / 加自由字符串 |
| `pcb silk-label-pads` / `pcb silk-netnames` | 焊盘标 pin 号/网名 / 区域内自动生成网名丝印 |
| `pcb silk-import-svg` / `pcb silk-zone-outline` | SVG logo 导入为实心丝印 / 功能分区边框自动绘制 |

## 保存与快照

| 指令 | 一句话用途 |
|---|---|
| `pcb save` | 保存到磁盘，以 `saved:true` 为准 |
| `pcb snapshot` | 当前 PCB 画布 PNG（视口渲染，配 `--previous-sha256` 检 stale） |
| `pcb stage-snapshot` | 阶段留档：原生快照+数据包，空帧/同帧门控 |
| 制造文件 | Gerber/坐标/BOM 导出经 GUI 或 `bom export`；交付前确认层叠/GND/电源/丝印 |
