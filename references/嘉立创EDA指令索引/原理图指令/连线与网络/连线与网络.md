# EasyEDAssistant Reference：嘉立创EDA指令索引 — 原理图指令·连线与网络

> `sch` 域连线与网络标记类条目。幂等纪律正本在 [`../../../lib/api-operations.md`](../../../lib/api-operations.md) 纪律 1–3，本节只列入口。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

| 指令 | 一句话用途 | 关键纪律 |
|---|---|---|
| `sch autoconnect` | pin 感知规划器：自选方向/短桩长度，把引脚（或 `--spec` 批次）连到 flag/netport | **幂等**，已连目标网跳过；35s 预算；no safe candidate = 硬拒不落笔 |
| `sch connect` | 手工从引脚引出桩线并在末端放 netflag/netport | **不幂等**，重发叠加导线与 marker，不盲重发 |
| `sch disconnect` | 删引脚桩线与其末端 flag（connect 的逆） | 删后查 `alsoDisconnectedPins[]` 逐个恢复 |
| `sch netflag` | 创建电源/地/网络旗标或端口 | VCC/GND 可局部重复；标签不替代连接图 |
| `sch no-connect` | 置/清引脚 NC 标记 | 保留明确 NC，不删物理引脚 |
| `sch plan` | 离线生成「显式 marker 增补（含 NC→连接）」保护队列 | 只支持明确增量；同脚先清 NC 核对中间态再连 |
| `sch designators` | 位号 allocate→plan→verify，修复器件绑定 | 按官方库前缀补缺，保留合法位号与顺序 |

## 连线后必查

1. 批次 `--spec` 连完 → `sch check` 兜叠加 marker → 回读 pin→net 与黄金表对账。
2. 跨页网络用 `sch nets` 审计同名多轨/单脚网（逐页命令看不见的那半）。
3. 网络标签类动作细节 → `easyeda actions` 查 `schematic.*`；已废弃 `sch_Netlist.getNetlist()` 不可用。
