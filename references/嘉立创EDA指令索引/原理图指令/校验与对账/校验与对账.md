# EasyEDAssistant Reference：嘉立创EDA指令索引 — 原理图指令·校验与对账

> `sch` 域读取/校验/差异/页面文档/保存导出条目。验证分层正本见 [`../../../lib/verification-delivery.md`](../../../lib/verification-delivery.md) §8.1。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 读取与差异

| 指令 | 一句话用途 |
|---|---|
| `sch read` | 一次调用取语义快照（器件+网络+check），回读对账首选 |
| `sch list` | 列页上器件（`--include-device-identity/--include-pins/--include-bbox/--include-wires`） |
| `sch connectivity` | 导出布局无关连接 IR（可 `--all-pages`） |
| `sch connectivity-diff` / `sch design-diff` | 离线比较两快照：拓扑层 / 身份+连接+几何+完整计划 |
| `sch reconcile` | 从块库重推应有连接，与活体网表逐条对账 |

## 门禁与几何检查

| 指令 | 一句话用途 |
|---|---|
| `sch gate` | S5 校验门固定序 layout-lint→check→bridge-check→drc，一张报告；`--strict` 告警也阻断 |
| `sch check` | SDK DRC 给不了的逐项检查 |
| `sch bridge-check` | 共线合并短路 + 孤儿桩（导线树粒度） |
| `sch drc` | 官方 SDK DRC 门（可能只有聚合布尔，聚合≠明细） |
| `sch layout-lint` / `sch layout-score` | bbox 重叠/间距检查 / 可读性打分（折叠反标、邻近、链）带可执行修复 |
| `sch sheet-geometry` | 纸张边界 + 图签禁放区（provenance 标注；绘制前必取） |

## 页面与文档管理

| 指令 | 一句话用途 |
|---|---|
| `sch pages` / `page-new` / `page-rename` / `page-delete` | 列文档与页 / 新建 / 改名（改名后看返回 `verified`，勿立即 `doc ls`）/ 删页（无撤销） |
| `sch rename` | 改整个文档名（非单页） |

## 保存与导出

| 指令 | 一句话用途 |
|---|---|
| `sch save` | 保存当前文档，以 `saved:true` 为准（autosave 仅兜底） |
| `sch export-image` | 页面或指定图元导出 SVG/PNG/PDF（文档渲染，后台安全，交付插图来源） |
| `sch netlist` | 导出网表工件（用 ManufactureData 通道） |
