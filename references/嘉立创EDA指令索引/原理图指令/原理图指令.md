# EasyEDAssistant Reference：嘉立创EDA指令索引 — 原理图指令

> `easyeda sch` 域总索引（来源版本 v1.5.1 自描述）。主数据路径：**connectivity → lib-layout → compose → apply → 回读对账**。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言；条目见三个同名子文件。

## 数据主线（先连接数据，再几何，最后转换回读）

1. 读现状：`sch connectivity`（布局无关 IR）→ 离线算几何：`sch lib-layout`/`sch compose` → 落图：`sch apply`（保护队列）→ 回读：`sch read`/`sch list`/`sch connectivity` 对账。
2. 逐件纠错：每落位一个器件跑 `scripts/visual-qa.py --schematic`（截图 + 图纸边界越界核验），见 [`../../绘制原理图/部分绘制与截图/部分绘制与截图.md`](../../绘制原理图/部分绘制与截图/部分绘制与截图.md)。
3. 页面红线：每页 ≤150 元件（引擎性能），图纸边界以 `sch sheet-geometry` 为准。

## 高频入口速查

| 场景 | 首选指令 | 备注 |
|---|---|---|
| 放置单件 | `sch place` | 库身份先经 `lib by-lcsc`/`blocks` 确认 |
| 模块整图 | `sch compose` → `sch apply` | 破坏性替换 `--replace` 须已授权范围 |
| 批量连线 | `sch autoconnect --spec` | 幂等；单发 `sch connect` 不幂等 |
| 严格门禁 | `sch gate --strict --doc <页>` | layout-lint→check→bridge-check→drc 固定序 |
| 截图交付 | `sch export-image` | 文档渲染，后台安全；**默认 SVG，PNG 须显式 `--format png --out <path>`**（v1.5.x） |
