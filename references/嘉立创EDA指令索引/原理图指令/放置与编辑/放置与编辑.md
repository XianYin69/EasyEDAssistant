# EasyEDAssistant Reference：嘉立创EDA指令索引 — 原理图指令·放置与编辑

> `sch` 域放置/几何/编辑类条目。参数与边界行为以 `easyeda sch <命令> --help` 为准。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

| 指令 | 一句话用途 |
|---|---|
| `sch place` | 按库身份在坐标落一只器件（写前先读库与坐标） |
| `sch compose` | 把已设计好的 Lib 电路合成到一页并编译保护队列（`--replace` 清页重建，须授权） |
| `sch apply` | 重放保护队列落图（契约见 [`../../动作目录与队列/动作目录与队列.md`](../../动作目录与队列/动作目录与队列.md)） |
| `sch materialize` | 把 1.4 原理图数据转成器件放置队列（仅基础放置，不代替 compose 完整组合） |
| `sch block-apply` | 实例化电路块：落件、连内部网、绑端口 |
| `sch autolayout` | 按模块分区自动摆位（确定性、lint-clean 坐标） |
| `sch autoplace-free` | 把器件打包进图纸空白区（无分区，其余件不动） |
| `sch lib-layout` | 从规范网络与实测引脚离线算 Lib 内部位置与导线 |
| `sch power-layout` | AMS1117 类四件套电源电路离线模板 |
| `sch frame` | 应用/校验模块虚线框与标题（JSON 驱动） |
| `sch extract-layout` | 从已放置实例反推块的 layout 模板 |
| `sch modify` | 改器件位置/位号/BOM 标志/自定义属性 |
| `sch replace` | 换成库内另一型号（器件标准化） |
| `sch rebind-symbol` / `sch rebind-footprint` | 五步换绑符号/封装（modify→delete→create→restore） |
| `sch select` | 按 ID 选择图元 |
| `sch group` / `sch group-move` / `sch group-arrange` | 虚拟组管理；组作刚体带线移动；按跨组网络铺第二层排布（平台无分组 API） |
| `sch clusters` | 列 L1 虚拟组并判组间重叠/出图纸 |
| `sch align` / `sch distribute` / `sch destagger` | 对齐、等距、批量消 marker 重叠（带桩线整组移动，默认 dry-run） |
| `sch sheet` | Sheet 层整理：全部功能区依纸张排布 |
| `sch open` | 按 UUID 打开/激活原理图页 |
| `sch clear` / `sch prim-delete` | 清空当前页 / 按 id 删任意图元（破坏性，先回读） |
| `sch resolve-lcsc` | 已放置件反查真实 LCSC C 号（默认 dry-run） |
