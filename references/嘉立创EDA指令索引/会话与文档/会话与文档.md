# EasyEDAssistant Reference：嘉立创EDA指令索引 — 会话与文档

> `easyeda` 顶层域索引（会话建立、文档路由、流程状态机）。参数一律以 `--help` 为准。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 全局 flag（所有域通用）

| Flag | 用途 |
|---|---|
| `--project <名/uuid>` | 按工程路由（抗 windowId 漂移），写操作必带 |
| `--doc <页/uuid>` | 把写操作钉在指定页/PCB，派发前经 document.current 确认，防落错前台页 |
| `--host` / `--ports` | daemon 主机与端口段（默认 127.0.0.1，60832-60841） |
| `--skip-version-check` | 版本不一致强跑（审计逃生门）；**本 skill 禁用**：不得用它掩盖本机 `versionGate` 非 ok，须记 blocked 转用户（见 [`../../约束部分/运行环境不可变/运行环境不可变.md`](../../约束部分/运行环境不可变/运行环境不可变.md)） |
| `--force-stale-read <理由>` | 越过 STALE_READ 门读 PCB（审计 daemon.stale_read.force；正常修法是 doc reload） |

## 会话与门禁

| 指令 | 一句话用途 | 流程落点 |
|---|---|---|
| `easyeda update --check --exit-code` | **本 skill 禁用**（会联网比对最新发行版）；改用 `easyeda health` 的 `versionGate` 本机比对，见 [`../../约束部分/运行环境不可变/运行环境不可变.md`](../../约束部分/运行环境不可变/运行环境不可变.md) | 桥接联通性测试·门禁检查 |
| `easyeda health` / `daemon health` | daemon 与连接器健康（不代门禁） | 桥接联通性测试 |
| `easyeda daemon start --auto-update-skill=false` | 前台起 daemon（同端口接管旧实例）；**必带 `--auto-update-skill=false`**，否则默认 on 会静默覆写已装 skill 目录（运行环境不可变） | 环境异常恢复 |
| `easyeda version` | CLI 版本信息 | 索引刷新核对 |

## 文档与视图

| 指令 | 一句话用途 |
|---|---|
| `easyeda doc ls/open/switch/reload` | 列/开/切/存后重开文档；mutation 后 STALE_READ 的标准修法 |
| `easyeda project info/doc/open` | 读工程与当前文档上下文、按 UUID 开页 |
| `easyeda view fit/fit-selection/region/zoom` | 视口缩放定位（截图前 fit 缓解 canvas-freeze） |
| `easyeda board create/current/list/copy/rebind/rename/delete` | Board（原理图↔PCB 组合）绑定管理，陈旧绑定用 rebind 修 |

## 流程状态机与工件

| 指令 | 一句话用途 |
|---|---|
| `easyeda workflow init/status/advance/confirm/reset/pages` | 设计流程状态机；`--reconcile` 对实况，指纹漂移即失效下游确认 |
| `easyeda apply <playbook.json>` | 重放声明式步骤队列（契约见 [`../动作目录与队列/动作目录与队列.md`](../动作目录与队列/动作目录与队列.md)） |
| `easyeda spec validate/show/backfill` | S0 方案书校验/规范化/位号回填（结构校验≠连接正确） |
| `easyeda audit tail/cost/export` | 审计日志：最近派发/成本台账/导出可重放 playbook |
| `easyeda notify` | EDA 窗口内 toast 步骤提醒 |
| `easyeda skill status/sync` | **本 skill 禁用**（语义即 "installed vs latest"，会比对最新发行版并改写 skill 目录，运行环境不可变）；本机版本核对改用 `easyeda health` 的 `versionGate` |
