## 动作目录与通用调用

| 指令 | 一句话用途 |
|---|---|
| `easyeda actions` | 打印类型化动作目录 JSON——CLI 未封装的图元操作（`pcb.via.create`、`schematic.*` 等）从这里查 |
| `easyeda call <action> [--payload '<json>' --window/--project/--doc]` | 直接调任一类型化动作（如 `system.health`、`schematic.component.place`） |
| `easyeda api ls/search/show` | 官方 `eda.*` API 面离线发现（未知接口先 `api search <query>`） |
| `easyeda debug exec` | 在连接器内跑原始 `eda.*` JavaScript——**确认门控的逃生口**，typed 动作能覆盖时禁用 |
| `easyeda audit tail/cost/export` | 派发审计：最近调用/成本台账/导出可重放 playbook |

## apply playbook 契约（`sch apply` / `easyeda apply <file>`）

1. 结构：`version` + `meta` + 有序 `steps`——每步 `action+payload`／`run+flags`／`notify`；`capture` 捕获实例 ID 供后续步引用；`assert` 失败即停。
2. 生成队列前读目标页**新鲜快照**；`--dry-run` 预览，破坏性替换在已授权范围。
3. 含连接守卫或 `requireFullExecution:true` 的队列必须完整重编译重执行——**不得用 `--resume/--from/--to` 跳守卫**；仅普通队列可按 journal `--resume`。
4. 超时/部分失败：先回读区分未执行/已落地/部分完成，不盲重发；`--yes` 只落实已有授权确认，不扩范围。
5. 不提供事务撤销；检查点显式 `sch save`/`pcb save`。

## 双链路等价

- MCP（7655）与 CLI/daemon 是同一套 typed action 的两个入口；MCP 不豁免任何 dry-run/回读/`saved:true` 纪律。
- 写/批量路径优先 CLI/daemon（一次派发）；选择判据见 [`../../桥接联通性测试/桥接联通性测试.md`](../../桥接联通性测试/桥接联通性测试.md)。
