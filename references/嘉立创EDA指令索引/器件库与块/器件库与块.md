# EasyEDAssistant Reference：嘉立创EDA指令索引 — 器件库与块

> `lib`/`blocks`/`bom` 域与选型脚本管道。选型留证纪律正本见 [`../../../SKILL.md`](../../../SKILL.md) 与元件检查步骤文档。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言。

## 器件库 `lib`

| 指令 | 一句话用途 |
|---|---|
| `lib search` | 按 MPN / 值+封装 / 名称搜器件库 |
| `lib by-lcsc` | LCSC C 号直达库身份（libraryUuid + uuid，放置参数来源） |
| `lib libraries` | 列库与可写个人/项目库 UUID |
| `lib footprint create` | 建空封装资产并回读验证 |
| `lib footprint build` | 按 JSON spec 编写 pad/line 几何（**封装编辑主入口**，全量重写式） |
| `lib footprint copy` | 无损复制既有封装到可写库（改官方封装先 copy 再 build） |
| `lib footprint get` / `delete` | 读封装资产 / 精确删一个并验证不存在 |
| `lib symbol create` / `build` / `get` / `delete` | 符号链同构：建空 / JSON spec 编写轮廓与引脚 / 读 / 删 |
| `lib device create` | 建 Device 绑定既有 symbol（+可选 footprint） |
| `lib device build` | **新建元件一条龙**：造 Symbol+Footprint（+可选 3D）并绑成 Device |
| `lib device model3d` / `get` / `delete` | 换绑/清除 3D 模型 / 读关联 / 删 |
| `lib model3d` | 导入检查 3D 模型资产（请求体上限 32MiB，原始模型 <~24MiB） |
| 已放置件换绑 | `sch rebind-footprint` / `sch rebind-symbol`（五步：modify→delete→create→restore） |

## 电路块库 `blocks`（离线，无 daemon）

| 指令 | 一句话用途 |
|---|---|
| `blocks ls` | 列块（`--category/--ready/--draft` 过滤） |
| `blocks search` | 按 id/描述/类别/端口/器件搜可复用电路（**新电路先搜块**） |
| `blocks show` | 打印块全 JSON（parts/internal_nets/ports/notes，`severity=must` 约束抄进对应阶段） |

## BOM

| 指令 | 一句话用途 |
|---|---|
| `bom export` | 导出原理图 BOM（csv/xlsx 工件） |
| `bom enrich` | 经 `scripts/bom-enrich.py` 给 BOM TSV 补 LCSC C 号 |

## 脚本管道与批量落位

1. 选型链：`blocks search` → `lib search`/`lib by-lcsc` → `python <SKILL_DIR>/scripts/parts-select.py <型号或值+封装查询> [--online]`（离线标准件库 `standard-parts.json` 已随上游清理删除，离线恒 0 候选；`--online` 显式才查实时目录并按 basic/preferred/库存排序）→ 结果参数进 `sch place`/`sch block-apply`。
2. 官方批量放置扩展 `eext-batch-place-components`（GUI 侧插件，tool-probe 清单可查）：CSV 坐标（表头带单位 `Name,X(mm),Y(mm)`）批量落位，仅初始落位，落位后逐件核验再连线。
3. 参数未核实或相互冲突 → 不落图、不写回库（ [`../../元件检查/元件检查.md`](../../元件检查/元件检查.md) ）。
