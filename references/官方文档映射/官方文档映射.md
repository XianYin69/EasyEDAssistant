# EasyEDAssistant Reference：官方文档映射

> 本文件是「官方文档与 GUI 指令映射」的总索引（自然语言），自 `references/lib/official-docs.md`（原 SKILL.md 官方文档章节）拆分迁入。
> 编辑遵守 RULE_EDIT.md：文本 ≤ 50 行、自然语言；内容见两个同名子文件。

## 用途

- 给出嘉立创 EDA 专业版（EasyEDA Pro）与本 skill 最相关的官方文档入口。
- 把官方 GUI 菜单指令映射为等价程序化命令，供人在 GUI 与 skill 之间对照。

## 子文件

1. **官方文档索引**：见 [`官方文档索引/官方文档索引.md`](官方文档索引/官方文档索引.md)——官方文档清单与阅读优先级。
2. **GUI 指令映射**：见 [`GUI指令映射/GUI指令映射.md`](GUI指令映射/GUI指令映射.md)——原理图与 PCB 菜单项到 `sch`/`pcb` 命令的对照表。

## 使用原则

1. **入口关系**：官方文档描述 GUI 操作流程；本 skill 的 MCP API（`eda.*`）与 CLI（`easyeda <domain> <command>`）是同一套 API 的程序化映射，菜单顺序不必与 CLI 一致。
2. **验证增益**：GUI 与程序化操作产生等价图元，但本 skill 额外做 dry-run、回读与 `saved:true` 校验，GUI 路径没有这些门控。
3. **真值优先级**：数值判据（线宽 / 间距 / keepout 半径）以 daemon 规则代码为真值；官方菜单只说明「在哪设」，不定义数值。冲突时以代码与 JLC 官网为准并回改文档。
4. **快捷键无关**：官方快捷键只在 GUI 有效；本 skill 走 MCP/CLI，不依赖键盘快捷键。
