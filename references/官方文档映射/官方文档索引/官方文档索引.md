## 阅读与使用注意

1. **程序化接口的来源**：本 skill 的 MCP API（`eda.*`）与 CLI（`easyeda <domain> <command>`）都基于上述官方文档设计，官方文档是语义参考。
2. **映射不等价于顺序一致**：官方文档描述 GUI 流程；本 skill 的程序化路径（`sch connect` / `sch apply` / `pcb route-short` / `pcb drc` 等）是对等价操作的映射，不保证与菜单顺序一致。
3. **真值优先级**：官方文档与本 skill 冲突时，以 daemon 规则代码（`pcb_rules.go` 等）为真值来源，并回改文档对齐。
4. **辅助入口**：GUI 快捷键见 [快捷键](https://prodocs.easyeda.com/cn/introduction/hotkeys/)；设计流程见 [设计流程](https://prodocs.easyeda.com/cn/introduction/design-flow/)。
5. **版权**：官方文档由嘉立创科技集团股份有限公司所有，本项目仅作入口索引，不复制正文。
